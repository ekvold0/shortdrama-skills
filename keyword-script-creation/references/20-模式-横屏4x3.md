# 模式 · 横屏短剧 4:3

> 只写与 `00-总纲` 不同的部分。横屏规范为 V1.5（支持 2.0/2.5 双模型）。

## 一、参数卡

| 项 | 值 |
|---|---|
| 画幅 | 4:3，1920×1440（全片统一） |
| 模型 | Seedance 2.0 为主；2.5 按情节启用 |
| 单组时长 | 2.0：4–15 秒；2.5：≤30 秒，编号标【2.5模型】 |
| 组内分镜 | 2–6 个；2.5 长序列可到 8 个 |
| 单镜时长 | 舒缓 3–6 秒；强冲突 1–3 秒 |
| 全片 | 单集 ≤3 分钟（项目另有约定从其约定） |
| 编号 | `SXX-XZ-001`／`SXX-XZ-008【2.5模型】` |
| 反向画幅项 | 非横屏 4:3、竖屏画幅、16:9 |
| 台词量 | 5–12 秒/组（2.5 可放宽） |

## 二、2.0 / 2.5 怎么选

**默认 2.0。** 只有这四种情形才考虑 2.5：
1. 大段连贯对白必须一口气说完（拆开就断气）；
2. 长镜头场面调度（一组内完成走位/换位）；
3. 复杂动作连续呈现（打斗、追车、坠落）；
4. 情绪递进需要完整时长铺垫（崩溃、告白、诀别）。

用 2.5 的三个前提：**信息单一集中、调度连贯可控、生成稳定可预期**。用 2.5 时在画面参数里适当简化运镜与调度。

**铁律**：同一序列组只能一种模型；2.0 与 2.5 不得混用；混用即无效。

## 三、构图与景别

1. **宽幅优势**：全景、中远景可展现环境与人物关系；横向运镜（横移、摇移）在这里是优势。
2. **左右均衡**：避免一侧空洞、主体全挤在中间；关键信息放在视觉重心（中心或黄金分割点）。
3. **双人中景同框**可用，利用宽画幅表现人物间距与关系张力。
4. **群像**：横向排列＋前后景分层，避免人头堆叠。
5. 对话场景可用三角形机位：顶角主机位交代关系，平行机位拍单人，外反拍过肩，内反拍主观，骑轴正反打。

## 四、运镜

- 横移、摇移、升降、环绕在宽幅下表现力强，但仍要物理化（方向/速度/轨迹/与主体关系）。
- 动作戏至少用一种复杂运镜并写清运动方式。
- 复杂运镜必须服务叙事，给出理由，不许炫技。

## 五、钩子

开篇首组强化冲突/反转/悬念，可用场景全景或人物对峙制造冲击；结尾组留悬念。横屏靠「宽画幅的场面感」留人，不是靠竖屏的贴脸冲击。

## 六、反向提示词（画幅项写死）

```
【场景穿帮禁用项】…、画幅错误、非横屏4:3、竖屏画幅、16:9、转场特效。
```

## 七、横屏高频错误

| 错误 | 为什么错 | 改法 |
|---|---|---|
| 两组之间换模型 | 红线：同组模型唯一，跨组切换也要在编号标明 | 统一到 2.0，或整段用 2.5 并逐组标注 |
| 2.5 组塞两个事件 | 30 秒也撑不住双信息 | 拆组或删事件 |
| 主体全挤中间 | 宽幅两侧浪费 | 左右分布＋前后景分层 |
| 无意义远景 | 宽幅最容易犯 | 远景必须带关系或环境信息 |
| 全片横移 | 生成不稳、观感单一 | 固定为主，横移点缀 |
