## 四、命令

```bash
python lib/refs.py list face                 # 目录：节 + 条号 + 标题
python lib/refs.py list edit                 # 分镜库目录（按体裁分节）
python lib/refs.py get face 11              # 取一条全文
python lib/refs.py get edit 11 --genre 电视剧
python lib/refs.py search sound 心跳         # 关键词全文检索
python lib/refs.py expand 电视剧 11 "本组用它把逼近拍成施压"   # 生成带原文的引用串
python lib/refs.py check "……附件6 电视剧第11条【手持晃动权力压迫】……"  # 校验引用
```

## 五、两种内联格式

**附件6（全内联，标准版第 9 条）**
```
附件6 电视剧第11条【手持晃动权力压迫】｜定义：…｜AI执行：…｜叙事功能：…｜适用场景：…｜代表作品：《继承之战》。本组取用：…
```

**附件3/4/5（条名＋用到的参数，避免单元格爆长）**
```
附件3 表情第11条【微愤怒】｜AI执行：短瞬眉头下压、眼裂收紧、眉心细纹闪现，即刻抹平。｜本组取用：0.4—0.6秒闪现一次
```

## 七、维护

- 库由 `tests/build_libs_from_spec.py` 从规范 DOCX 生成；规范升版时重跑即可。
- 手改库文件会在下次生成时被覆盖，要加条目请改规范或改生成脚本。
- `lib/index.json` 是全量索引（280 条：kind/genre/section/n/title）。

## 九、写法库（第六类，不是条目库——整篇读，不用 refs.py）

前面四个库要"取一条"，这六个库要"通读一遍再抄"。它们没有条号，不能内联成引用串，也不进 `index.json`。

| 文件 | 内容 | 什么时候读 | 读法 |
|---|---|---|---|
| `41-运镜库.md` | 26 条运镜（十个运动轴对齐 `MOVE_FAMILY`）＋竖屏改写速查＋三种组合模板 | 写 movement / 镜头语言前 | 先看总表挑 1 条主运镜，再抄它的四要素参数串 |
| `42-打光库.md` | 16 条成品布光（光位＋光质＋色温＋光比）＋情绪→布光速查 | 写 light 前 | 按情节选一条，四件套照抄再按场景改光位 |
| `48-开场钩子.md` | 12 条钩子模板＋短剧专属 4 条＋堆叠规则与五类错误 | 写每组 0.0—2.0 秒时 | 挑 1–3 条分通道堆叠，不超过时间栅格 |
| `49-节奏与可读性.md` | 速度曲线（加速/减速/呼吸）＋可读性三账＋主体占比与画面级失败 | 排整集组序、查台词余量时 | 先排 A/B/C 三个记号，再逐组过可读性三账 |
| `52-表演三拍与道具.md` | 预备-动作-跟随＋重心支撑脚＋手与道具接触＋眉的方向 | 写动作连续性 / 表情前 | 每个大动作拆三拍，接触点与支撑脚都要落到句子里 |
| `55-类型成品提示词.md` | 八类型各一组成品＋10 秒完整范本＋类型速配表 | 对颗粒度／换题材时 | 抄结构不抄字，人物道具台词全部换掉 |

**和技法库的分工**：技法库（第八节）管"这招叫什么、什么档位、能不能投"；写法库管"这句话具体怎么写"。先用写法库定句子，再用技法库核档位，别反过来。

**引用纪律**：这六个库的内容可以直接抄进提示词，但**不许把条目名当引用写**（它们不是附件3–6，没有条号）。要引用电影/切镜，仍走附件6。
