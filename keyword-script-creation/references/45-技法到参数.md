# 技法到参数 · grokfilm 300 条（关键词层）

> **定位**：「画面参数」九项怎么写、从哪取料。是 `02 分镜描述改写规则` 的机器版——查完三张表就能落笔。
> **数据源**：`lib/cine_tech.json`（300 条，version 1.0）。取料用 `cine_tech.by_slot('C3e 画面参数·光影')`，不要整库读。
> **一句话结论**：英文定义**不能翻译，只能降维**——操作层抽变量、意图层改成看得见的结果、典故层赶进参考电影列。

## §1 九子参数 ← 技法落点（每项都有技法池）

画面参数九项**定序不可乱**：摄影机 → 质感 → 色彩 → 机位 → 运镜 → 光影 → 动作 → 场面调度 → 参考电影。

| 落点代码 | 技法池 | 必填项 | 参数槽 | 合格示例 | 不合格示例 |
|---|---|---|---|---|---|
| `C3a 画面参数·摄影机` | 8 条 | 机身/镜头/焦段/光圈/ISO/快门，禁「电影感」 | {focal} {fps} | ARRI ALEXA 65，35mm 定焦，f/2.0，ISO800，1/50 秒 | 电影感画面，专业摄影 |
| `C3b 画面参数·画面质感` | 3 条 | 颗粒/柔化/动态范围，禁「AI绘画感/3D感」 | {focal} | 柯达 5219，颗粒中等偏细，暗部可见，14 档动态范围 | 油画质感，很高级 |
| `C3b 画面参数·色彩` | 6 条 | 色相偏移＋饱和度＋对比三项写全，禁「高级调色」 | — | 色相偏移 +8 度青，饱和度 -15%，对比 +20% | 高级调色，电影色调 |
| `C3c 画面参数·机位` | 16 条 | 高度+俯仰角+朝向+距离四项齐全，方位写物理参照 | {height} {deg} {dist} | 机位高 0.3m，上仰 15 度，正面朝向，距主体 2.0m | 低角度仰拍，很有压迫感 |
| `C3d 画面参数·运镜` | 30 条 | 方向+幅度+速度+轨迹四要素；一镜只一个主运镜 | {move} {dur} | 沿轴线前推 0.8m，匀速，用时 3.0 秒，轨迹直线 | 缓慢推近，很有张力 |
| `C3e 画面参数·光影` | 46 条 | 光位+光型+光比+色温四项齐全，禁「氛围感」 | {ratio} {K} | 主光左上 45 度硬光，光比 1:16，色温 4300K，背景压黑 | 氛围感很强，光影很高级 |
| `C4b 正向提示词·动作物理化` | 1 条 | 七要素：部位/方向/幅度/速度/发力/结束姿势/伴随运动 | {move} | 右手抬至下颌高度，向左侧划 20cm，用时 0.4 秒，结束时手掌朝下 | 他很愤怒地挥手 |
| `C3h 画面参数·场面调度` | 1 条 | 三层纵深各有事件；竖屏禁横向并排 | {p} | 前景雨帘占画面 1/5，中景人物占高 62%，远景门口有人影移动 | 画面层次很丰富 |
| `C4e 正向提示词·画面备注` | 3 条 | 只填片名+年份，须出自片单库，禁生造 | — | 《第三个人》1949 | 参考《银翼杀手》《迷魂记》的赛博感 |

> **池薄不是遗漏**：动作物理化只 1 条、参考电影只 3 条——grokfilm 这两类本就少。这两项的主料在别处：动作七要素见 `50-正向提示词.md` §三（部位/方向/幅度/速度/发力/结束姿势/伴随运动，含呼吸），短语→七要素的展开见 §九 呼吸派生表；参考电影见 `40-画面参数.md` §五 参考片单 与本文 §2 的「典故→参考电影列」转换。本表只做技法侧补位。

## §2 六类句式转换（站点原文 → 成品，可直接套）

### 2.1 名词术语 → 参数项（拆成可填变量）

| 站点英文原文（Three-Point Lighting） | 改写后（画面参数·光影） |
|---|---|
| consisting of a key light, fill light, and backlight. The key provides main illumination, the fill softens shadows, and the backlight separates the subject from the background. | 光影：主光 前侧45度 高2.2m 硬光 4300K；辅光 正面0度 高1.8m 柔光箱 补1档；背光 后侧135度 高2.6m 勾边发丝。光比1:4。 |

**规则**：一个英文名词簇必须拆成「方向+高度+光质+色温」四件套，缺一项即视为未改写。

### 2.2 动词短语 → 运动四要素（方向/幅度/速度/轨迹）

| 原文（Push In） | 改写后（画面参数·运镜） |
|---|---|
| slowly moves the camera toward the subject, drawing viewers deeper | 运镜：沿镜头轴线向前推进，位移0.8m，匀速，用时3.0秒，起幅中景→止幅中近景，轨迹直线不下沉。 |

**规则**：英文动词只有方向没有量。必须补「幅度（米/度）+速度（秒或占比）+轨迹（直线/弧线/手持）」，否则模型自己乱动。

### 2.3 形容词 → 可测量（最容易被跳过的一步）

| 原文 | 不能写成 | 改写后 |
|---|---|---|
| extremely fast pan（Whip Pan） | 「极快的甩镜」 | 水平摇90度用时0.25秒；快门1/30秒，中段全糊 |
| jarring discontinuity（Jump Cut） | 「突兀的跳切」 | 相邻两镜同机位同角度，景别跳变≥2级，间隔0帧 |
| dramatically distorts（Dolly Zoom） | 「背景剧烈变形」 | 背景横向拉伸约1.4倍，主体高度不变（占画面62%） |
| 2x slow motion（Slow Motion） | 「慢动作」 | 拍摄48fps 回放24fps，慢放2倍；快门1/100秒 |
| warm, soft key light | 「温暖的柔光」 | 主光3200K，柔光箱1.2m，光比1:3，面部高光不过曝 |
| shallow depth of field | 「浅景深」 | f/1.8，焦点0.8m，背景虚化直径比3:1 |

**规则**：形容词后面必须跟一个数字或一个量纲。给不出数字，说明这条技法你还不能投。

### 2.4 意图/心理从句 → 可观察结果（唯一合法改写方向）

| 原文意图 | 错误写法（保留心理词） | 正确写法（看得见） |
|---|---|---|
| creates unease/disorientation（Dutch Angle） | 「营造不安、失衡」 | 画面内所有垂直线向右倾斜12度，地平线出画，门框与画框下边夹角12度 |
| building tension（Long Take） | 「用长镜头制造紧张」 | 单镜连续6.0秒不切，焦点始终在人物手上，背景两人缓慢靠近至1.2m |
| direct attention（Rack Focus） | 「引导观众注意力」 | 焦点由前景手表（0.8m）拉至后景门口人物（4.0m），移焦用时0.6秒 |
| adds dreamlike quality（Slow Motion） | 「增添梦幻感」 | 1.2秒动作放慢至2.4秒，纸片下落可见翻转3周，落点处停留0.5秒 |
| ominous atmosphere | 「气氛诡异」 | 单点顶光，光比1:32，主体半张脸在死黑中，背景无补光 |
| feels contemplative | 「沉思感」 | 人物静止不动3.0秒，视线不移动，只有呼气可见（胸廓起伏1cm） |

**规则**：模型生成的是像素，不是心理。凡进不了画面的词，要么改写，要么删掉，绝不保留。

### 2.5 影史典故 → 只进「参考电影」列

| 原文里的典故句 | 处理 |
|---|---|
| popularized in German Expressionist cinema / with Caravaggio / Godard in Breathless / famously used in Vertigo and Jaws | 画面参数·参考电影 只填：《卡里加里博士的小屋》1920、《词语》1955、《精疲力尽》1960、《迷魂记》1958。正文删除典故句。 |

**规则**：一条提示词最多挂 1 个参考片。挂 2 个以上，模型会把两种风格平均成四不像。

### 2.6 条件/否定/风险描述 → 反向提示词（不写进正向）

| 原文中的风险句 | 去向与写法 |
|---|---|
| seamless continuity / 不能有剪辑感 | 反向·基础段：禁转场特效、禁叠化、禁画面溶接 |
| concealing features while revealing outline（Silhouette） | 正向写「面部完全无光、仅轮廓可见」；反向补「禁面部补光、禁轮廓内出现五官细节」 |
| ominous / unsettling（Horror 系） | 不进正向；转成反向·剧情不符段：「禁恐怖血腥、禁鬼怪形象」 |
| AI 易崩项（手部/多人/快速动作） | 反向·人物畸变段：禁多手多指、禁面部融化、禁肢体穿插 |

## §3 禁用词 → 等价替换（写完必须扫一遍）

左列出现在提示词里即判 **error**。这类词在模型侧等于「没有任何约束」，写了等于白写，还会稀释已写好的参数。

| 禁用词 | 为什么禁 | 分镜层替换（禁量化） | 关键词层替换（带数值） |
|---|---|---|---|
| 电影感 / 电影级 | 无参数，模型随机发挥 | 写清光源方向与受光面 | ARRI ALEXA 65，35mm，f/2.0，光比1:4，5600K |
| 氛围感 | 同上 | 写有几个光源、从哪来 | 单点顶光4000K，光比1:32，背景照度低于主体4档 |
| 高级调色 / 调色感 | 同上 | 写画面偏什么色、亮部暗部各什么色 | 色相偏移+8度青、饱和度-15%、对比+20% |
| 油画感 / 绘画感 / 笔触 | 直接触发风格化，破坏写实 | 不写 | 反向·画面质量段：禁绘画笔触、禁油画质感 |
| 3D感 / 渲染感 / CG感 | 触发三维渲染风 | 不写 | 反向·画面质量段：禁3D渲染、禁塑料质感、禁边缘光晕 |
| 二次元 / 动漫风 / 日系 | 与真人写实红线冲突 | 不写 | 反向·基础段：禁二次元、禁插画、禁赛璐璐上色 |
| 紧张 / 压抑 / 窒息 | 心理词，画面无对应 | 肩线抬升、下颌前伸、手指扣住桌沿 | 呼吸22次/分、瞳孔放大、眉心纵褶3mm |
| 唯美 / 浪漫感 | 主观评价 | 逆光发丝光、前景虚化遮挡 | 逆光3800K、前景叶片占1/5虚化、空气浮尘可见 |
| 震撼 / 大片感 | 主观评价 | 低机位、三层纵深各有事件 | 机位高0.3m上仰15度、前景/中景/远景各1事件 |
| 流畅 / 自然 / 真实 | 主观评价 | 写清有没有晃、晃多大 | 手持幅度±2cm、频率1.5Hz；或三脚架完全静止 |
| 呼吸感 | 含混（既指镜头也指表演） | 写「看得见的胸廓起伏」 | 胸廓起伏幅度1cm、周期4秒 |
| 时空交错 / 蒙太奇感 | 空词 | 写交叉剪辑与每段时长 | A/B交替，每段2.0秒，共6段 |
| 情绪张力 / 张力拉满 | 空词 | 写具体微表情与身体朝向 | 下唇内收2mm、身体前倾8度、视线不移动3秒 |
| 专业 / 电影工业级 | 空词 | 删 | 删 |

> 机器校验：`verify.py` 的 **CT01** 直接命中这张表；英文技法名（如 Dutch Angle / dolly zoom）命中 **CT07**；T4 禁投中文名（一镜到底/叠化/长镜…）命中 **CT08**。否定写法（无配乐、禁叠化）不判命中——那是反向提示词的写法。

## §4 双轨差异：同一条技法，两层文本必须不同

分镜层受《05-落地要求》约束——**禁**牛顿/毫米/每秒N次/FACS 拉丁名，只留「意图+可观察行为+≤1 节奏锚」；关键词层**反而要求**写肌肉名、方向、距离、速度。同一技法因此有两条落点。

| 技法 | 分镜层写法（意图+可观察） | 关键词层写法（量化） | 典型错法 |
|---|---|---|---|
| 荷兰角 Dutch Angle | 机位：手持微斜，画面里门框和窗框都不是正的，人站不直。情绪目标：他心里已经站不稳了。 | 机位：roll轴倾斜12度（顺时针），地平线出画，垂直线与画框下边夹角12度。 | 分镜层写「倾斜12度」——违反 05 覆盖层禁量化 |
| 推近 Push In | 运镜：镜头一点一点往他脸上靠，靠到他不想被看清的地方停住。 | 运镜：沿轴线前推0.8m，匀速3.0秒，起幅中景→止幅中近景。 | 只写「缓慢推近」，幅度速度全无，模型推成变焦 |
| 甩镜 Whip Pan | 运镜：镜头猛地甩向门口，中途什么都看不清，停住时人已经在那。 | 运镜：水平摇90度用时0.25秒，快门1/30秒，中段全糊，末端急停2帧。 | 写「快速摇镜」，模型摇成0.8秒，糊度不够 |
| 移焦 Rack Focus | 运镜：先看清他手里的东西，再一瞬间看清门口站着的人。 | 运镜：焦点0.8m→4.0m，移焦0.6秒，前后景虚化直径比3:1。 | 写成「虚化背景」——那是光圈，不是移焦 |
| 剪影 Silhouette | 光影：他整个人是黑的，只有肩膀和下巴的边线亮着，看不见脸。 | 光影：背光3800K从后方170度打入，面部照度为0，轮廓边缘过曝1档，人物占画面高度70%。 | 写「逆光剪影」但给了面部补光，出来是半剪影 |
| 明暗对照 Chiaroscuro | 光影：光只落在半张脸上，另外半张和背景一起黑掉。 | 光影：单侧硬光45度，光比1:16，暗部照度低于主体4档，背景全黑。 | 写「强反差光影」，光比缺失，出来是普通侧光 |
| 升格 Slow Motion | 节奏：这一段慢下来，看清纸片翻了几圈才落地。 | 拍摄48fps 回放24fps，慢放2倍，快门1/100秒，落点停留0.5秒。 | 写「慢动作」，模型给0.5倍速，动作变形 |
| 一镜到底 One-er | （禁止单镜实现）机位跟着他从门口走到桌前，中途不切；实际拆为3镜续接。 | 拆为3镜各2.0秒，机位A→B→C同动线，衔接处 match-on-action，末镜复现首镜构图。 | 直接写「一镜到底6秒」——超单镜上限，且模型必崩 |

## §5 堆叠控制与画幅改写

### 5.1 一镜一主运镜，最多三技法

300 条里 30 条落在「运镜」这一格。一条提示词写三个运镜，模型会把它平均成一个不存在的运动。

- **主技法 1 条**：决定这一镜的运动骨架，必须来自 T1/T2。
- **辅技法 ≤2 条**：只能是光影、色彩、构图类，不得与主技法争夺同一运动轴。
- **衬技法不限**：氛围层（颗粒、浮尘、雾、雨）——只加质感不改运动。
- **冲突判定**：主技法含「转动」时，辅技法不得再含「位移」；反之亦然。

| 错误堆叠 | 为什么错 | 改法 |
|---|---|---|
| 推近 + 甩镜 + 环绕 | 三种运动抢同一轴，模型输出抖动/变形 | 保留推近为主；环绕降为下一镜的主技法 |
| 荷兰角 + 鸟瞰 + 广角+变形宽银幕 | 倾斜与俯视叠加后主体在竖屏内被压成一条 | 保留荷兰角；画幅改常规35mm |
| 升格 + 甩镜 | 甩镜需低速快门制造糊，升格需高速快门取清晰，互斥 | 二选一；若要两者，拆两镜 |
| 浅景深 + 大远景 + 微距 | 景深与景别互相矛盾，模型按最近的那个演 | 景别定了再定景深 |

### 5.2 画幅改写：竖屏装不下的怎么救

| 技法 | 竖屏冲突点 | 替代写法 |
|---|---|---|
| 航拍/直升机/大远景/建立镜头 | 竖屏高度方向信息多、宽度被裁，宏大感丢失 | 改「垂直下摇」或「高角度俯拍近景」，用纵深代替横向广度 |
| 宽银幕变形/IMAX/横移长镜 | 宽高比物理不兼容 | 竖屏改「浅景深+横向光带」；或用 2.39:1 横屏并接受上下黑边（须在画面备注声明） |
| 一镜到底/长镜 | 超单镜 8 秒上限 | 拆 2–3 镜，衔接备注写「机位从 A 续到 B」，末镜复现首镜构图 |
| 平行剪辑/分屏 | 竖屏分屏后每格宽 <40%，主体过小 | 改「交替硬切」，A/B 各 2.0 秒，靠音效做声桥标记切换 |
| 甩镜 | 横向留白少，甩出去后落点信息易丢 | 改为「垂直甩」上/下 60 度，或缩短至 0.15 秒作纯过渡 |

## §6 参数槽取值域（模板里的 {xxx} 照此填）

| 槽位 | 含义 | 取值域 / 单位 | 示例 |
|---|---|---|---|
| {focal} | 焦距 | 14/24/35/50/85/135 mm（定焦优先） | 35mm |
| {height} | 机位高度 | 米，地面0.0–0.3 / 胸1.2 / 眼1.6 / 顶3.0+ | 0.3m（低机位） |
| {deg} | 角度 | 俯仰：上仰+/下俯-；倾斜：顺时针+/逆时针-，单位度 | -15（下俯15度） |
| {dist} | 机位到主体距离 | 米，0.15–0.5 特写 / 0.8–1.5 中近 / 2–4 中景 / 5+ 全景 | 0.9m |
| {move} | 运动幅度 | 位移用米，转动用度，变焦用百分比 | 0.8m / 90度 / 15% |
| {dur} | 运动用时 | 秒，0.1 精度；须 ≤ 单镜上限 | 3.0秒 |
