# 画面参数（字段 3）

> 目标：让这一格文字可以直接被摄影指导或 AI 执行，而不是一段观后感。
> 固定结构 9 段，顺序不可变：摄影机 → 画面质感 → 色彩 → 机位 → 运镜 → 光影 → 动作 → 场面调度 → 参考电影。

## 一、固定基准（每组完整复写，不许省略）

**横屏 4:3**
```
横屏4:3（1920×1440），ARRI ALEXA 65，柯达5219/5207电影胶卷，35–定焦 85，f/2.0–f/4.0，ISO 800，快门1/50秒，LogC色彩模式，14档动态范围，院线级色彩分级
```

**竖屏 9:16**
```
竖屏9:16（1080×1920），ARRI ALEXA 65，柯达5219/5207电影胶卷，35–定焦 85，f/2.0–f/4.0，ISO 800，快门1/50秒，LogC色彩模式，14档动态范围，院线级色彩分级
```

只在剧情情绪需要时微调（如夜景降 ISO、强冲突加颗粒），微调也要写具体值。

## 二、九个子参数怎么写

| 子参数 | 必含内容 | 合格例 | 不合格 |
|---|---|---|---|
| 摄影机 | 机型、画幅、焦段、光圈、ISO、快门、色彩模式 | `ARRI ALEXA 65，定焦 50，f/2.8，ISO800，1/50秒，LogC` | `电影机拍摄` |
| 画面质感 | 胶卷、颗粒粗细、锐度、影调、对标质感 | `柯达5219，颗粒中等偏细、暗部可见，锐度中高边缘不过锐` | `有电影感` |
| 色彩 | 主色、辅色、饱和度、对比度、冷暖 | `主色冷青灰（5600K偏青），钠灯暖橙点缀（3000K），饱和度-8%，对比度+12%` | `色调好看` |
| 机位 | 角度、高度、距离、景别 | `平视，机位高1.4米，距主体0.8米，中景` | `中景` |
| 运镜 | 方式＋方向＋速度＋轨迹＋与主体关系 | `固定；后段极慢推近0.3米，速度约2厘米/秒` | `缓慢推镜（有氛围）` |

## 三、机位库

### 1. 景别（按距离）
大远景 ELS（环境/地理，人物极小，建立镜头）→ 远景 LS（空间规模，环境为主）→ 全景 FS（全身＋环境，人是结构中心）→ 中景 MS（膝/腰以上，对话主力）→ 近景 MCU（胸以上，表情神态）→ 特写 CU（局部细节，情绪/道具）→ 大特写 ECU（眼/唇/道具细节，极致张力）。

### 2. 角度（按高度）
平视（客观中立）／仰拍（权力、威严、压迫）／俯拍（渺小、无助、被监控）／鸟瞰顶拍（几何、宿命）／荷兰角（失衡、不安、危机）。

### 3. 方向与方位
正面（庄重、对称）／斜侧 45 度（最常用，立体）／正侧面（轮廓、动作方向）／背面（悬念、代入）／过肩 OTS（对峙、双向视线）／反应机位（拍听者）。

### 4. 视点
客观／主观 POV（角色所见）／半主观（带情感倾向）／反应镜头（听者反馈）。

### 5. 运镜
固定（靠画框内调度积压张力）／跟拍（时空连续）／推拉（聚焦或揭示环境）／摇移（横摇展横向空间，纵摇展垂直空间）／甩（快速横摇，运动模糊）。**每个都要写方向、速度、轨迹、与主体关系。**

### 6. 对话三角形机位（两人为例）
1 号顶角主机位（全景交代关系，用于场景头尾）／2、3 号平行机位（两侧正面单人）／4、5 号外反拍过肩（客观）／6、7 号内反拍（单人主观）／8、9 号骑轴正反打（视线对镜头）。

### 7. 特殊机位
低机位（膝/地面，压迫或儿童视角）／腰腿机位（突出动作）／手持跟拍（真实、强冲突）／多机位（复杂动作、群像）。

### 8. 三条铁律
- **轴线（180°）**：机位在轴线一侧；要越轴必须插中性镜头（特写/空镜/正面）。
- **叙事服务**：不为炫技上复杂机位。
- **AI 适配**：优先固定机位与简单运镜；POV、荷兰角、甩镜头谨慎，且必须能稳定生成。

## 四、综合优化五看

1. **站位**：参考经典影片的站位关系（《去年在马里昂巴德》《爱乐之城》《低俗小说》），横屏用左右空间，竖屏用中心纵深。
2. **场景搭建**：核心陈设＋空间层次；横屏注意左右陈设均衡，竖屏注意上下留白。
3. **动作**：细化到可执行，不用「激烈」「轻柔」这类词单独打发。
4. **神态与关系**：通过站位、眼神、距离体现关系，不靠旁白解释。
5. **调度**：镜头内人物运动与空间转换要写清起点—路径—终点。
