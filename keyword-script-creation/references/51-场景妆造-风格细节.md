# 场景与妆造（字段 5）· 风格细节（字段 7）

## 一、场景与妆造简述

### 必含两块
**场景**：地点＋时间＋光线＋核心陈设＋空间层次（前景/中景/深处各有什么）。
**人物妆造**：每个在场人物写四项——

| 项 | 写什么 | 例 |
|---|---|---|
| 服饰 | 颜色、款式、材质、磨损/穿戴细节 | 深灰涤棉工服，洗得发白，左胸小logo，袖口磨毛 |
| 体态 | 身形、姿态、站/坐/行动特征 | 158cm 微胖，圆脸，习惯性含肩 |
| 神情 | 面部表情基调 | 嘴角下压，眼皮半垂，眼神不聚焦 |
| 动作 | 典型肢体动作 | 左手一直攥着布包带子 |

### 规则
1. 必须与正向提示词里的人物/妆造参数**完全一致**，不得矛盾。
2. 同一场景跨序列组，环境陈设、光影、核心道具**完全统一**；每组复写场景核心特征。
3. **横屏**：补充左右空间布局（左侧窗、右侧办公桌），注意左右陈设均衡。
4. **竖屏**：补充上下空间与中心安全区，说明主体在画面中的高度位置。

### 路人/群演
未给参考图的角色要自行生成妆造，且**必须差异化**：年龄区间、性别、着装风格、体态特征。
例：`20岁出头女性，前台工装`、`40岁中年男性，商务西装，微胖`。横屏群像要规划多人在宽幅中的分布。

### 特殊场景（闪回/回忆/梦境/平行时空）
必须标 **【特殊场景标记】**，并写视觉区分：`闪回：冷色调降饱和度，轻微模糊边框，复古胶卷颗粒`。叙事边界要一眼可辨。

## 二、风格细节描述补充

### 定位
它是画面参数与正向提示词的**贴肉补充**，必须与质感/摄影机/光影参数 100% 贴合，且**每个微观分镜都要有独立描述**。

### 每个分镜写六样
1. 胶卷颗粒：粗细、分布（暗部可见/高光干净）
2. 光影层次：高光、中间调、阴影的过渡
3. 色彩影调：冷暖偏向、饱和度、是否褪色
4. 人物微表情细节：眼神光、嘴角、眉毛
5. 道具材质：金属反光/木质纹理/布料褶皱
6. 景深虚实：焦点位置、虚化程度

### 随情节变质感
| 场景类型 | 质感倾向 |
|---|---|
| 强冲突 | 高对比、硬光、高锐度、粗颗粒 |
| 内心独白/抒情 | 柔和光影、细腻面部、浅景深 |
| 悬疑 | 低照度、明暗对比、暗部保留细节 |

### 画幅差异
- 横屏：额外写左右画面的层次与空间氛围（左侧冷光窗、右侧暖灯桌面）。
- 竖屏：额外写上下层次（上方吊环/天花板压顶、下方地面细节）与中心安全区的质感处理。

### 合格例
```
分镜1｜柯达5219粗颗粒，暗部颗粒明显；窗外冷光勾勒人物轮廓，高光不过曝；主色冷青灰，饱和度-10%；眼神光小而硬，嘴角微抿；金属窗框反光冷白；焦点在眼，背景虚化至f/2.0。
分镜2｜颗粒转细，面部质感细腻；顶光压出下颌阴影，光比1:3；暖橙台灯入画，色温对比；眼睑半垂、睫毛投影落在下眼睑；桌面木质纹理清晰；焦点前移0.2米。
```

### 自检
- [ ] 与画面参数/提示词无矛盾
- [ ] 逐分镜独立，不是全组一句话
- [ ] 质感随情绪变化
- [ ] 有具体可执行的参数（颗粒/光比/色温/焦段）
- [ ] 画幅专属层次写明（横屏左右/竖屏上下）
