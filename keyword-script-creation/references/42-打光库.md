# 打光库 · 16 种布光怎么落成参数

> 用途：写「画面参数·光影」（九项第 6 项）时取用。光影是九项里最容易被写成「氛围感」的一项，也是最该写死数字的一项。
> 来源：higgsfield-skills `01-cinematic/references/camera.md` 的打光理论与成品打光库（10+15 条），合并去重、换成公制与四件套口径。
> **纪律**：光影 = 光位 ＋ 光型 ＋ 光比 ＋ 色温，四项缺一即不合格；「氛围感/高级/有层次」命中 **CT01** 直接 error。
> **机器拦到哪**：**CT10** 缺色温 K 或光比 1:n 报 error，缺光位/光质报 warning；光位打得对不对机器不判，走 90 的自检与 42 §末的注意项。

---

## §1 四件套与取值域

| 项 | 写什么 | 取值 |
|---|---|---|
| 光位 | 相对主体的方向＋高度＋角度 | 正面 0 度／前侧 45 度／正侧 90 度／后侧 135 度／正后 170 度；高度写米（地面 0.0／胸 1.2／眼 1.6／顶 2.4+） |
| 光型 | 硬光／柔光／反射／实景光源 | 硬光＝直射灯或裸灯（边缘锐）；柔光＝柔光箱 1.2m、柔光布、反光板；实景＝画面里看得见的灯、窗、屏、火、霓虹 |
| 光比 | 主体受光面 : 暗面 | 1:2 平淡／1:4 常规／1:8 造型／1:16 戏剧／1:32 恐怖 |
| 色温 | 主光开尔文值 | 1500–2000 火光／2700 钨丝家用／3200 暖白／4300 中性暖／5600 日光／6500 阴天月光／9000 冷夜 |

> 一个英文名词簇必须拆成这四件套，缺一项视为未改写（`45` §2.1）。

## §4 竖屏与 AI 生成注意

1. **竖屏顶部就是天花**：顶光在 9:16 里压在人物头顶的位置比横屏更狠，光比 1:32 时整张脸会掉进死黑——除非你就是要把脸吃掉（剪影、恐怖）。
2. **侧光要留补**：竖屏两侧空间窄，单侧硬光容易只照亮半条手臂；光比写到 1:8 以上时，补一句「暗部保留 1 档细节，不完全压黑」。
3. **实景光源要写位置**：写「画面右侧台灯」「背后窗」；只写「有台灯」模型会随便挂一盏。
4. **窗光是最稳的一档**：窗外日光＋室内暖光，两灯一冷一暖，AI 几乎不会崩，适合大多数日常戏。
5. **反向提示词配套**：写剪影就在反向补「禁面部补光、禁轮廓内出现五官细节」；写平光就补「禁硬阴影、禁强对比」。

## §5 自检

- [ ] 光位、光型、光比、色温四项齐全，没有一项是形容词
- [ ] 色温写成开尔文，不写「暖」「冷」（CT01 拦「温暖」但不是全拦，自己别偷懒）
- [ ] 光比有数字，且与情绪档位匹配
- [ ] 实景光源写清了在画面哪个位置
- [ ] 与 `41-运镜库.md` 的主运镜不冲突（摇镜＋强侧光会让受光面持续变化，必要时改成固定机位）
- [ ] 与 `51-场景妆造-风格细节.md` 的时代/环境光源一致（民国戏里别出现 LED）
