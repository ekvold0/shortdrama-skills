# 音频与对白（字段 8）· 分层音效（字段 9）

## 一、铁律

1. **只允许三类声音**：人物对白、人物独白、自然环境音/拟音。**绝对禁止 BGM、配乐、歌曲**。
2. 所有音频、对白、独白时长必须与序列组时长 100% 匹配，口型同步。
3. 台词逐字照原文，不许概括、改写、增删（口语化微调可以，但要在台词留痕里记）。
4. 对白与音效要参照附件4、附件5 设计，不许自创体系。

## 二、语速与配平

| 项 | 值 |
|---|---|
| 语速 | **2.25 字/秒**（允许 2.0–2.5） |
| 计算 | 台词字数 ÷ 2.25 = 语音秒数 |
| 组台词量 | 5–12 秒（2.5 长序列可放宽） |
| 单句组 | 低于 5 秒允许，但必须注明「单句组」 |
| 留白 | 组末 ≥0.5 秒，标【留白】＋时长 |
| 静音 | 需要时标【静音】＋时长 |

验算例：`这件事，我会查到底。` = 10 字（含标点不计，按 9 字算）→ 9 ÷ 2.25 = 4.0 秒；若组时长 6 秒，剩 2 秒可放反应镜与留白。

**配平不上的处理顺序**：① 拆组；② 把对白挪到原本无对白的组；③ 口语化压缩（不改信息）；④ 延长组时长（不超模型上限）。**不许加快语速硬塞**。

## 三、对白标注格式

```
苏英（语气平静清冷，语速平缓）：这件事，我会查到底。
```
- 必带：角色名＋情绪基调＋语速。
- 独白：`【内心独白】苏英（声音冷静无波，像陈述案情报告，语速均匀）：……`
- 画外音：`（画外音）`；电话/广播注明介质。
- 无对白的组写「本组无对白」，不要留空。

### 内心 OS（产线沉淀）
只写三件事：**身体感受／当下决定／说不出口的刻薄话**。不做心理分析，不做主题总结。
反例：`她要的不是座。她要我认错。`（替观众下结论）
正例：`腿有点抖。`／`这站我不让。`／`装什么装。`

## 四、音效标注

必须带**触发时间点**，并与画面动作同步：

```
0秒 瓷器炸裂巨响；3.2秒 茶水滴落地面；5.8秒 椅子腿刮地（-12dB）
```

- 环境音写底噪：空调送风、车厢引擎、远处报站。
- 拟音写动作对应：衣料摩擦、脚步、拉链、膝盖响。
- 音量可用 dB 或「极低/低/中/高」，跨组保持一致口径。

## 五、分层音效（四层，必须与音频字段完全对应）

| 层 | 写什么 | 例 |
|---|---|---|
| 人声层 | 人物、情绪、语速、音量、空间感、有无混响 | 苏英对白干声，清冷坚定，音量适中，无混响，贴耳感强 |
| 核心音效层 | 剧情核心冲突音效：类型、触发时间、音量、质感 | 0秒 紫砂壶砸地炸裂，音量拉满，质感厚重真实，无杂音 |
| 环境细节层 | 场景底噪：类型、音量、空间感 | 办公区中央空调送风底噪、键盘细碎声，音量极低 |
| 空间混响层 | 混响参数 | 密闭办公室小空间混响；大厅自然混响；人声保持清晰 |

四层内容不得新增、修改音频字段里没有的声音；反过来音频字段也不许出现分层里没有的核心音效。

## 六、留白与节奏

- 组末留白 ≥0.5 秒：`【留白】11.8—12.3 共0.5秒`。
- 情绪需要时用【静音】制造张力（如耳光前 0.3 秒全静）。
- 反应镜头的画外音要写清「对白继续、画面切听者」。

## 八、自检

- [ ] 无 BGM/配乐/歌曲
- [ ] 台词量 5–12 秒（或已注明单句组）
- [ ] 字数 ÷ 2.25 ≤ 组时长 − 留白
- [ ] 每句带角色＋情绪＋语速
- [ ] 独白有【内心独白】标识
- [ ] 音效带触发时间点，与动作同步
- [ ] 四层齐全，与音频字段一一对应
- [ ] 组末留白 ≥0.5 秒并标注
