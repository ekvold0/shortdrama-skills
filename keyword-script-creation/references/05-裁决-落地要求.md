# 落地要求 · 裁决层（最高优先级）

> 读法：本文件与其他 references 冲突时，**以本文件为准**；本文件与规范原文冲突时，按第三节「裁决表」执行，并在自检记录的「依据」栏写明用了哪条裁决。
> 来源：《AI短剧脚本生成要求_标准版》第一部分 23 条 + 三份关键词规范 + 产线沉淀。

## 一、七条不可协商

1. **两份输入都要读**：剧本文档 + 分镜头脚本文档。只给一份 → 停，先要另一份，不凭记忆补。
2. **十字段齐全、顺序固定、每组自包含**：禁止「同上／同前／同左／见锚点卡」。每组都是独立生成单元。
3. **组时长 4–15 秒且必须为整数秒**（用户实际生成时只能设整数时长）；横屏 2.5 模型可到 30 秒并标【2.5模型】；**竖屏禁用 2.5**，锁 4–15 秒。
4. **同组不跨场景；全硬切；无 BGM；所有文字（字幕/UI/标牌）后期叠加，AI 不生成可读文字。**
5. **全覆盖**：原文每一句话、每个动作、每个环境变化、每个心理活动（外化后）都要有落点，不挑重点。
6. **引用带原文**：附件6 全文内联（定义/AI执行/叙事功能/适用场景/代表作品＋本组取用）；附件3/4/5 内联「条名＋用到的参数」。只写条号 = 不合格。
7. **双轨自检通过才交付**：三次循环自检填满 ＋ `verify.py` 零 error。

## 三、九条冲突裁决（已定稿，不再逐次讨论）

| # | 冲突 | 裁决 | 理由 |
|---|---|---|---|
| 1 | 语速：规范 1–2 字/秒 vs 产线 2.5–3.2 字/秒 | **默认 2.25 字/秒，允许 2.0–2.5**；自检注明取值 | 取两区间中间值；既不违规范精神，也贴合短剧实际语速 |
| 2 | 全片时长：标准版「≤3 分钟」vs 短篇「600–900 秒」 | 按模式：**竖屏/横屏短剧单集 ≤3 分钟；短篇全片 600–900 秒** | 两条管的是不同片型 |
| 3 | 2.5 模型：横屏 V1.5 支持 ≤30 秒；竖屏 V2.5 无 | **竖屏永久禁用 2.5**；横屏按情节启用并标注 | 竖屏规范未开放，超 15 秒即违规 |
| 4 | 自检强度：横屏要三表+报告；竖屏只勾选 | **统一用强版本**（三表＋过程报告） | 交付留痕更完整，不增加实质工作量 |
| 5 | 附件3 第十节标「5条」实为 9 条；V1.5 表1 有重复行 | 以实际条目为准：**附件3 共 90 条**；自检表按本技能 11 项版 | 以库为准，不以标题数字为准 |
| 6 | 正文写「参考电影列表见附录」，三份规范均无附录 | 用 `40-画面参数.md` 第五节片单 | 缺附录，必须补一个可执行的 |
| 7 | 组时长精度：模板「0.5 秒」vs 实际 12.3 秒 | **统一 0.1 秒**；0.5 秒只作为编排建议 | 与提示词时间段精度一致，账目才闭合 |
| 8 | 模板纵向「一组一块」vs 产线横向「一行一组」 | **交付用横向一行一组**（10 列），需要时另附纵向详情页 | 导入与筛选更顺，与你现有成品一致 |
| 9 | 旧分镜无「单元」列 | `ingest.py` 自动切组：同场景＋4–15 秒＋一个核心事件，并标「待确认」 | 兼容两代分镜文件 |

补充：**单句组低于 5 秒台词量是允许的**，但必须在音频字段与自检里注明「单句组，低于 5 秒常规区间」。

## 四、产线沉淀（吸收为通用默认）

1. **单一数据源**：一份 `kwdata.json` 同时派生微观分镜、正向提示词、音频、风格细节、自检。改一处，全表跟着变。
2. **引用必须带原文**：条号不存在 → `refs.py` 直接报错，不允许降级成纯文字、不允许猜。
3. **呼吸派生**（情绪标签 → 每分钟呼吸次数），无脸镜头不写呼吸（用 `shots[].breath=0` 覆盖）：

| 情绪标签含 | 每分钟 |
|---|---|
| 忍、沉、沉默、冷、疲、麻、不说、压着、憋 | 12 |
| 慌、急、噎、窘、惊、懵、愣、求 | 20 |
| 骂、逼、拔、追、封、定、施、催、命令、羞、恼、气 | 19 |
| 顶、接、让、指、答、问、认、看 | 16 |
| 其余 | 15 |

4. **内心 OS 三件事**：只写「身体感受／当下决定／说不出口的刻薄话」，**不做心理分析、不做主题总结**。
   反例：「她要的不是座。她要我认错。」——这是替观众下结论。
5. **语言烈度阶梯**（项目可覆盖，缺省不用）：L1 试探→L2 绑架→L3 围攻→L4 反噬→L5 崩塌；每一级的还手比上一级更短、更冷。
6. **交付前 10 项自检**（已并入 `verify.py`）：镜号连续／总时长一致／每组 2–6 镜／提示词从 0 排到组末／固定参数复写／引用带原文／有台词者出镜／空间自洽／反向五段／无半角°与错列。

## 五、返工重灾区（动笔前扫一眼）

| 症状 | 纠正 |
|---|---|
| 只闻其声：有台词但人在画外 | 补出镜镜，或标明确设定（电话/广播/主观） |
| 串座串手：越肩方向反了、道具换手 | 回查空间坐标，逐条核五者自洽 |
| 大头贴干说：3 秒以上单人正脸念台词 | 插反应镜＋画外音＋切回「正在说」 |
| 单元塞满：一组跨两个场景 | 按场景边界重切 |
| 全员同框：群像堆在一个镜头 | 拆多分镜＋独立反应镜 |
| 空镜凑时长：无信息画面填时间 | 换细节镜/道具镜，必须带信息 |
| 情绪全克制：全片没有一次打中的峰值 | 高潮补一次峰值表情 |
| 账目对不上：镜头加总 ≠ 组时长 | 回 `70` 重算，不要改数字凑 |
| 同上/同前 | 逐组复写锚点 |
| 术语矛盾：「长焦推 0.6 米」「航拍小幅升降」 | 换摇臂/变焦，量级匹配 |
| 裸条号引用 | `refs.py expand` 重写 |

## 六、交付前终校

**机器**：`python scripts/verify.py <kwdata.json>` 零 error（warning 可留，但要在交付说明里列明）。
**人工四问**：
1. 这句台词像不像这个人物在这种情况下会说的话？
2. 这个空间里，人站得住、手伸得到、视线对得上吗？
3. 每个镜头有没有新信息（动作/情绪/关系/环境）？删掉会不会损失？
4. 观众看到第 3 秒、第 30 秒、结尾，会不会划走？
