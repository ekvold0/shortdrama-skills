# 运镜库 · 26 种运动怎么落成参数

> 用途：写「画面参数·运镜」（九项第 5 项）和「镜头语言」时，从这里取样，不要现编。
> 来源：higgsfield-skills `01-cinematic/references/camera.md` 的运镜百科（22 条）＋本技能 40 §三 既有口径，合并去重、换算公制、按 CT03 运动轴重排。
> **三条纪律先看**：① 英文名只作检索别名，抄进正向提示词即触发 **CT07**；② 一镜只有一个主运镜（CT03），下表「家族词」相同的两条不能同镜；③ 四要素缺一即未改写——方向、幅度、速度、轨迹。
> **机器拦到哪**：**CT09** 只查「有没有运动轴或『固定』」（error）和「有没有米/度/秒」（warning），**CT12** 查英制单位；「这个运镜配不配这场戏」机器不判，走 90 的自检。

## §1 四要素与十个运动轴

| 家族词（CT03 认这个字） | 含义 | 同族不能叠加的写法 |
|---|---|---|
| 推 / 推进 / 前推 | 沿轴向前接近主体 | 推近＋前推＋推进 |

> 省略写法「推镜头／拉镜头／摇镜头／移镜头／跟镜头」机器也认（CT09/CT03 都算轴），但参数里仍建议写成「推近 0.3 米」这种带量的形式——省写的只是名字，量还得给。
| 拉 / 后拉 / 拉远 | 沿轴向后远离主体 | 后拉＋拉远 |
| 摇 / 横摇 / 纵摇 | 机身原地转动 | 横摇＋上摇＋摇镜 |
| 移 / 横移 / 平移 | 机身横向平移 | 横移＋平移 |
| 跟 / 跟拍 | 与主体同步位移 | 跟拍＋跟随 |
| 升降 / 摇臂 | 机身垂直升降 | 上升＋下降 |
| 环绕 / 旋转 | 绕主体公转 | 环绕＋旋转 |
| 甩 / 甩镜 | 极速摇，带运动模糊 | 甩镜＋横摇（甩本身就是摇的超速版，同镜只能留一个） |
| 变焦 | 焦段变化，机身不动 | 变焦＋推近（除非写明是「推轨变焦」复合，见 §4） |
| 俯仰 | 只改俯仰角不位移 | 俯仰＋升降 |

**写死**：跨家族 ≥2 即 CT03。要两个运动，拆两镜，或用 §4 的复合写法并说明「一条主技法＋一条辅技法」。

## §2 26 条运镜总表

| 2 | 后拉揭示 | 拉 | 沿轴向后拉 3.0m，匀速，用时 3.0 秒，起幅近景→止幅全景，轨迹水平不抬升 | 1–4s | 全 | 后拉时主体必须留在画内，写清「主体始终占画面高 45%」 |
| 3 | 横移平移 | 横移 | 机身向右横移 2.5m，匀速 0.8m/秒，用时 3.0 秒，主体保持画面右侧 1/3，前景视差大于后景 | 2–4s | 横屏优先 | 竖屏横向信息被裁，改「前推＋浅景深」 |

| 5 | 纵摇揭示 | 纵摇 | 机身原地纵摇，自脚部摇至面部，仰角由 -10 度到 +5 度，用时 2.0 秒，末端减速停稳 | 1–3s | 全 | 竖屏友好，纵向信息量正是竖屏强项 |

## §3 竖屏改写速查（9:16 装不下的怎么救）

| 原写法 | 竖屏冲突 | 改法 |
|---|---|---|
| 横移长镜、航拍大远景 | 宽度被裁，宏大感丢失 | 改「前推穿层」或「纵摇揭示」，用纵深换广度 |
| 270 度大环绕 | 环形半径小于 2m 时背景穿帮 | 缩到 60–90 度，或改「半环绕＋前推」两镜 |
| 升镜 | 竖屏顶部空间少，升起后主体出框 | 改「降镜」，自上而下接近更稳 |
| 甩镜 | 落点信息易丢 | 垂直甩 60 度，或 0.15 秒纯过渡 |
| 多人同框横排 | 每人宽不足 30% | 拆正反打，一人一镜 |

> 规则出处：`45-技法到参数.md` §5.2。本表只补运镜侧的落地值。

## §4 组合模板（序列组级，不是单镜）

一个 8–12 秒的组，运镜要成句，不要三个镜头各来一下。

**模板 A · 施压逼近（对峙/审问/打脸前）**
```
镜1 固定（2.0秒，全景，交代两人距离与站位）
镜2 前推 0.8m／3.0秒（中景→近景，逼近者越轴不可越，机位固定在轴线一侧）
镜3 移焦 0.8m→4.0m／0.6秒（从被逼者的手切到他身后退无可退的墙）
```
**模板 B · 空间揭穿（反转/真相）**
```
镜1 前推穿层 1.5m／2.0秒（前景遮挡物出画，露出后景第三人）
镜2 后拉 2.0m／2.5秒（把原本以为的独处拉成有人围观）
```
**模板 C · 情绪悬停（虐心/告别）**
```
镜1 环绕 60 度／4.0秒（半径 1.5m，主体居中，背景虚化）
镜2 固定（2.5秒，微表情特写，机位零运动，只留呼吸）
```

## §5 自检

- [ ] 本镜只命中一个家族词（`_move_families` 只报 1 个）
- [ ] 四要素齐全：方向有方位、幅度有米/度、速度有秒或 m/s、轨迹有直线/弧线/手持
- [ ] 正向提示词里 0 个英文技法名（CT07）
- [ ] 运动幅度与时长匹配：0.5 秒走 3 米 = 6m/s，模型做不出来
- [ ] 竖屏镜头已按 §3 改写，未硬套横屏写法
- [ ] 下一镜的起幅与本镜止幅的构图能接上（衔接备注里写清）

## 六、一集别只用一种轴（CT14）

单镜一轴是底线（CT03），但**整集只有一种轴同样不合格**——十二组全是「缓慢推近」，观众第二组就麻木了。

- 一集里 `movement` 用到的运动轴**不少于 4 种**（十个轴见 §二）。`CT14` 低于 4 种报 warning。
- 全集留**一个招牌镜**：一次尺度的揭示、一次性走完的长镜、或只有这个题材才成立的手法。写进该镜 `note`：「本集招牌镜」。
- 招牌镜放在情绪最高点，不要放开场（开场有钩子，见 `48`）；一集一个，不贪多。
- 轴的数量够了还要看**分布**：别把四种轴全塞在前三组，后半集只剩固定。
