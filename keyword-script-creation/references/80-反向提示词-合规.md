# 反向提示词（字段 10）· 合规

> 反向提示词只针对**画面**，不涉及声音。结构五段固定，顺序不可变，内容必须按本组剧情动态调整。

## 一、五段结构

```
【基础禁用项】…
【画面质量禁用项】…
【人物畸变禁用项】…
【场景穿帮禁用项】…
【剧情不符禁用项】…
```

## 二、必填内容（照抄，不许删项）

**基础禁用项**
> 模糊、变形、多余手指、手指扭曲、手指粘连、文字、水印、低质量、画面闪烁、人物不一致、塑料质感、伪影、摩尔纹、过曝、死黑、字幕、logo、二维码、台标、片头片尾

**画面质量禁用项**
> 油画感、塑料质感、3D模型感、AI绘画感、卡通风格、二次元、模糊、失焦、过曝、死黑、噪点溢出、画面抖动、穿帮镜头

**人物畸变禁用项**
> 面部变形、五官错乱、手指畸形、多手指、少手指、肢体穿帮、人物变脸、体态畸形、妆容不符、着装不符

**场景穿帮禁用项（画幅项按模式写死）**
- 竖屏：`场景错乱、道具不符、时空穿帮、光影混乱、画幅错误、非竖屏9:16、横屏画幅、转场特效`
- 横屏：`场景错乱、道具不符、时空穿帮、光影混乱、画幅错误、非横屏4:3、竖屏画幅、16:9、转场特效`

**剧情不符禁用项（逐组改写，最能体现用心）**
根据本组剧情写「本组不该出现什么」：
```
苏英微笑、苏英转身离开、张德功夫妇平静对视、茶杯完好、办公室灯全亮
```

## 三、动态调整三原则

1. 基础/质量/畸变三段可以固定，但**剧情不符段每组必须不同**。
2. 禁用项要与本组正向提示词里的主体、动作、道具对应（正向写「握拳」，反向就禁「手部松弛」）。
3. 画幅禁用项必须与成片画幅一致，写错等于没写。

## 四、合规

- 敏感内容：正向做合规化（换表达、换景别、避开直接展示），反向明确禁用违规内容。
- 平台红线：暴力血腥、色情低俗、违法违规、侮辱性标签、地域/性别/年龄歧视、封建迷信。
- 文字：字幕、时间卡、屏幕 UI、标牌一律**后期叠加**；AI 只生成窗口/色块/框架，不生成可读文字（反向已禁「文字、字幕」）。
- 不写可能被判定为「教程/示范」的危险动作细节。

## 五、版本管理

每组交付时带版本行：`V1.0｜2026-10-26｜依据竖屏V2.5｜修改人：…`。
改稿后编号保持连续，不得因增删组导致重号；改动内容写进《修改前后对比摘要》。

## 六、自检

- [ ] 五段齐全、顺序对
- [ ] 基础/质量/畸变三段含全部必填项
- [ ] 画幅禁用项与模式一致
- [ ] 剧情不符项逐组不同、针对本组
- [ ] 未把声音类禁用项写进反向（反向只管画面）
- [ ] 无平台违规内容
