# 微观分镜（字段 6）· 转场 · 切镜

> 一个序列组内的镜头清单。它是正向提示词的时间骨架，也是分镜脚本到关键词脚本的接缝。

## 一、硬指标

| 项 | 要求 |
|---|---|
| 单组镜数 | 2–6 个（横屏 2.5 长序列可到 8） |
| 单镜时长 | 舒缓 3–6 秒；强冲突 1–3 秒 |
| 无意义长镜 | 禁超 8 秒（2.5 模型长镜头须有连贯调度或完整情绪支撑） |
| 转场 | 全部硬切，禁任何转场特效 |
| 对白 >3.0 秒 | 必须插反应镜头或空镜 |
| 情绪点 | 每 3–5 个分镜一个情绪/冲突/反转点 |
| 衔接 | 分镜之间必须有衔接备注（位置、动作、道具状态） |

## 二、每个分镜必须写全

```
镜号｜景别｜时长（起—止）｜机位与运镜｜画面主体与动作｜情绪·微表情
```

- **景别**：ELS/LS/FS/MS/MCU/CU/ECU，或中文对照；禁自造。
- **机位与运镜**：角度＋高度＋距离＋焦段＋光圈＋景深＋运镜（物理化）。
- **画面主体与动作**：谁＋在哪＋做什么；动作按七要素写。
- **情绪·微表情**：肌肉参数＋呼吸；不许写「愤怒」。
- **衔接备注**：本组结尾与下一组的视觉接点（位置/姿态/道具/光位）。

## 三、四种情节的优化策略

### 1. 强冲突（悬疑/惊悚/警匪/谍战）
- 镜数在上限附近（比常规多 30%–50%），单镜压到 1–3 秒；
- 硬切、跳切、特写堆叠、交叉剪辑；
- 倾斜构图、极端明暗、手持晃动；
- 对标《无间道》《搏击俱乐部》《记忆碎片》的节奏与悬念。

### 2. 舒缓抒情（剧情/爱情/文艺）
- 单镜 3–6 秒，长镜、跟拍、环绕；
- 推拉摇移升降甩综合运用（横屏用横移摇移，竖屏用推拉纵摇）；
- 景深、光影层次、质感细节承担情绪；
- 对标《小偷家族》《地久天长》《重庆森林》《苏州河》。

### 3. 多人物可拆分
- 增加镜数，按叙事顺序逐个聚焦；
- 每镜 1–2 个核心人物，抓微表情、手部、肢体；
- 统一光影基调保持连贯；正反打/过肩强化互动；
- 横屏可用双人中景同框表现距离与张力。

### 4. 多人物群像同框
- 前后景分层、高低差站位、动态动线；
- 横移/环绕/升降覆盖全场景；
- 焦点转换引导视线，兼顾整体氛围与个体动作；
- 统一色彩与光影，防止拼贴感。

## 四、全覆盖与反应镜头

1. **全覆盖**：不许只挑重要事件。原文每句话、每个动作、每个环境变化、每个心理活动（外化）都要有镜头。
2. **反应镜头**：一句对白超 3.0 秒，插入听者反应或空镜；必须写清「对白画外音」和「切回说话人」的衔接。
3. **动作戏**：至少一种复杂运镜并物理化描述。
4. **多主体**：每个主体至少一种动态，非聚焦主体微动态写进画面备注。
5. **特殊叙事**（闪回/梦境/内心独白/多人对白/天气突变/换装/外貌变化）按特殊规则处理，写清视觉区分与衔接。

## 五、切镜参考（附件6）

分镜不能只对标电影。按段落类型选参考：

| 段落 | 优先参考 | 取用 |
|---|---|---|
| 强冲突/悬疑/打脸/群像/职业 | 网剧 | `refs.py list edit` 第一节 |
| 对话/长镜/心理/多机位 | 电视剧 | 第二节 |
| 战斗/高速运动/心理外化/风格化构图 | 动漫 | 第三节 |
| 动作匹配/声音桥接/平行剪辑/节奏曲线 | 通用 | 第四节 |

引用必须内联原文（`refs.py expand`），不许只写条号。

## 六、景别梯度（第三次专项自检用）

合格梯度（相邻镜头不能原地踏步）：
```
特写 → 中景 → 远景
近景 → 中远景 → 全景
全景 → 中景 → 特写
远景 → 近景 → 微距特写
```
再对照运镜：景别变化要服务叙事重心转移与情绪递进，不是为变而变。横屏额外查全景/中远景是否用足宽幅；竖屏额外查主体是否出安全区。

## 七、三次专项自检（写完微观分镜立刻做）

1. **内容污染**：有没有瞬移、违反重力、肢体扭曲、不合生理的动作？有则改。
2. **数量与情节匹配**：镜数够不够撑起这段情节？不够就重生成；够则按四种策略二次优化。
3. **景别逻辑**：按上面的梯度检查；横屏查宽幅利用，竖屏查安全区。

## 八、衔接备注怎么写

```
衔接备注：结尾苏英面向镜头、右手仍扶窗框，下一组承接正面近景，光位不变（顶光偏左）。
```

必须含：人物位置、姿态/动作状态、道具状态、光位/色调、下一组从哪接。

## 九、微观分镜自检

- [ ] 2–6 镜（2.5 ≤8），单镜 1–6 秒，无 >8 秒无意义长镜
- [ ] 每镜有景别/机位/时长/动作/情绪
- [ ] 每镜有微表情与呼吸
- [ ] 对白 >3 秒处有反应镜或空镜
- [ ] 每 3–5 镜有情绪/冲突点
- [ ] 分镜顺序与分镜脚本/剧本一致
- [ ] 有衔接备注
- [ ] 无任何转场特效词
