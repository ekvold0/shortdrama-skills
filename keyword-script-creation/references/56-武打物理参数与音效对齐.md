# 武打物理参数与音效对齐（关键词层）

> 承接分镜层 `storyboard-creation/references/53-武打动作组.md`：那边定**拍法与逻辑**，这里定**数值与声音**。
> 原则：分镜层不写数，关键词层必须写数。写了数的动作才不像摆拍。

---

## 一、六层槽位怎么落进十字段（KW-01 对齐表）

| 六层槽位 | 落进哪个字段 | 必写内容 |
|---|---|---|
| 环境介质 | 场景 / 物理交互 | 雨、水洼、尘、碎屑、瓦片，以及**被击打后的状态** |
| 机位运镜 | 运镜 | 低机位前推、侧向平移、环绕越肩；镜头与人物运动同步 |
| 发力链 | 动作 | 蹬地—拧腰—送肩—贯穿，动作数量与停顿点 |
| 受力反馈 | 动作 / 表演 | 皮肤压陷、肌肉波纹、头部后仰、倒飞抛物线、碎屑方向 |
| 速度感 | 画质 / 运动 | 运动模糊、能量轨迹、残影、甩镜；主体清晰背景流动 |
| 尺度参照 | 场景 | 用参照物写规模（人在巨型石像前小如蚂蚁） |

## 二、慢动作参数（KW-07 核心）

| 项 | 写死值 |
|---|---|
| 击中瞬间 | **1/4–1/5 倍速**（不是 1/2，1/2 只是"看着慢"） |
| 恢复 | 随即回常速，同一镜内完成 |
| 快门 | 高速快门凝固液体与碎屑（雨滴/水花/碎屑呈颗粒状、边缘实） |
| 升格次数 | **一个打斗组只升格一次**（CT19 抓 ≥2 次） |
| 单组倍速 | 只一种，不混（多种倍速留给剪辑） |

可直接抄的写法：

```
命中瞬间降为 1/4 倍速，拳面与面颊接触处皮肤压陷、颧侧肌肉纹起；
水花呈清晰颗粒向远离拳头的方向甩出，随即恢复常速，人物重心继续前压。
```

反面写法（会被判塑料）：

```
慢动作打斗，水花四溅，很燃。
```
——没有倍速、没有接触点、没有方向，模型只能给你一段糊的。

## 三、受力反馈参数化（KW-07）

按"被击部位 → 形变 → 位移 → 后续"四段写，每段≤12 字：

| 部位 | 形变 | 位移 | 后续 |
|---|---|---|---|
| 面颊 | 皮肤压陷、颊侧起纹 | 头向后侧甩 15–25° | 发丝滞后甩出、唾液或汗珠飞散 |
| 胸腹 | 肌肉波纹一圈扩散 | 上身折叠、双脚离地 | 背部先撞介质（墙/桌），再落 |
| 肩背 | 肩胛内收 | 身体横移半步、转轴 | 手抓住家具止住、家具位移 |
| 腿部 | 支撑腿膝弯 | 单膝跪地 | 地面尘环扩散、裤料褶皱堆叠 |

倒飞要写抛物线：`离地 → 最高点 → 落地`，并指定落点介质（撞的是茶几还是门框）。

## 四、速度感与尺度（KW-07）

- **运动模糊**：主体清晰、背景流动；快速挥击处出现 2–3 层残影，方向与拳路一致。
- **能量轨迹**：只在受击帧出现，形状沿动作方向拉长，**不常驻**。
- **尺度参照**：用自然语言给参照物，不写"巨大"两个字。例：`她的身高只到石像脚踝，石像的一只脚压住整条街`。

## 五、音效四层与接触点对齐（KW-08）

四层沿用（`references/70-音频对白-分层音效.md`）：人声 / 核心音效 / 环境细节 / 空间混响。

对齐纪律（这是本条的全部要害）：

| 纪律 | 具体 |
|---|---|
| 严格对齐接触点 | 打击音效必须与**发力链接触的那一帧**同帧起，不提前、不滞后 |
| 音先于画？不许 | 影视里可"提前半帧"做冲击感，**AI 生成里一律不许**——模型会把声音当画面指令，出现动作与声音错位 |
| 介质音效 | 水花、碎裂、布料、脚步，与画面交互一致（踩水才有水声，落地才有尘响） |
| 混响 | 空间大小决定尾巴长度（大厅长、走廊短），同一场景不变 |

写法模板：

```
音效：拳面接触面颊的一刻起闷响（与命中帧同帧），随后是布料摩擦与后脚擦地；
水花声紧随倒地方向；环境底噪为雨声与远处车流，大厅混响尾巴约 1.2 秒。
```

## 六、自检（提交前逐组过）

- [ ] 每个打斗组有环境介质，且写了被击后的状态
- [ ] 命中瞬间写了 1/4–1/5 倍速 + 回常速
- [ ] 受力反馈四段齐全（形变/位移/后续/介质）
- [ ] 有运动模糊或残影，主体清晰
- [ ] 尺度参照用了参照物，不是形容词
- [ ] 单组只升格一次、只一种倍速（CT19）
- [ ] 打击音效与命中帧同帧，不提前不滞后
- [ ] 介质音效与画面动作一致
- [ ] 混响尾巴在同场景内不变

---

## 七、与机器的分工

- CT19 能抓：缺受力反馈词、缺重心恢复词、单组升格 ≥2 次。
- 抓不到的（只能人看）：倍速写得对不对、接触点是否真的同帧、水花方向与出拳方向是否一致。
- 因此**参数审查 + 音画核对**这两项人评不能省（需求文档 KW-07/KW-08 的验收口径）。
