# 三次循环自检 · 自检清单与报告

> 规范原文：未完成三次自检及自检过程报告的脚本视为无效脚本。
> 本文件提供可直接填的三张表＋一张报告；`verify.py` 能机器查的，已在括号里标了检查码。

## 使用方式

1. 写完全部序列组 → 按表 1→表 2→表 3 顺序逐条过，**不许跳、不许合并**。
2. 每条填：通过/不通过 ＋ 发现问题 ＋ 修改措施。发现问题必须写清「哪组、哪字段、改前→改后」。
3. 汇总进表 4《自检过程报告》，随 Excel 一起交付（`build_xlsx.py` 会生成一张「三次循环自检」sheet）。

## 微观分镜三次专项自检（写完分镜立即做）

1. **内容污染**：瞬移、违反重力、肢体扭曲、不合生理 → 改。
2. **数量与情节匹配**：镜数撑不撑得起这段？不够重做，够则按四策略优化。
3. **景别逻辑**：按 `60` 第六节梯度查；横屏查宽幅利用，竖屏查安全区。

## 机器校验怎么跑

```bash
python scripts/verify.py work/《剧名》_S03_kwdata.json --strict
```

- `error` 必须清零才可交付；
- `warning` 可以留，但要在交付说明里逐条列出理由（例如「单句组 2.0 秒，低于 5 秒」）。

## 人工终检四问

1. 这句台词像不像这个人物在这种情况下会说的话？
2. 这个空间里，人站得住、手伸得到、视线对得上吗？
3. 每个镜头有没有新信息？删掉会不会损失？
4. 第 3 秒、第 30 秒、结尾，观众会不会划走？
