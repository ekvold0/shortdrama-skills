# 正向提示词（字段 4）· 一体化视频提示词

> 一个序列组 = 一条时间轴。按 0.1 秒切段，每段 7 个字段，顺序固定，缺一不可。
> 时间轴从 `0.0` 排到组末，最后一段结束时间 **必须等于** 组时长。

## 一、每段的固定格式

```
X.X—X.X秒：画面主体：…；动作物理化拆解：…；情绪物理化拆解：…；镜头语言：…；对白/旁白：…；音效：…；画面备注：…。
```

| 字段 | 必须写什么 | 禁止 |
|---|---|---|
| 画面主体 | 谁＋在哪＋做什么＋站位与空间关系；多主体逐个列 | 「两人在争吵」 |
| 动作物理化 | 部位＋方向＋幅度＋速度＋发力＋结束姿势＋伴随运动；**含呼吸状态** | 「激动地挥手」 |
| 情绪物理化 | 肌肉名＋收缩/放松＋移动距离＋方向＋速度；**每段都要有微表情** | 「愤怒」「悲伤」 |
| 镜头语言 | 景别/机位/视角/运镜/焦距/景深，运镜要物理化 | 「特写（有张力）」 |
| 对白/旁白 | `角色（情绪，语速）：原文`，一字不差；无对白写「无」；画外音标注 | 概括、改写、省略 |
| 音效 | 环境音/拟音/音乐性音效，带时间点，与动作同步 | 「环境音」三个字打发 |
| 画面备注 | 道具/特效/动线衔接/转场；反应镜插入点；非聚焦主体微动态 | 空着 |

## 二、时间段怎么切

1. 段数 1–15；总时长 8–15 秒为基准（目标 10 秒），2.0 模型 4–15，2.5 ≤30。
2. 一段只承载一个动作节拍或一句对白；对白长就拆段，不堆。
3. 每段都必须是「可拍的一口气」，不能一段写三个动作。
4. 时间段必须覆盖本组引用的全部原文：每句话、每个动作、每个环境变化、每个心理活动（外化）。
5. 首尾相接，不许跳秒、不许重叠；最后一段结束 = 组时长。

## 三、动作物理化七要素

```
部位（右手/左肩/颈部/腰部）＋方向（向上/向左后/顺时针）
＋幅度（抬45度/转15度）＋速度（缓慢/快速/匀速/加速）
＋发力（猛然/轻柔/颤抖着）＋结束姿势（停在半空/收回到胸前）
＋伴随运动（转身带衣摆、握拳时小臂绷紧）
```

每段还要写**呼吸**：呼吸急促／屏住呼吸／均匀呼吸／呼吸变浅。无脸镜头可标 `breath=0` 不写。

## 四、情绪物理化

优先调用附件3 的量化参数（角度、百分比、时长、消退方式），不要自创模糊值：

```bash
python lib/refs.py get face 1        # 真实微笑
python lib/refs.py get face 11       # 微愤怒
python lib/refs.py search face 咬肌
```

写法：
- 肌肉：皱眉肌／咬肌／眼轮匝肌／颧大肌／降口角肌／额肌／鼻肌。
- 动作：收缩/放松、上提/下压、内收/外扩。
- 量：角度、毫米、百分比、持续秒数、回落曲线。
- 递进：靠参数的逐段变化表现，不靠贴情绪标签。

合格：`皱眉肌收缩约2毫米，眼裂收窄20%，咬肌绷紧、下颌略前送，持续1.2秒后缓慢回落，呼吸变浅至每分钟19次`
不合格：`她显得很生气`

## 五、复杂运镜

- 必须物理化：`镜头以角色为中心极慢速环绕约120度，角色跃起瞬间凝固，衣摆与发丝缓慢飘动，背景水滴悬停`。
- 必须给理由：强调力度／表现时间凝固／交代空间。
- 动作戏至少一种复杂运镜，且写清轨迹与速度。
- 竖屏优先推拉、纵摇、跟拍；横屏可用横移、摇移、环绕。

## 六、多主体与非聚焦主体

1. 每个主体都有位置与动态，**禁止任何主体完全静止**。
2. 聚焦主体详写；非聚焦主体简写但非零（转头、肩随呼吸、手指敲桌）。
3. 画面备注里点名非聚焦主体的微动态。
4. 站位用物理方位＋相对关系：`靠车窗一侧`、`过道右侧靠立柱`、`背对车门`；**禁裸「居左/居右」**（机位一翻就错）。

## 七、脑补（强制但有边界）

- 可以补：上下文必然存在的场景细节、道具、微表情、环境动态、非聚焦主体微动。
- 不可以：改剧情、改人设、跳过原文已有细节、为凑时长加无关动作。
- 脑补的音效必须符合物理逻辑。

## 八、AI 生成限定词（每组带）

```
4K超清、写实摄影、无AI畸变、无穿帮、人物面部特征统一、动作自然流畅、横屏4:3画幅（或 竖屏9:16画幅）
```

核心人物的面部特征、着装、造型，**每组重复固定标注**，一字不改，跨组才不变脸。

## 九、呼吸派生表

| 情绪标签含 | 每分钟 |
|---|---|
| 忍、沉、沉默、冷、疲、麻、不说、压着、憋 | 12 |
| 慌、急、噎、窘、惊、懵、愣、求 | 20 |
| 骂、逼、拔、追、封、定、施、催、命令、羞、恼、气 | 19 |
| 顶、接、让、指、答、问、认、看 | 16 |
| 其余 | 15 |

## 十、十条绝对禁止

1. 抽象情绪词（愤怒、悲伤、紧张……）
2. 文学性描写（每句必须可被物理执行）
3. 模糊量词（时间必须 0.1 秒）
4. 缺微表情、缺呼吸、缺镜头物理参数的镜头
5. 遗漏/修改/省略任何对白或旁白
6. 只挑重点事件写，跳过原文细节
7. 主体完全静止
8. 复杂运镜只写名称；动作戏不用复杂运镜
9. 「见前文」「见锚点卡」等引用
10. 分镜间无衔接备注；一句对白超 3 秒不插反应镜/空镜

## 十一、一段合格样例

```
0.0—3.0秒：画面主体：苏英立于办公室左侧窗前，距窗0.4米，身体朝窗外偏右15度，双手自然下垂，画面右侧前景为办公桌一角（虚）；
动作物理化拆解：右手缓慢抬起约15度扶住窗框，小臂发力，肩随呼吸轻微起伏约1.5厘米，重心在右脚，呼吸均匀每分钟15次；
情绪物理化拆解：皱眉肌收缩约1.5毫米，眼轮匝肌轻微收紧、眼裂收窄10%，咬肌微绷，嘴角向下3度，持续2.4秒后缓慢回落；
镜头语言：中景平视固定机位，机位高1.5米、距主体1.8米，定焦 50，f/2.8，浅景深、背景虚化；
对白/旁白：苏英（语气清冷，语速平缓）：这件事，我会查到底。；
音效：0秒空调低频送风，2.1秒键盘细碎敲击（画外）；
画面备注：背景同事低头敲键盘、肩随呼吸起伏（非聚焦微动态）；本段末尾硬切下一镜。
```

- [ ] 台词逐字、带情绪与语速
