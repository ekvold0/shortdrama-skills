# 模式 · 竖屏短剧 9:16

> 只写与 `00-总纲` 不同的部分。竖屏规范为 V2.5。

## 一、参数卡

| 项 | 值 |
|---|---|
| 画幅 | 9:16，1080×1920（全片统一） |
| 模型 | **仅 Seedance 2.0，禁 2.5** |
| 单组时长 | 4–15 秒，整数秒 |
| 组内分镜 | 2–6 个 |
| 单镜时长 | 舒缓 3–6 秒；强冲突 1–3 秒 |
| 全片 | 单集 ≤3 分钟（项目另有约定从其约定） |
| 编号 | `SXX-XZ-001`（无 2.5 标识） |
| 反向画幅项 | 非竖屏 9:16、横屏画幅、16:9 |
| 台词量 | 5–12 秒/组 |

## 二、构图与景别

1. **中心安全区**：核心人物、关键道具、冲突主体必须在画面中心安全区，避开手机状态栏、底部字幕、右侧按钮区。
2. **景别优先**：近景、中近景、特写为主；中景可容单人上半身＋适量环境；全景必须全身完整入画、不被裁切；远景慎用（人物占比过小）；大远景仅用于必要交代。
3. **对话主力机位**：平视近景内反拍、正反打、过肩（对焦人物面部必须清晰）；竖屏正反打是对话核心剪辑逻辑。
4. **仰拍**可强化气势；俯拍强调无助；荷兰角须确保主体不出安全区。

## 三、运镜

- 优先固定机位；推、拉、纵摇、跟拍生成稳定。
- **横移在竖屏受限**，慎用；甩镜头慎用。
- 跟拍要保证人物始终在中心安全区，不能把人甩出画。
- 复杂运镜（环绕、贴地俯冲、子弹时间）只在情绪/动作峰值用，且必须物理化描述。

## 四、钩子

单集开篇首个序列组必须在前 3 秒给冲突/悬念/反常信息；结尾组留悬念或反转。竖屏靠「竖着划走」的留存逻辑，前 3 秒没有钩子等于白拍。

## 五、反向提示词（画幅项写死）

```
【场景穿帮禁用项】…、画幅错误、非竖屏9:16、横屏画幅、转场特效。
```

## 六、竖屏高频错误

| 错误 | 为什么错 | 改法 |
|---|---|---|
| 用 2.5 模型跑 20 秒 | 竖屏规范未开放，超 15 秒即违规 | 拆成两组 |
| 大远景交代城市 | 人物太小，手机上什么都看不见 | 换中景/近景，环境用背景带出 |
| 双人并排中景 | 竖屏放不下，人被裁切 | 拆正反打或过肩 |
| 主体贴边 | 被字幕/按钮挡住 | 移到中心安全区 |
| 横移跟拍长镜头 | 竖屏横向空间不足，易崩 | 改推拉或纵摇 |

## 七、交付前竖屏专项检查

- [ ] 无【2.5模型】标识、无 >15 秒组
- [ ] 每组画面参数含「竖屏9:16（1080×1920）」
- [ ] 反向提示词含「非竖屏9:16」
- [ ] 全景组人物全身入画、无裁切
- [ ] 核心信息在中心安全区
- [ ] 开篇 3 秒有钩子
