## 账目纪律

1. **先排表再写正文**：组数、每场时长、累计先定，再动笔。
2. 全片累计必须落在 **600–900 秒**；各幕占比 20-25 / 50-55 / 20-25。
3. 每写完一场，把「实际时长」回填，重新看累计与差额。
4. 超时/不足只允许：合并组、拆组、调整场次内容；**不许改语速、拖台词、堆空镜**。
5. 终稿必须闭合：总览累计 = 正文逐组合计 = 各组时长之和。

## 八个节点登记（写进「关键节点」列）

开场钩子 → 激励事件 → 第一转折点 → 中点 → 第二转折点 → 危机 → 高潮 → 结局

## 常见失衡

| 症状 | 数值表现 | 处理 |
|---|---|---|
| 第一幕太长 | 建置 >30% | 砍日常，把激励事件提前 |
| 第二幕注水 | 对抗 >60% | 合并重复冲突，砍支线 |
| 第三幕仓促 | 结局 <15% | 给高潮与收束留足组数 |
| 总时长不足 | 累计 <600 | 补事件（不是拉长镜头） |
| 总时长超 | 累计 >900 | 删次要场次、合并同场景组 |
