# 模板 · 交付物清单

## 必交

| # | 文件 | 说明 |
|---|---|---|
| 1 | `{剧名}_S{集}_关键词_v{n}.xlsx` | 主交付；5 个 sheet（短篇才有「全片总览」） |
| 2 | `{剧名}_S{集}_kwdata.json` | 源数据；改一句台词重跑即得新表 |
| 3 | 自检记录 | 在 xlsx 的「三次循环自检」sheet 里，含问题与修改措施 |
| 4 | 待确认项 | 交付说明里列：哪些地方与剧本/分镜有出入、哪些是脑补 |

## Excel 五个 sheet

| sheet | 内容 | 必需 |
|---|---|---|
| 关键词脚本 | 10 列 × N 组（一行一组） | 是 |
| 全片序列组总览 | 幕/场/编号/场景/时长/模型/核心事件/累计 | 短篇是，其余否 |
| 三次循环自检 | 表1+表2+表3+报告 | 是 |
| 梗概与锚点 | 故事/钩子/人物/道具/视觉/空间/账目/引用索引/版本 | 是 |
| 台词时长账目 | 每组字数、语音秒、留白、合计、差值 | 是 |

## 交付前检查

- [ ] `verify.py --strict` 零 error；warning 已在说明里逐条列出
- [ ] Excel 打开无截断、无挤压，行高够，字体统一
- [ ] 编号连续、时长闭合、总时长符合模式
- [ ] 每组十字段齐全，无「同上/同前/同左」
- [ ] 引用全部带原文，条号经 `refs.py` 校验
- [ ] 反向提示词画幅项与成片一致
- [ ] 版本行完整（版本/日期/依据/修改人）
- [ ] 源 JSON 与 Excel 同目录
