# AI 生成单元模板（段落式，禁止表格形态）

> 每个单元一个块，字段顺序固定，不得增删改名。
> 相对基础规范的模板：**新增【画幅】字段**（裁决 8 要求每单元复写，不得假设）。
> 所有"同上/同前/见前文"一律判不合格。

---

```
【幕场坐标】M_-S__ / 单元 U__（本单元在结构中的位置与功能，一句话）
　　　　　　↑ 若属于用户指定的剧情重点，在括号后加【重点①】
【分镜号】M_-S__-__（按幕—场—镜递增，全片连续）
【原文片段】"逐字引用本单元对应的原文全部句子"（跨单元标注"接上单元/续下单元"）
【画幅】__:__ ｜____×____（用户提供的参数，全片统一，每单元复写）
【视觉风格】引用场景卡【视觉风格】＋本单元特殊处理（如色调、质感、光比）
【画面参数·参考电影】《片名》年份（≤1 部，须出自片单库；无出处写"无"，禁写风格描述）
【出场角色】角色 A（姓名，年龄，是否按参考图）、角色 B（姓名）＋重要主体/道具
【时间坐标】上午 / 正午 / 黄昏 / 深夜（依原文）
【年代坐标】如"当代·江南小城"
【日期坐标】如"冬季·老街面馆"
【气候天象】温度-天气-风/雨/雪，尽量量化；室内写室温与光
【时间线与子镜头】
第 X.X–X.X 秒｜景别，角度，机位高度，景深，运镜：画面内容（场景氛围→站位→光影→动作→调度→细节）；站位用物理方位；非聚焦主体微动态。
第 X.X–X.X 秒｜……
【动作物理化拆解】逐时间段写部位+方向+幅度+速度+时长；只写看得见的动作，不写频率数值
【情绪物理化拆解】按 A/B/C 三级写：A 级给部位+方向+时长；B 级给意图+行为+≤1 个骨架参数；C 级只给意图+行为
【本分镜对白】时间段+角色+逐字内容＋语速与情绪基调；无对白写"无"；旁白标【旁白】不生成口型
【本分镜音效】
人声　第 X.X–X.X 秒｜……
核心音效　第 X.X 秒｜……
环境细节　第 X.X–X.X 秒｜……
空间混响　（房间大小与混响感受）
【衔接备注】与上/下单元及跨场的动作、位置、情绪、服化道、光线衔接（场首末单元必填）
```

---

## 每个字段的填写要点

| 字段 | 要点 | 常见错 |
|---|---|---|
| 幕场坐标 | 说明这个单元在结构里干什么（建置/中点/高潮/余韵） | 只写编号，不写功能 |
| 分镜号 | 与表格版一一对应 | 两套编号对不上 |
| 原文片段 | 逐字，不改写；跨单元标注接续 | 只写大意 |
| **画幅** | 每单元复写，来自用户参数 | 漏写或写默认值 |
| 视觉风格 | 引用场景卡，不自由发挥 | 每单元风格漂移 |
| **画面参数·参考电影** | 只填《片名》年份，≤1 部 | 写"参考XX的风格"、挂两三部 |
| 出场角色 | 含主体与道具；标注是否按参考图 | 漏掉关键道具 |
| 时间/年代/日期/气候 | 给 AI 定位时空，越具体越稳 | 写"白天"这种模糊词 |
| 时间线与子镜头 | 每段都有景别＋运镜＋画面＋站位＋微动态 | 只写画面不写机位 |
| 动作拆解 | 部位+方向+幅度+速度+时长 | 写"快速""用力" |
| 情绪拆解 | 标级别；A 级才给参数 | 全片都写微表情 |
| 对白 | 逐字＋语速＋基调；超 3 秒要插反应镜 | 台词写不完硬塞 |
| 音效 | 四层齐全，缺层写"无"并说明 | 只写"环境音：有" |
| 衔接备注 | 写具体连续项（手上有粉、额角有汗） | 写"正常衔接" |

## 填写示例（片段）

```
【幕场坐标】M3-S08 / 单元 U37（高潮段，厨房学做面）
【分镜号】M3-S08-04
【原文片段】"她照着账本上的方子，第三次揉面，额角渗出汗，面团终于在掌心里变得光滑听话。"
【画幅】9:16｜1080×1920
【视觉风格】写实电影感、暖黄灯光、低饱和暖色调、清晨厨房蒸汽质感，浅景深为主
【出场角色】林知夏（26 岁，按角色参考图）、面团（拳头大小，表面由粗糙渐光滑）、木质案板、面粉
【时间坐标】清晨（天刚亮）
【年代坐标】当代·江南小城
【日期坐标】冬季·老街面馆厨房
【气候天象】室外约 3 度干冷；室内灶台余温约 18 度；无风雨，窗玻璃有薄雾
【时间线与子镜头】
第 0.0–6.0 秒｜中近景，斜侧 45 度，机位与案板齐平，中等景深，固定机位：……
【动作物理化拆解】……
【情绪物理化拆解】……
【本分镜对白】无。
【本分镜音效】人声 无。核心音效 …… 环境细节 …… 空间混响 ……
【衔接备注】上接 U36（面团开裂、她蹙眉撒粉）：开场面团仍带裂纹、案板面粉量与 U36 末帧一致……
```
