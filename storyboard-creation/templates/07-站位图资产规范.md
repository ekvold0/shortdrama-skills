# 站位图资产规范（45° 黑白线稿）

> 多人场景生成前的空间锁定资产。它只锁位置：不锁长相、不锁服装、不锁光线。
> 一张图对应一个静止的场面调度；人一动，这张图就作废，必须换新的。

---

## 一、适用前提

| 项 | 规定 |
|---|---|
| 触发条件 | 同一场景内同框 **≥2 人** |
| 适用情形 | 全程无场面调度、不换位的对话 / 对峙 / 群像 |
| 不适用 | 有人起身、走动、换座 → 走第七节「换位条款」，另出图 |
| 产出时点 | 分镜第 4 步锚点环节，与角色卡、场景图同期产出 |
| 消费者 | 分镜表（站位锚点）、关键词层（`refs` 的 `站位图`）、分镜图提示词 |

---

## 二、资产规格（硬约束，逐条核）

| # | 项 | 规定 | 常见违规 |
|---|---|---|---|
| 1 | 画风 | **黑白线稿** | 上色、厚涂、写实渲染 |
| 2 | 视角 | **45° 俯视**——斜俯视，地面平面关系与背景立面同时可读 | 正俯视（模型现在理解不了）、平视、鱼眼 |
| 3 | 人物表现 | 火柴人 / 剪影 | 写实人体、画衣褶、画发型 |
| 4 | 五官 | **不画** | 画眼睛、画脸型、画表情 |
| 5 | 人名标注 | 一人一条引线，线端写人物名 | 无引线；名字堆在角落 |
| 6 | 姓名一致性 | 与角色卡、关键词提示词**完全一致** | 写"男一""公主""白衣女子" |
| 7 | 空间参照 | 门 / 窗 / 主家具 / 通道 **四件套齐全** | 只画人不画参照物 |
| 8 | 与场景图关系 | 构图、景别、机位高度一致，**只允许画风差异** | 换个角度另画一张 |
| 9 | 文件规格 | PNG，短边 ≥1080 | JPG 二次压缩、手机截图 |

### 为什么不能画脸

画了脸，模型会把这张图里的脸一起当参考——黑白线稿上的简易五官，会被它补成一张具体的脸，压过角色卡。同理不能画衣褶、不能画发色：**任何视觉细节都会被当成要求**。站位图只提供位置与朝向。

### 允许的例外

为让人眼分辨不同人物，可以给火柴人不同的**线色或填充**。这类颜色只作辨认标记，不得承载服装色、发色、肤色信息，也不能写进任何提示词。

---

## 三、生成步骤

1. **确认参照物**：先读该场景的场景图与空间座位关系图，把门、窗、主家具、通道的位置定下来。
2. **写提示词**：明确说这是"**站位图 / 座位图**"，45° 俯视、黑白线稿、火柴人、不画五官，并**从左至右逐个讲清每个位置是谁**。
3. **出图**：人物数量、相对距离、朝向、谁在门边谁在窗边，逐项对照分镜写成句。
4. **加引线与人名**：一人一条引线，线端名字与角色卡逐字一致。
5. **比对场景图**：把站位图与场景图并排看，机位高度、墙线走向、家具轮廓必须对得上。

### 提示词骨架

```
一张 45° 俯视的黑白线稿站位图（座位图），不要上色，不要画五官。
场景：{场景名}，参考[图片1]。机位高度与[图片1]一致，视角为斜俯视 45°，
能同时看到地面位置关系与背景墙面。
空间参照标出：门在{方位}、窗在{方位}、主家具是{名称}、通道在{方位}。
从左至右逐个位置：
① {人名A}——{位置描述}，面朝{目标}；
② {人名B}——{位置描述}，面朝{目标}；
③ {人名C}——{位置描述}，面朝{目标}。
人物用火柴人或剪影表示，每人拉一条引线，引线末端写人名。
黑白线稿，无文字叠加，无阴影渲染。
```

## 四、俯视示意（画完对照这张的读法）

```
                 窗（后墙偏左）
        ┌──────────────────────────────┐
        │                              │
        │      ●A ────── ① A           │   ← 引线：一人一条
        │   ▓▓▓▓ 长桌 ▓▓▓▓             │
        │      ●B ────── ② B           │
        │                              │
        │  ●C ────── ③ C               │
        └──────────── 门 ──────────────┘
                      通道
                ▲
        机位在这侧，45° 压下来
```

读法三条：

- **先找四件套**：门窗桌椅认不出 → 这张图不能用。
- **再读引线**：引线指错人、或者两条线交叉 → 重画。
- **最后读朝向**：火柴人的"肩线"朝向必须与分镜里的视线落点一致。

## 五、合格 / 不合格对照

| 情形 | 判定 | 原因 |
|---|---|---|
| 45° 斜俯视、黑白线稿、火柴人、引线齐全 | 合格 | — |
| **正俯视**（垂直向下看平面图） | 不合格 | 模型读不出立面与人体朝向，出片站位照样漂 |
| **画了脸**（有眼睛、有脸型） | 不合格 | 脸会被一起参考进去，压过角色卡，等于换人 |
| **没引线 / 名字靠猜** | 不合格 | 谁是谁无法核对，关键词层引用时必错位 |
| **画了写实人体或服装** | 不合格 | 服装与体型被当要求，与角色卡冲突 |
| **只画人不画门/窗/家具/通道** | 不合格 | 空间无参照，机位一翻全错 |
| **与场景图角度、机位高度不一致** | 不合格 | 站位对得上、构图对不上，分镜图会二次跑偏 |
| **换位了仍用旧图** | 不合格 | 旧图锁的是旧位置，等于没有锚点 |
| **一张图塞两个调度** | 不合格 | 一图一事，混画必冲突 |
| **运动中的人画进图** | 不合格 | 图描述静止姿态，动作用文字写路径 |

## 六、编号、命名与投放

| 项 | 规定 |
|---|---|
| 目录 | `20_资产/站位/` |
| 命名 | `STG-{集号}-{序号}_线稿.png`，例：`STG-S03-01_线稿.png` |
| 序号 | 同场景按调度顺序 01、02、03；换位一次加一号 |
| 版本 | 构图或人物变化即升版，旧图不覆盖，标 `_deprecated` |
| 集号写法 | 与分镜表一致（`S03`） |

### 投放方式

在关键词层作为 `refs` 的一项，正文用 `[图片N]` 引用：

```json
"图片4": {"type": "站位图", "file": "STG-S03-01_线稿.png", "note": "黑白不画脸"}
```

正文点名必须**图 + 文字双写**（只给图模型会漂）：

```
人物站位：见[图片4]，从左至右 A / B / C。
相对位置：A 靠窗坐桌端，B 靠门坐另一桌端，C 站门口朝桌。
```

站位图锁定后，同场景多镜头可**并行抽卡**（FL-03）；跨段仍须串行，等前段记录镜头静帧（SB-02）。

## 七、换位条款

人物发生场面调度（起身、走到别处、换座、进门、离场）时：

| # | 动作 | 要求 |
|---|---|---|
| 1 | 新增一张站位图 | 不许在旧图上改，另出 `STG-S03-02_线稿.png` |
| 2 | 分镜表标注 | 该生成单元备注 `站位图 STG-S03-02` |
| 3 | 路径写进文字 | 站位图只画**静止姿态**；运动过程写成路径句，不画进图 |
| 4 | 旧图降级 | 换位前的镜头继续用旧图；换位后所有镜头必须用新图 |

路径句写在提示词里，形如：

```
A 从桌端起身，沿桌右侧绕行约 1.2 米，停在 B 身侧转向门（2.5 秒）。
—— 这段移位不画进站位图，站位图只给起止两处静止的座位关系。
```

## 八、自检

- [ ] 是 45° 斜俯视，不是正俯视、不是平视
- [ ] 黑白线稿，人物是火柴人/剪影，**没有一个五官**
- [ ] 每人一条引线，引线末端的人名与角色卡、提示词逐字一致
- [ ] 门、窗、主家具、通道四件套都标出来了
- [ ] 机位高度、墙线、家具轮廓与场景图对得上（只差画风）
- [ ] 图中只画静止姿态，运动中的人在文字里写路径
- [ ] 换过位的场景，有对应编号的新图，分镜表已标注
- [ ] 文件名 `STG-{集号}-{序号}_线稿.png`，已登记版本
- [ ] 关键词层已作为 `refs` 的 `站位图` 项，正文配了中文相对位置复述

> 本模板对应需求 SB-01
