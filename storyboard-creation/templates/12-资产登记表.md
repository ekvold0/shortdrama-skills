# 资产登记表（参考图 / 角色资产 / 命名与版本）

> 依据 AS-04（参考图管理规范）+ FL-05（版本与文件管理）。
> 作用：参考图决定成片审美，**没登记的图不许进提示词**；所有资产都要能被"哪个版本、从哪来、能不能商用"三问追到。
> 用法：每集开工先复制本表到该集目录，边做边填；资产统一闸门（闸门四）时逐行核。

**三条标准**（每张参考图逐条打勾，缺一条就换图，不硬修）：

1. 像相机直出的真人照片——有毛孔、有细纹，无精修感。
2. 看头发——真人有碎发、毛躁、暗部发丝发干；又顺又亮像抹发胶的是 AI 图，不要。
3. 正脸、看镜头、表情中性；侧脸大笑的图做参考会"又素又糙"。

另有两条纪律写进表下方备注：

- **至少两张做多图融合**，不用单张；借骨相的那张要挑准（滤镜和妆能洗掉，骨相洗不掉）。
- **身材条款**：锁脸卡通常是胸像，模型看不到身体。凡全身镜头，必须在该组提示词里**单独用文字写身材**（身高/骨架/肩宽/腿型/站姿）——只写脸必出"头在飘"。

## 二、选图纪律（AS-04 操作层）

| 情况 | 做法 |
|---|---|
| 提示词不动，一次出一组 | 组内只换图不换词，才能判断是图的问题 |
| 整组都不对 | 说明图没选好 → 换图重抽，**不硬抽** |
| 只有一张对 | 用那张当"骨相基准"，再补一张气质/服装，重新融合 |
| 已生成 3 组仍不对 | 回到"设计"环节改文字（她是谁），不是继续抽 |

> 硬抽的反面记录也要登记：`硬抽次数` 列，一次都不该有。

## 三、命名规则（FL-05）

```
剧名_S集号_分镜_v版本号    例：《这位置我不让》_S03_分镜_v2.json
剧名_S集号_关键词_v版本号  例：《这位置我不让》_S03_关键词_v2.xlsx
```

资产（按附录 A 目录树，前缀固定）：

| 类型 | 前缀 | 例 |
|---|---|---|
| 场景图（无人） | `SCN-` | `SCN-S03-客厅_v2.png` |
| 站位图（线稿） | `STG-` | `STG-S03-01_线稿_v1.png` |
| 大脸卡 | 角色名 | `A_大脸_v1.png` |
| 服装卡（无头） | 角色名 | `A_服装_v1.png` |
| 背面/后脑图 | 角色名 | `A_背面_v1.png` |
| 道具卡 | `PROP-` | `PROP-旧银钗_v1.png` |
| 色卡 | `COL-` | `COL-S03_v1.json` |
| 分镜图（关键帧） | `KB-` | `KB_S03_U07_v1.png` |
| 记录镜头帧 | `REC-` | `REC_S03-U03_v1.png` |

规则：版本号只加不减（`_v1`→`_v2`），**旧版不删**（返工要能回溯）；同集内 `[图片N]` 编号稳定，跨集可复用同号（同资产）。

## 三·五、跨集角色卡（V2.6）

一部剧的角色是**开剧时一次定完的**，不是一集一集长出来的：

1. **开剧先通读全部剧本**（不是只读第一集），把出场角色一次性定下来，写进 `assets.characters` 全集。
2. 每个角色按**首次出场的形象**出一套三类卡（大脸／无头服装／背面后脑），之后**跨集沿用同一张卡**——不重出、不升版本。
3. 只有剧本**明确写换装或造型变化**（婚服、战损、年龄跨度、囚服、病容…）才升 `v{n}`，新卡在台账写明适用的集数区间。
4. **同一角色换衣服 = 同一角色的新版本**，不是新角色；不许为换装新建一个角色条目。
5. 没写换装的角色，后面每一集都用最初那张卡——这是默认，不需要每集重新确认。

## 五、闸门四（资产统一）自检

- [ ] 每角色三张：大脸 / 无头服装 / 背面后脑，齐全且都登记
- [ ] 每个场景一张无人场景图
- [ ] 每个多人场景一张站位图；换位场景另有第二张
- [ ] 每个场景一张色卡（从该场景图取 HEX）
- [ ] 关键道具（有就）单独一张
- [ ] 参考图全部过三条标准，且每组 ≥2 张
- [ ] 全身镜头有文字身材
- [ ] 所有资产填了版本号与来源；`硬抽次数` 为 0
- [ ] 没有把下游产物（截图、上一代生成图）当新参考图登记
