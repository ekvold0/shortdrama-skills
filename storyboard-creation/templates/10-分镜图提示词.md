# 分镜图（关键帧）提示词模板

> 分镜图 = 图生视频的直接输入，不是预览稿。
> 位置固定：**资产全部就绪之后、视频生成之前**。早一步做，资产一改全废；晚一步做，视频已经在自由发挥。
>
> **本文件的交付物只有一样：可以逐张复制去生图的提示词。** 不生成图、不调接口，出图由人在平台上完成。

---

## 零、怎么用（三步，一张图三分钟）

| 步 | 做什么 | 产出 |
|---|---|---|
| 1 | 照 §一 点齐资产，给每张资产编号 `图片N` | 一张编号表 |
| 2 | 从 §三 选构型 → 照 §四 六段填空 → 套 §二 风格前缀 | 一段提示词 |
| 3 | 复制到出图工具，四个字段（比例 / 参考图 / 种子 / 版本）记进 §七 清单 | 一张图 + 一行记录 |

**一次只写一张。** 不要一口气写十个单元的提示词再回头改——第一章的图会推翻你对构型的判断。

## 二、风格前缀（第一句就要写，决定整张图的底子）

分镜图的风格必须与最终视频一致，否则图生视频会把它往它的默认审美上拉。三选一，**整集只用一种**：

**A 现代真人写实（短剧主流）**
```
电影剧组的现场剧照。像剧组摄影师在实景里用中画幅数码相机和 35mm 电影镜头拍的：
高分辨率但成像柔和，皮肤与衣料按真实光线自然呈现，整体干净通透；没有后期修图，也没有刻意强化任何细节。
```

**B 古装/年代真人写实**
```
电影剧组的现场剧照，年代戏实拍。像剧组摄影师在棚内实景里用中画幅数码相机和 40mm 镜头拍的：
高分辨率但成像柔和，织物纹理、木石旧痕按真实光线自然呈现，整体干净通透；没有后期修图，也没有刻意强化任何细节。
```

**C 3D 漫风格化（AI 漫剧）**
```
32mm胶片质感，虚幻引擎5.3，Nanite虚拟几何体，lumen全局光照，光线追踪全局光照，全局反射，路径追踪，
富士REALA 500D RED Komodo，HDR 10-BIT色深，宽广动态范围，电影级风格化写实三维CGI。
```

> 前缀只解决"这张图像什么介质拍的"，**不解决像谁**——长相靠 `[图片N]` 大脸卡，不靠形容词。写"绝美""惊艳""精致五官"一律改成对卡的点名。

## 三、按构型挑写法（一图只做一件事）

同一段六段结构，重心随构型换。**先判构型，再填空**：

| 构型 | 什么时候用 | 重心 | 最容易错 |
|---|---|---|---|
| **定场图** | 换场第一个单元 | 场景图说清空间与纵深，人物可以极小或不在画面里 | 只顾拍人，墙面没交代 → 下一段换角度空间就塌 |
| **单人特写** | 情绪峰值、台词重音 | 大脸卡 + 眼睛与嘴的状态；背景只留一层虚化 | 一次塞两个人 → 脸必串 |
| **双人同框** | 对话、对峙 | 站位图 + 中文相对位置复述；两人前后错开半个身位 | 写成"面对面"却没写距离与谁挡谁 |
| **过肩** | 反打、压迫感 | 前景肩背虚化占 1/3，主体在另一侧清晰 | 前景那人也给了脸 → 变成双人同框 |
| **道具/局部特写** | 手、刀、杯、纸 | 道具卡 + 材质与磨损；背景全虚 | 道具卡没画磨损，图里干净得像新的 |
| **全景调度** | 打戏、多人走位 | 站位图 + 机位高度 + 三人以上各自在做什么 | 只写"三人对峙"，没人写手在哪 |

## 四、提示词结构（七段，顺序不换）

| # | 段 | 写什么 | 写法要点 |
|---|---|---|---|
| 0 | 风格前缀 | §二 三选一，原句照抄 | 不改字、不缩写 |
| 1 | 场景引用 | 哪个场景、哪张图、内/外、什么时间 | `场景：{场景名}[图片1]，室内夜景` |
| 2 | 人物引用 | 谁在场、各自用哪张卡 | `人物：A[图片2][图片3]、B[图片4][图片5]` |
| 3 | 站位引用 | 站位图编号 + 一句中文相对位置复述 | `人物站位：见[图片6]，从左至右 A / B` |
| 4 | 景别机位 | 景别、机位高度、角度、焦段、画幅 | `中景，机位 1.2 米，平视偏侧 15°，35mm，竖屏 9:16` |
| 5 | 层次三账 | 前景 / 中景 / 背景，三账都要有内容 | 见下节 |
| 6 | 光线与色彩 | 光位、光比、色温、色卡编号 | `窗光为主，光比 1:3，3800K，基准 COLOR-S07-A` |
| 7 | 固定禁用句 | 原句照抄，一个字不改 | 见 §五 |

### 层次三账（缺一不算过）

| 账 | 写什么 | 示例 |
|---|---|---|
| 前景 | 虚化或遮挡的元素：植物、窗框、门框、人物肩部 | `前景左下：茶几一角与半杯水，虚化` |
| 中景 | 人物主体，对焦清晰，正在做什么 | `中景：A 坐在沙发左侧，手停在膝盖上；B 站窗边背对半个身` |
| 背景 | 纵深元素 + 背景正在发生什么（须有独立、不同步的生活化行为） | `背景：窗外晾衣绳上的衬衫在动；对面楼有一扇亮着的窗` |

> 分镜层只写层次意图，不写毫米、光圈、ISO——数值归关键词层。

## 五、固定禁用句（第 7 段，原句照抄）

```
视频全程禁止出现任何字幕，禁止文字叠加，必须是纯画面；禁止出现任何bgm，禁止配乐。
不要出现：文字、字幕、水印、logo、分格、漫画格、多余人物、第二机位、镜面反射里多出的人。
```

> 前一句是平台层约束（与关键词第 0 段同源），后一句是图层的负向词。**两张图之间不许只改一句**——每次改动都要能说出改的是哪一段。

## 六、编号与路径

| 项 | 规定 |
|---|---|
| 编号 | 单镜组：`KB_{集号}_U{单元号}_v{n}`，例 `KB_S07_U03_v1`；**多镜组**（2.5 档一个单元里 2 个以上镜头）：`KB_{集号}_U{单元号}_{镜号}_v{n}`，例 `KB_S07_U03_S02_v1` |
| 文件 | `30_分镜图/KB_S07_U03_v1.png` |
| 单元号 | 与分镜表生成单元号一致，不跨单元复用 |
| 版本 | 重出一次 `n+1`；旧图改名加 `_deprecated`，**不覆盖** |
| 一图一镜 | 一张图只做一个镜头；**单镜组一单元一张，多镜组按镜头各出一张** |

### 分镜表必填列

| 列 | 内容 |
|---|---|
| 分镜图编号 | `KB_S07_U03_v1` |
| 分镜图路径 | `30_分镜图/KB_S07_U03_v1.png` |
| 版本 | `v1` |
| 对应生成单元 | `S07-U03` |
| 状态 | 待出 / 已出 / 已作废 |

校验：单元有编号但文件不存在 → error（CT25）。

### 预算紧时只抽 1/3：抽哪张（按此优先级，不按单元顺序）

| 优先 | 关键单元 | 为什么是它 |
|---|---|---|
| 1 | **跨段衔接的末单元** | 就是下一段的锚点，缺了下一段的站位没依据 |
| 2 | **打戏的命中帧**（受力反馈那一镜） | 打戏只有这一帧能把力度定死 |
| 3 | **B 级情绪峰值** | 全片记住的就是这几帧 |
| 4 | 换场第一个单元（定场图，**强烈建议但不进闸门**） | 没有它，后面每张都在猜空间；CT25 只硬性要求前 3 类 |
| 5 | 其余按顺序补齐到 ⌈总数÷3⌉ | 只补到此为止 |

> 前 3 类缺图 → CT25 error；定场图缺图只提示，不判红（单场景集不适用）。

> 覆盖率不足或上述关键单元缺图 → CT25 error。抽 1/3 是**降级**，不是常规做法；能全出就全出。

## 七·五、分镜图怎么被用（V2.6，按组时长）

**V2.10**：一组只能有一张首帧，且只能标在分镜图上（`kind: board` + `role: first_frame`）；各镜的 `shot_ref` 是图片引用，不是首帧。

| 组的时长 | 档位 | 要不要用分镜图 | refs 里怎么写 |
|---|---|---|---|
| **4–15 秒** | 2.0 | **不用** | 不挂分镜图。挂了 CT17 报 warning「本组 X 秒，不需要分镜图」 |
| **15–30 秒** | 2.5 flash / 2.5 标准版 | **要用**（逐镜画面参考） | `kind: board` + `role: shot_ref`；想当起点就写 `role: first_frame` |

两条附注：

- **分镜图仍然要产出**（1/3 抽帧那套照旧）——它是你自己的出图交付物与站位锚点，只是 4–15 秒的组不把它喂给模型。
- 分镜图**占一张图片名额**（三种档位都一样，V2.12 平台实测：2.0 的 9 张里要扣掉它），且不参与身份链；2.5 里它可以**兼首帧**。

---|---|---|---|
| Seedance 2.0 系列 | **整组的生成起点**，不做单个镜头的画面参考 | `kind: board`、`role: first_frame` | **不占**（9 个位全留给资产） |
| Seedance 2.5 flash | **单个镜头**的画面参考 | `kind: board`、`role: shot_ref` | **不占**（10 个位留给资产） |
| Seedance 2.5 标准版 | **单个镜头**的画面参考 | `kind: board`、`role: shot_ref` | **不占**（30 个位留给资产） |

三条后果，写的时候要记住：

1. **2.0 里给单镜参考没用**——2.0 是整组生成，分镜图只锁起点；单镜画面要靠资产图 + 文字。真需要逐镜参考画面，就升到 2.5 flash 或标准版。
2. **分镜图也算一张图**——"九图给满 + 再挂一张关键帧"在 2.0 里会被 CT17 判超限（9+1=10 > 9）；要么少给一张资产图，要么升 2.5 flash。
3. **分镜图不参与身份链**——它是产物，锚定画面起点，不锚定长相；长相仍由原始大脸卡负责（CT23）。

## 八、禁止事项

| # | 禁止 | 为什么 |
|---|---|---|
| 1 | 资产未齐就出图 | 资产一改，整批关键帧作废，白花 |
| 2 | 出了图后资产变更仍沿用旧图 | 图与卡不是同一个人，视频必然换脸 |
| 3 | 一图做两个镜头 / 画分格 / 做表情九宫格 | 图生视频读不懂分格，会把两格揉成一个画面 |
| 4 | 在图里画字幕、场号、文字标注 | 会被图生视频当画面内容继承下来 |
| 5 | 拿分镜图当资产用（当场景图、当角色卡） | 它是产物，进参考链就是二代传递 |
| 6 | 参考文献里的上一版分镜图、锚点帧做参考 | 参考链只能一代，锚点必须指原始文件 |
| 7 | 用"电影感""高级""有氛围"代替机位与光位 | 模型按训练集高频补全，等于没写 |
| 8 | 用形容词写长相（"绝美""五官精致"） | 与"没给就补最常见的"同源，会得到网红脸 |
| 9 | 从上一张分镜图再生成下一张 | 复印件的复印件，四代之后脸就散了 |
