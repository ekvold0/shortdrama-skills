# 场景图资产规范（三块结构）

> 一个场景一张卡，三块固定。场景图的唯一用途是**当资产用**：当视频的背景、当色卡的取色源、当换场子的空间依据。
> 判断标准只有一条：**这张图里有没有人？有没有字？** 有人、有字都不算合格的场景图。

---

## 一、三块总览

| # | 块 | 回答什么问题 | 下游去哪 |
|---|---|---|---|
| 1 | 环境要素 | 这个空间里有什么（结构、陈设、道具、氛围、色彩基调） | 场景图画面、色卡 |
| 2 | 光线与光影氛围 | 光**从哪来**、什么颜色、往哪打、影子落在哪 | 场景图画面、关键词的光线段 |
| 3 | 拍摄规格 | 用什么机器、什么镜头、什么景深拍的 | 风格包的镜头句 |

> 顺序不能换：先有这个空间里有什么，才谈光怎么落上去；先定光，才定用什么机器拍得住这光。

---

## 二、环境要素块

| 字段 | 填写要点 |
|---|---|
| 空间形制 | 几面墙、什么层高、窗在哪、门在哪、有几个出口。**要能让人照着摆机位** |
| 建筑与材质 | 墙体、地面、顶面各是什么材质；旧在哪、新在哪 |
| 主要陈设 | 三到五件撑起空间的东西（沙发、餐桌、木人桩、货架），写位置不写评价 |
| 关键道具 | 这场戏要用到的物件，**单独标出来**并说明在第几步被谁碰到 |
| 氛围元素 | 尘、烟、水汽、风、光斑、空中浮物——可有可无，但一旦写了就要能看见 |
| 色彩基调 | 主色 / 辅色 / 强调色，各给 HEX 与占比。**这就是色卡的取色源** |
| 空间锚点 | 写清 3–4 个可被台词和动作指认的锚点（"靠窗""门边""桌角"），供站位与分镜复用 |

**样例（客栈后厨·午后）**

- 空间形制：长方形，进深约 6 米、面宽 4 米；东侧一扇高窗离地 1.6 米，西侧通往前堂的门洞宽 1.2 米；北墙一道灶台通长，南墙堆货架。
- 建筑与材质：夯土地面踩出浅坑；墙面白灰剥落露出土坯；梁是原木，烟熏成深褐。
- 主要陈设：通长灶台（北）、两张矮长桌（中偏西）、货架两层（南，靠墙）、水缸一口（门洞右侧）。
- 关键道具：灶台左侧的**铜锅**（第三镜被主角揭开）、货架第二层的**粗陶罐**（第五镜被碰倒）。
- 氛围元素：窗光里有细小浮尘；灶口有一线白汽。
- 色彩基调：主色 `#6B5B4A` 土褐（约 55%）／辅色 `#8A8F7B` 灰绿（约 30%）／强调色 `#C0682A` 灶火橙（约 15%）。
- 空间锚点：高窗、门洞、灶台左端、水缸。

## 三、光线与光影氛围块

> **这一块不许写"光线柔和"——必须回答光从哪来。**

| 字段 | 填写要点 |
|---|---|
| 光源类型 | 自然光／钨丝／荧光／钠灯／火光／混合。几种就写几种，按强弱排 |
| 来向 | 从画面哪一侧、哪个高度打进来（左前上方 45°、正后方逆光、顶上直下） |
| 色温 | 给 K 值：正午日光 5600K／黄昏前 4300K／钨丝 3200K／钠灯 2800K／窗光散射 6500K |
| 光比 | 亮部与暗部差几档（1:2 柔和 / 1:8 硬 / 1:16 极硬），或直接写"亮部不过曝、暗部有细节" |
| 影子 | 影子朝哪、软硬、边缘清不清；地面/墙上有无光斑 |
| 氛围情绪 | 这光让人什么感觉（闷、冷、不安、被晒着），一句就够 |

**样例（客栈后厨·午后）**

- 光源类型：主光＝东侧高窗的散射日光；辅光＝北墙灶口火光；无补光。
- 来向：窗光自左前上方约 40° 斜切进画面，落在两张矮长桌与地面中央；火光自画面下方偏低位置向上舔。
- 色温：窗光 5600K（冷白）／火光 1800K（橙红），冷主暖辅，两个极限色温并置。
- 光比：窗光区与灶台背面约 1:8；人物若站在窗光里，暗部侧脸靠火光提起一档。
- 影子：窗棂的影子投在地面与桌沿，边缘清晰；灶台背墙上有火光的抖动反光。
- 氛围情绪：又闷又亮，亮得让人眯眼，暗的区域偏偏是最热的。

## 四、拍摄规格块

> 写实风格**默认 ARRI 阿莱**，写进提示词；非写实风格用对应风格标签（见 `references/44-打光库.md` 与风格包 `ct_rules.style_prefix()`）。

| 风格 | 机器 | 镜头 | 默认规格 |
|---|---|---|---|
| 写实（现代/年代） | ARRI ALEXA 65（大场面）／ALEXA 35（常规）／ALEXA Mini LF（贴身手持） | Signature Prime（主用）／Master Prime（老片质感）／Prime DNA（轻微畸变） | 光圈 T2.8–T4；4K–6K；Log 直出后调 |
| 3D 漫风格化 | 无真实机器——用渲染器语言 | — | `32mm胶片质感，虚幻引擎5.3，Nanite虚拟几何体，lumen全局光照…`（见风格包） |
| 其他非写实 | 用风格标签（如水墨、赛璐璐、定格） | — | 整集只能一种 |

**写进提示词的原句（写实风·可直接抄）**

```
电影剧组的实景剧照。ARRI ALEXA 35 配 Signature Prime 镜头拍摄，T2.8，高分辨率但成像柔和；
空间结构、材质与陈设按真实物理呈现，没有后期修图，也没有刻意强化任何质感。
```

## 五、场景图的硬规矩（五条）

1. **空场景、无人物**。这是资产，不是剧照。人物要进去是分镜图与视频阶段的事。
2. **画面里不许有任何文字**：招牌、门牌、菜单、报纸、海报上的字一律模糊掉或避开。和视频的第 0 段禁用一致。
3. **一张卡一组镜头**：同一场景多次出现**合并成一张卡**，只在光线/时间变化时列为变体（"同一空间·夜""同一空间·雨"各出一版图，卡不重写）。
4. **比例固定**：竖屏 9:16、横屏 16:9，与整集画幅一致；不要一张卡一个比例。
5. **可复用**：这张图要同时当（a）视频背景、（b）色卡取色源、（c）换场时的空间依据。任一用途做不到就重画。

---

## 六、从场景图到色卡（顺序不能反）

```
场景图出图 → 在图上取 3–5 个 HEX → 写成色卡（含占比与取自哪一处）→ 分镜图 / 关键词引用色卡
```

- 禁止：先编 HEX 再让场景图去凑（`templates/08-色卡规范.md` 里已列为反例）。
- 色值必须能在场景图上指认出来，所以色卡每条都要写 `from`（取自哪一处：窗光区、木墙、灶火）。
- CT18 同时校验两头：正文里的 HEX 必须来自所引色卡；色卡的 `from` 必须指向真实场景。

---

## 七、自检（七条，缺一条不算完）

- [ ] 三块齐全，光线块写明了光源类型 + 来向 + 色温 + 光比
- [ ] 画面里没有人、没有字
- [ ] 色彩基调给了 3–5 个 HEX 与占比，并且能在图上指认
- [ ] 空间锚点写得能被台词与动作指认（至少 3 个）
- [ ] 拍摄规格与整集风格包一致（写实＝ARRI，非写实＝对应标签）
- [ ] 同一场景的变体只在光线/时间上不同，空间与陈设没变
- [ ] 场景编号 `SCN_<集号>_<序号>` 与资产登记表、`data.json` 的 `assets.scenes[].id` 一致

> 本模板对应需求 SB-07（场景图资产）与 CT34（光线来源/拍摄规格缺失即提示）
