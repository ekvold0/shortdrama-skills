# 色卡规范（场景色彩基准）

> 一个场景一张色卡，是全场景分镜图与成片的唯一色彩基准。
> 色卡里的每个颜色都必须是**取来的**，不是想出来的。

---

## 一、定卡顺序（别倒过来）

| 步 | 做什么 | 产物 |
|---|---|---|
| 1 | 按剧本定文字项：情绪基调、整体基调、禁用色 | 色卡草稿（无 HEX） |
| 2 | 用草稿基调出**无人场景图**，覆盖所有可能入镜的墙面 | `SCN-S03-客厅_v2.png` |
| 3 | 从该场景图上取 3–5 个主色，记 HEX 与面积占比 | 取色记录 |
| 4 | 定肤色基准与色温基准 | 回填草稿 |
| 5 | 编号入册，出一张色卡 PNG | `COLOR-S03-A.png` |

> 顺序的意义：**先用文字定调，再用图定色**。文字项在没有场景图时先写；HEX 一定要等场景图出来再取，不许先编一个"好看的十六进制"再让场景图去凑。

**色温基准（K）怎么给**——没有测光数据时按主光性质查表，别空着也别瞎编：

| 画面主光 | 基准 K | 典型场景 |
|---|---|---|
| 窗外日光（阴天/散射） | 6500K | 日戏、窗光为主 |
| 正午硬直射日光 | 5600K | 户外正午 |
| 影棚灯／闪光 | 5500K | 定妆、证件式打光 |
| 黄昏前 1 小时 | 4300K | 夕阳、暖调结尾 |
| 室内暖灯／钨丝 | 3200K | 夜戏台灯、餐厅 |
| 夜景路灯（钠灯） | 2800K | 街头夜景 |

判定用相对值：**同场次内所有镜头以该基准为准，偏差 ≤800K**（CT18）；换场次重给基准。取色时以画面里最接近中性灰的一块作白平衡参照，再决定往冷暖偏多少。

## 二、色卡字段表

| 字段 | 填写要求 | 示例 |
|---|---|---|
| 场次 | 场号 + 场景名 + 内外/时间 | `S03 客厅·内·夜` |
| 色卡编号 | `COLOR-{集号}-{字母}`，字母按定稿顺序 A、B、C | `COLOR-S03-A` |
| 情绪基调 | 一句话，说这场戏要什么感觉 | `压抑的僵持：谁都不肯先开口` |
| 主色 | 3–5 个，HEX + 面积占比，从大到小 | `#2B2F33 42%`、`#4A4239 23%` |
| 辅色 | 承托主色的第二层，1–2 个 | `#6E6255 15%` |
| 点缀色 | 1 个，画面里面积最小但最抓眼的 | `#C25B3F 3%（母亲手里的搪瓷杯）` |
| 肤色基准 | 该场景光线下人物肤色的落点，HEX | `#C9A183`，暗部 `#8E6F58` |
| 禁用色 | 本场绝不能出现的颜色，逐条写原因 | `正红：与剧中丧仪冲突` |
| 整体基调 | 冷暖方向、对比度、饱和度、暗部倾向 | `冷灰底、低饱和、暗部偏青、对比中等` |
| 色温基准（K） | 校核用数值，从取色结果换算 | `3800K` |
| 取色来源图 | 必须是**无人场景图**，写文件名与版本 | `SCN-S03-客厅_v2.png` |

> 「整体基调」写方向，不写牌子、不写"莫兰迪""高级灰"这类名词代替具体色值。

## 三、取色记录（附在色卡后）

| # | 色样 | HEX | 占比 | 取自画面哪一处 | 用途 |
|---|---|---|---|---|---|
| 1 | 近黑灰 | `#2B2F33` | 42% | 沙发背后的墙 | 主色·背景压暗 |
| 2 | 暖褐 | `#4A4239` | 23% | 布艺沙发 | 主色·中景承托 |
| 3 | 灰米 | `#6E6255` | 15% | 地板与地毯 | 辅色·地面 |
| 4 | 搪瓷红 | `#C25B3F` | 3% | 茶几上的搪瓷杯 | 点缀色·唯一暖点 |
| 5 | 冷白 | `#D8DDE0` | 8% | 窗玻璃反光 | 辅色·高光 |

规则：

- 取色点必须落在**场景图里真实存在的区域**，注明是哪一处。
- 主色按面积从大到小排，前三项面积合计应 ≥70%。
- 面积占比是设计意图，不是像素统计，能自洽即可。

---

## 四、编号与文件

| 项 | 规定 |
|---|---|
| 编号 | `COLOR-{集号}-{字母}`，例 `COLOR-S03-A` |
| 文件 | `20_资产/色卡/COLOR-S03-A.png` |
| 图上内容 | 色块并排 + 每块标 HEX + 场景名 + 编号，黑底或白底，无装饰 |
| 版本 | 色卡改动不升字母，按图内隐含版本重出；同一场次要"换一套颜色"才升字母 |
| 复用 | 跨集同一场景可复用同号；**跨场次不得共用一张色卡** |

## 五、下游怎么引用

| 层 | 写法 | 说明 |
|---|---|---|
| 锚点表 | `色彩基调：COLOR-S03-A` | 用编号回指，不抄色值 |
| 分镜图提示词 | `色彩基准：COLOR-S03-A（冷灰底、低饱和、暗部偏青）` | 编号 + 一句话，两样都给 |
| 关键词层 | `色彩参数：…色温 3800K…，基准 COLOR-S03-A` | 数值必须落在色卡区间内 |
| 成片核对 | 抽帧比色卡主色 | 偏差进人评记录 |

## 六、禁则

| # | 禁止 | 原因 |
|---|---|---|
| 1 | 手填"好看的颜色"、凭感觉给 HEX | 无法复现、无法校验，CT18 无从比对 |
| 2 | 用"暖色调""高级灰""电影感"代替具体色值 | 那是形容词，不是基准 |
| 3 | 跳过场景图、先编 HEX 再让场景图去凑 | 画面是随机结果，色卡成了装饰；正确顺序是 **场景图 → 取色 → 色卡 → 分镜图／关键词** |
| 4 | 色卡晚于分镜图定稿 | 关键帧与成片两套颜色，必跳变 |
| 5 | 同一场次内色温漂移 **>800K** | 判越界，warning（CT18），回退重定 |
| 6 | 色值写错格式（缺 #、位数不对）或某个色没写 rom | 判 error（CT18），补格式、补取处 |
| 7 | 关键词正文里现编了一个色卡上没有的 #RRGGBB | 判 error（CT18），改回色卡里的值 |
| 6 | 一次取色跨多个场景共用 | 每个场景光位不同，取色点不可移植 |
| 7 | 取色来源图是有人物的图 | 人物肤色与服装会污染主色判断 |
| 8 | 只写主色不写禁用色 | 禁用色是防穿帮的负面约束，缺了必出事 |

---

## 七、不合格样例（对照）

| 写法 | 问题 |
|---|---|
| `主色：暖色调、米色系` | 无 HEX，无法校验 |
| `主色：#FFFFFF #000000` | 纯黑白，不是从场景图取的 |
| `肤色基准：白皙透亮` | 形容词，不是落点色值 |
| `色卡编号：客厅色卡` | 不符合 `COLOR-{集号}-{字母}` |
| `取色来源：参考图网站` | 不是本项目的无人场景图 |
| `禁用色：无` | 缺负面约束 |

## 八、自检

- [ ] 编号符合 `COLOR-{集号}-{字母}`，文件在 `20_资产/色卡/`
- [ ] 主色 3–5 个，全部有 HEX 与面积占比
- [ ] 每个色都标了取自场景图哪一处
- [ ] 取色来源图是**无人**场景图，且覆盖了本场所有入镜墙面
- [ ] 肤色基准给了落点值与暗部值
- [ ] 禁用色逐条写了原因
- [ ] 色温基准有数值，关键词层色温与之相差 ≤800K
- [ ] 锚点表已回指编号，分镜图与关键词都能对上
- [ ] 色卡 PNG 与字段表内容一致（色块、HEX、编号）

## 九、一页填空版（复制即用）

> 用法：把这个代码块复制进该场的色卡文件，逐格填。填完拿给自检表对一遍。

```text
色卡编号：COLOR-{集号}-{字母}        对应场景：SCN-{集号}-{场景名}_v{n}
取色来源图：{无人场景图文件名}        取色区域：全画面 / 仅左半 / 仅窗侧
色温基准：____ K（窗外日光散射 6500／正午硬直射 5600／影棚灯 5500／黄昏前一小时 4300／室内暖灯 3200／夜景路灯 2800）
同场次允许偏差：≤800K

主色（3–5 个，按面积从大到小）
1. #______  占画面 __%   取自：______（墙面/沙发/木地板…）
2. #______  占画面 __%   取自：______
3. #______  占画面 __%   取自：______
4. #______  占画面 __%   取自：______

肤色基准：#______（亮部） / #______（暗部）    取自：______

禁用色（逐条写原因）
- #______：______（例：饱和正红，会抢主色，且与"深青绿"冲突）
- #______：______

与关键词层的关系
承载该场的序列组：S{集}-U{起} ~ U{止}
关键词层 color_card 字段填：COLOR-{集号}-{字母}；color_temp 填：____ K
```

填的时候只记两条：**色卡从无人场景图取，不是先编 HEX 再让场景图去凑**；**色卡早于分镜图和关键词定稿**（顺序：场景图 → 取色 → 色卡 → 分镜图／关键词）。

> 本模板对应需求 SB-07
