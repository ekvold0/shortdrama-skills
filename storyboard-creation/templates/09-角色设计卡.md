# 角色设计卡（五块结构）

> 一个角色一张卡，五块固定，缺一块不算完。
> 判断标准只有一条：这段话换到别的角色身上还能用 → 它就是废话。

---

## 一、五块总览

| # | 块 | 回答什么问题 | 从哪里推导 | 下游去哪 |
|---|---|---|---|---|
| 1 | 身份背景 | 她是谁、从哪来、现在要干什么 | 剧本的剧情与关系 | 全部描述的根 |
| 2 | 审美方向 | 往哪个时代、哪种人的美推 | 世界观与年代 | 大脸卡的调子 |
| 3 | 脸部 | 长什么样，含永久识别点 | 年龄 + 经历 | 大脸卡 |
| 4 | 妆发 | 这一场她的妆与头发是什么状态 | 当前场景状态 | 大脸卡、服装卡 |
| 5 | 服装 | 穿什么、为什么是这一身 | 身份 + 本场要做的事 | 无头服装图、道具卡 |

> 顺序不能换：先有身份，才有审美方向；先有年龄与经历，才推得出脸；先知道这一场要干什么，才定得出妆发与服装。

---

## 二、身份背景块

| 字段 | 填写要点 |
|---|---|
| 出身 | 家世、地域、阶层。写到能解释她的口音、礼数、手上有没有茧 |
| 经历 | 两三件改变过她的事，写成事实不写成形容词 |
| 性格 | 用"遇到什么事会怎么做"来写，不写"温柔善良" |
| 当下处境 | 这一集开始时她处在什么局面里 |
| 本场要做什么 | 这一场她具体要完成的一个动作或一句话 |
| 关键关系 | 与同场其他人的关系、亏欠或隐瞒 |

**示例（盛唐公主·李昭华）**

- 出身：宗室女，封号昭华。父为安西都护，常年在边镇；母是胡商之女，生她后不久病故。
- 经历：幼年在龟兹长大，十四岁才入长安；会骑马，会两种话；入宫后学过三年礼，仍改不掉说话前先看对方眼睛的习惯。
- 性格：说话慢，决定之后不回头；对下人客气，对长辈沉默。
- 当下处境：和亲的旨意已下，尚未宣；她自己已经知道。
- 本场要做什么：在御花园西北角，把一枚旧铜铃塞给弟弟，让他别等她。
- 关键关系：与弟弟李昭远——她带大的，也最不肯让他看见自己哭。

## 三、审美方向块

| 字段 | 填写要点 |
|---|---|
| 往哪推 | 具体到时代与人群：哪个朝代、哪种身份的人的美 |
| 参考坐标 | 俑、壁画、旧照片、某类实物，写得出名字 |
| 不能像什么 | 明确排除的方向（网红脸、现代妆、某类模板） |
| 一句定调 | 全卡唯一允许的"感觉句"，其余全部落到具体 |

**示例（李昭华）**

- 往哪推：往**盛唐仕女俑**方向推——面如满月、面颊有肉、下颌柔和；眉眼舒展，不锐利。
- 参考坐标：唐墓出土彩绘女俑、周昉《簪花仕女图》的脸部比例。
- 不能像什么：不能像现代网红脸（尖下巴、高鼻、大眼），不能像日系少女漫，不能像清宫剧的柳叶眉。
- 一句定调：丰润、安静、有分量，像一块温过的玉，不像瓷器。

---

## 四、脸部块

| 字段 | 填写要点 |
|---|---|
| 年龄 | 具体数字，与经历对得上 |
| 脸型 | 轮廓怎么走：宽窄、面中平或鼓、下颌有没有肉 |
| 骨相 | 颧骨、眉骨、下颌角的高低与宽窄——滤镜洗不掉的就是这一层 |
| 眉 | 形状、粗细、眉尾走向、眉色浓淡 |
| 眼 | 眼型、眼尾、眼皮厚薄、眼距。**不写"大眼睛"** |
| 鼻 | 鼻梁高度、鼻头形状、鼻翼宽窄 |
| 唇 | 厚薄、唇峰、唇色、嘴角走向 |
| 皮肤质地 | 干/油、薄/厚、有无红血丝；与年龄一致 |
| 永久识别点 | **至少一处**，写死在骨或皮上：一颗痣、一道疤、一处不对称 |
| 表情基线 | 不演戏时的默认表情，防止每张图都换一张脸 |

**示例（李昭华，23 岁）**

- 脸型：圆润鹅蛋脸，面中平缓，双颊有肉；下颌线柔和，低头时略有双下巴。
- 骨相：颧骨不高但宽，眉骨平，下颌角圆钝不外翻。
- 眉：蛾眉，细而淡，眉尾略往下垂，眉心距离偏宽。
- 眼：细长杏眼，眼尾平不上扬，眼皮略厚（内双），眼距略宽。
- 鼻：鼻梁低平，鼻头圆润略肉，鼻翼不窄。
- 唇：下唇比上唇厚，唇峰不明显，唇色偏淡，嘴角平。
- 皮肤质地：薄，颧骨处透一点红血丝，眼下有淡淡的青。
- **永久识别点**：右眉尾一颗小泪痣；左耳垂有一道旧疤（幼时马惊），两耳垂不对称；笑时只有左边显出酒窝。
- 表情基线：嘴唇轻抿，眼睛看着对方但不聚焦，像在想别的事。

## 五、妆发块

| 字段 | 填写要点 |
|---|---|
| 妆面 | 底妆厚薄、眉、眼、颊、唇逐项写；写用了什么，不写"精致妆容" |
| 发型 | 髻式、分缝、鬓发处理、发量 |
| 发饰 | 具体件数与位置，谁给的、什么材质 |
| 当前状态 | 从这一场的状态推导：掉了什么、乱在哪、有没有汗 |

**示例（李昭华，本场在御花园）**

- 妆面：薄白底妆，看得见本身肤色；斜红两道在太阳穴；额头一枚金色五瓣花钿；眉按原形描淡；唇用胭脂薄薄点一层，中间深边缘浅。
- 发型：高髻偏右，鬓发贴面覆住耳朵，后颈留几缕碎发。
- 发饰：金步摇一支（本场已取下收进袖中，怕走动时响）、素银簪两支。
- 当前状态：走得急，右鬓有一缕散下来；鼻尖有薄汗；花钿边缘有一点点翘。

## 六、服装块

| 字段 | 填写要点 |
|---|---|
| 内层 | 贴身衣物：形制、颜色、领口 |
| 外层 | 主服装：形制、颜色、长度、袖型 |
| 鞋 | 形制与声响（石子路、木地板、地毯各不相同） |
| 配饰 | 腰间、腕上、手持的各是什么 |
| 材质与磨损 | 料的厚薄、光泽、旧在哪（袖口、膝头、下摆） |
| 颜色依据 | 为什么是这几个颜色——与身份、场合、情绪对得上 |

**示例（李昭华）**

- 内层：素白抹胸，领口齐胸。
- 外层：藕荷色上襦（窄袖、袖口收口）+ 月白下裙（高腰、裙长及地）+ 淡青半臂（短于腰）+ 藕荷长披帛一条，一端绕臂垂到膝下。
- 鞋：软底绣鞋，走石子路几乎没有声。
- 配饰：腰间禁步一串（玉片，走快了会响，所以她走得慢）、袖中铜铃一枚。
- 材质与磨损：上襦是细麻，洗过多次，肩线处微微发白；披帛是薄纱，边缘有一处抽丝。
- 颜色依据：全身上下没有一处正红——今日要去见的人，不能穿艳。

## 七、自检：换人测试

逐条念一遍，问：**这句话换给另一个角色，还成立吗？**

| 原文 | 换给"长安商贾之女"还成立吗 | 判定 |
|---|---|---|
| 面容精致，气质出众 | 成立 | **无效**，删除重写 |
| 皮肤白皙，五官立体 | 成立 | **无效** |
| 圆润鹅蛋脸，双颊有肉，低头时略有双下巴 | 不成立（商贾之女常年操持，脸更瘦更糙） | 有效 |
| 右眉尾一颗小泪痣 | 不成立 | 有效 |
| 眼神温柔如水 | 成立 | **无效** |
| 看人时先看眼睛再看嘴，说完会停半秒 | 不成立 | 有效 |

处置规则：

- 判"成立"的句子 → **必须**替换成该角色独有的信息，不许保留。
- 一条卡里"成立"的句子超过两处 → 整卡退回重写。
- 换了角色只是改名字、改衣服颜色，其余不动 → 同样退回。

## 八、禁用词清单

| 禁用词 | 为什么无效 | 换成什么维度 |
|---|---|---|
| 好看 | 不指向任何具体特征 | 脸型、骨相、五官的具体形状 |
| 绝色 | 评价，不是描述 | 一段可指认的比例关系 |
| 精致 | 泛化夸赞，模型用高频脸补全 | 妆面逐项写：底妆厚薄、眉形、唇色 |
| 大眼睛 | 模型直接放大眼睛，变网红脸 | 眼型、眼尾走向、眼皮厚薄、眼距 |
| 高鼻梁 | 同上，会推向模板化的西式骨相 | 鼻梁高度、鼻头形状、鼻翼宽窄 |
| 肤白貌美 | 两个词都在往"标准美女"收 | 皮肤厚薄、血色、瑕疵、年龄痕迹 |

同类词一并禁用：倾国倾城、天生丽质、气质高雅、五官完美、魔鬼身材。

## 九、自检

- [ ] 五块齐全，没有一块空着或只写一句
- [ ] 身份背景里能指回剧情：出身、经历、处境、本场要做什么
- [ ] 审美方向写了时代与人群，并明确排除了不能像的方向
- [ ] 脸部有**永久识别点**，且至少一处是不对称
- [ ] 妆发、服装都能从"本场要做什么"推出来
- [ ] 全卡无禁用词，无"成立"的通用句
- [ ] 换人测试逐条做过，判"成立"的已替换
- [ ] 角色名、称呼与角色卡文件名、关键词提示词一致
