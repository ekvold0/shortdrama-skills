## 3. 逐镜表（一镜一个完整动作组）

| 镜号 | 景别 | 运镜 | ①预备 | ②发力 | ③攻击 | ④防守 | ⑤受力反馈 | ⑥重心恢复 | 时长 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 中景 | 侧向跟拍 | 重心压右腿，双拳收至肋下 | 蹬右后脚→拧腰→送右肩 | 右拳击向B左颧 | B左臂内格 | 头随拳向右甩，退半步 | A落步站稳，B后脚撑住 | 3s |
| 2 | 　 | 　 | 　 | 　 | 　 | 　 | 　 | 　 | 　 |
| 3 | 　 | 　 | 　 | 　 | 　 | 　 | 　 | 　 | 　 |

填表口诀：**五、六两列空着 = 这镜没写完。**

- 一镜只放一个完整动作组；大动作拆 起势/完成/落定 三镜。
- 组合击允许写"两连击"，但两次落点必须不同。
- 命中那一拍要停（屏息停顿点），标注在该镜末尾：`【停一拍】`。

## 5. 收尾镜（跨段才要）

若本组是该场景最后一段、且下一段仍在此场景：

```
【分镜N】人物站位记录镜头 24mm，时长：1秒 景别：大全景 运镜：固定 镜头角度：俯拍 承接上镜头的结束姿态。人物和道具物品强制静止一秒。
```

五条件缺一不可（24mm／大全景／固定／俯拍／静止一秒）；段内连续镜头不必加（用户裁定 B）。

## 7. 交给关键词层之前，自己过一遍

- [ ] 六阶段全填，⑤⑥ 不为空

- [ ] 只选了一型拍法，且该型必写项都写了

- [ ] 一镜一组，没有"打完接着打第二套"

## 8. 交给关键词层时的一句话

> 把这组交出去时只说两件事：**拍法是哪一型**、**升格在第几镜**。其余（倍速、快门、受力参数、音效对齐）由 `keyword-script-creation/references/56-武打物理参数与音效对齐.md` 承接，不要在分镜层写数值。
