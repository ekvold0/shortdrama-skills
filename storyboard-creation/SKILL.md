# 短剧分镜头脚本生成

> **版本行**：`V1.2｜2026-11-11｜接入四份写法库（43 运镜选型／44 打光选型／46 开场钩子／47 类型分镜配比，对齐关键词技能 41/42/48/55）｜修改人：分镜技能维护`

把一个剧本文档，转成能直接投喂 AI 视频工具的分镜：**先给方案、再给锚点、后写镜头，账目自洽、逐句有落点**。

## 0. 这个技能解决什么

| 不做 | 要做 |
|---|---|
| 拿起剧本就写镜头 | 先梗概、再 3–4 种结构方案，用户选定后动笔 |
| 每场重新想象人物样子 | 先立角色/声线/道具/空间锚点，全片复写 |
| 写完再算时长，对不上 | 先算账（总时长→各场→各单元），再写内容 |
| 用"悲伤地/愤怒地"糊过去 | 微表情走 FACS，整体情绪走"意图＋可观察行为" |
| 交付一堆散装文字 | Excel 分镜表 + AI 单元块 + 自检记录 + 台词留痕 |

## 1. 输入契约（缺什么就问，别猜）

**必填**：画幅比例、分辨率、模式、时长上限。
**选填**：平台、前后集上下文、参考图、交付格式。

- 画幅未确认 → **不输出任何分镜**，但可以先做梗概与结构方案。
- 前后集上下文缺失 → 按"独立单集"处理，并在交付物开头写明该风险。
- 用户只丢剧本、什么都没说 → 用一条消息问齐四项，不要分四轮问。

## 1.5 技法选取层（写镜之前先取料）

分镜不是"想到什么写什么"。每个镜头先定**落点**，再从 `references/55-技法选取-300条.md` 取一条已降维的写法。

- **只用 T1/T2**；T3 只在 55 §4 允许的画幅下用；**T4 一律走 55 §7 的等价替代**，并在衔接备注写「由 X 替代」。
- **一镜一主技法**：单镜 1 个运动类主技法，光影/色彩/构图类辅技法 ≤2，且不得与主技法抢同一运动轴（转动 vs 位移不可并存）。
- **一个效果一个落点**：同一效果不许在两列重复描述。
- **典故不进正文**：参考片只进「画面参数·参考电影」，写《片名》年份，全片 ≤1 部。
- 分镜层**禁量化**：不写毫米/每秒N次/FACS/光比数字——那是关键词层的活（见 55 §8）。

取料命令（不必整库读）：

```python
import sys; sys.path.insert(0, "scripts")
import cine_tech
cine_tech.by_slot("C3d 画面参数·运镜")   # 30 条候选
cine_tech.by_slot("C3e 画面参数·光影")   # 46 条候选
cine_tech.allowed(("T1", "T2"))          # 209 条可投池
```

## 1.6 写法层（技法管叫什么，写法库管这句话怎么写）

55 那套 300 条解决的是「这一招叫什么、什么档位、能不能投」；**「这一镜的话该写成什么样」在另外四份库里**：

| 要写的东西 | 读哪份 | 拿到什么 |
|---|---|---|
| 机位与运镜 | `43-运镜选型.md` | 十个轴 + 26 条运镜的分镜层写法定式（轴／方向与落点／起止景别） |
| 光影 | `44-打光选型.md` | 16 种布光的分镜层写法（光源与方向／光质／冷暖关系）+ 情绪→布光速查 |
| 每组前 2 秒 | `46-开场钩子.md` | 12 条钩子模板 + 短剧专属 4 条 + 堆叠规则 |
| 整场怎么切 | `47-类型分镜配比.md` | 八类题材的镜数/景别梯度/单镜时长/钩子/运镜/光位倾向 |

**执行顺序**：先按 47 定这场戏的形状 → 按 46 定首镜 → 按 43/44 写具体镜头 → 最后才去 55 查档位（T1–T4）确认这条技法能不能投。**倒过来会先拿到一个技法名再硬塞进画面，CT07/CT08 必爆。**

写法库四份都是**整篇读的**（不像 55 那样按落点查），它们没有条号，内容可以直接抄进分镜表，但不许当引用写。

## 2. 模式判定

| 模式 | 判定线索 | 结构要求 | 单镜上限 | 单元 |
|---|---|---|---|---|
| 竖屏短剧 | 9:16、单集 ≤3 分钟、强钩子 | 梗概＋结构方案（轻量） | 8 秒 | 4–15 秒 |
| 横屏短剧 | 横画幅、单集 1–3 分钟 | 梗概＋结构方案（轻量） | 10 秒 | 4–15 秒 |
| 短篇视频 | 10–15 分钟、完整起承转合 | **全片分幕分场规划（必做）** | 15 秒 | 4–15 秒 |

- 画幅**永远来自用户**，上表只描述典型画幅，不得拿来当默认值。
- 时长上限以用户给值为准；用户说"按平台常规"时，给建议值并请其确认。

## 3. 九步工作流

### 第 0 步 · 参数确认
收齐画幅、分辨率、模式、时长上限；确认交付格式。缺项按第 1 节处理。

### 第 1 步 · 规范研读
加载顺序：
1. `references/05-落地要求-覆盖层.md`（最高优先级，**必读**）
2. `references/00-通用内核.md`（方法底座）
3. 模式参数：`10-竖屏短剧.md` / `20-横屏短剧.md` / `30-短篇视频.md`
4. 用到才读：`40-表情微表情库.md`、`41-对话台词库.md`、`42-声音设计库.md`、`43-运镜选型.md`（写机位与运镜时）、`44-打光选型.md`（写光影时）、`46-开场钩子.md`（写每集首单元前必读）、`47-类型分镜配比.md`（第 5 步切单元前）、`50-跨类型分镜法.md`、`55-技法选取-300条.md`（卡在机位/运镜/光影/景别时**按落点查**，别整篇读）、`60-范例库.md`

写法库（43/44/46/47）与技法库不同：**整篇读，先定写法再查档位**，见 1.6。

不得只看模板不看附件；每个分镜块要能指回它用了哪条方法（附件 4 条目 / 词库条目）。

### 第 2 步 · 故事梗概 ★闸门 1
写清：主线与反转、出场人物与动机、时间地点与时间线、情绪曲线、贯穿道具、与前后集的衔接点。
**输出后必须停止，等用户确认。确认之前不得出结构方案，更不得出分镜。**

### 第 3 步 · 叙事结构方案 ★闸门 2
给 **3–4 种**方案，每种六要素：
①开场钩子 ②叙事视角 ③信息揭示顺序 ④悬念与反转落点 ⑤留存/完播设计 ⑥与前后集衔接。
支持组合（如 A+C＝结果前置＋倒叙回退），但组合必须写清两件事：**回退点落在剧本已有的时点**（不得为倒叙新增情节）、**在哪一镜切换结构**。
同时请用户指定**本集剧情重点**（哪 2–3 个节拍必须打中），并在方案表里预分配镜数与时长。
**输出后必须停止。用户选定结构并给出重点之前，不得写任何分镜。**

### 第 4 步 · 一致性锚点 ★闸门 3
- 角色锚点：外形（脸型/发型/服装单品）＋声线（音色/语速/口音）
- 贯穿道具常量表：材质、状态变化、复现位置
- 视觉常量：色彩/光影编码、视觉母题
- **空间座位关系图**：谁在哪、面朝哪、视线看谁、前景/深处、靠门还是靠通道

短篇模式在此加做**分幕分场表**（三幕配比、场次地图、弧光增量、情绪强度）。

### 第 5 步 · 时长规划与单元切分
先算账再写字：
1. 总时长 → 按结构分段 → 分到各场
2. 各场按原文顺序切生成单元（4–15 秒，目标 7–12 秒，**单元时长必须是整数秒**，如 7 秒而非 7.2 秒，单元不跨场景）
3. 逐句台词按语速验算（2.5–3.0 字/秒，紧张 3.0–3.5，抒情 2.0–2.5）
4. 台账三列：镜号 / 时长 / 累计

### 第 6 步 · 逐场分镜（分批交付）
- 每次交一场或 3–6 个单元，等确认再继续；一次输出全部必被截断。
- 每个单元自带：画幅、视觉风格、角色锚点、空间坐标**完整复写**，禁止"同上/同前"。
- 表单形态与 AI 单元形态同时产出（见第 4 节）。

### 第 7 步 · 三轮自检
①逐句映射 ②单元与账目 ③合规与规格。清单见覆盖层第七节，逐条打勾，结果随交付。

### 第 8 步 · 交付
交付物清单见第 4 节；末尾附：待确认项、合规风险提示、台词改动留痕表。

## 4. 输出契约

**默认交付（Excel 一个文件，多 sheet）**
| Sheet | 内容 |
|---|---|
| 分镜表 | 镜号 / 景别 / 时长 / 机位与运镜 / 画面内容与景深 / 台词·音效 / 情绪目标 / 画面参数·参考电影 |
| 技法映射 | 按需生成：镜号 / 单元 / 技法 / 落点 / 档位 / 参数片段（镜头 `tech` 有值才出） |
| AI 单元 | 每单元一段结构化文本（14 字段，禁止表格形态） |
| 锚点表 | 角色 / 声线 / 道具 / 视觉常量 / 空间座位图 |
| 自检 | 三轮自检记录 |
| 台词留痕 | 原句 → 改写句 → 理由（无改动则写"无"） |

**可选**：同内容的 Markdown / Word 版本（用户要才给）。

**工具**
- 写完一批先跑 `scripts/verify.py` 校验（字段/账目/镜号/违禁词/语速/情绪分级）。
- 校验通过后再跑 `scripts/build_xlsx.py` 生成 Excel 交付件。
- 数据格式与命令见 `scripts/README.md`。

**命名**：`{剧名}_S{集号}_分镜_v{n}.xlsx`；单文件多集时用 `{剧名}_S{起}-S{止}_分镜_v{n}.xlsx`。
**位置**：默认输出到用户工作目录下的 `输出/`；同名 JSON 源文件与 xlsx 一起交付，便于改完重跑校验。
**重点标注**：用户指定的剧情重点，在单元坐标后标【重点①】，并在汇报里单独列出"怎么加的"。

**编号规则**
- 镜号：竖屏/横屏 `S03-005`；短篇 `M3-S09-05`；子镜 `-1/-2`
- 单元号：`U01` 起全片连续
- 时间：一律"第 X.X 秒至第 X.X 秒"，0.1 秒精度

## 5. 硬规则速查（违反即返工）

1. 画幅、分辨率、时长上限以运行期参数为准，不得假设。
2. **三个停车点必须停**：梗概 → 结构方案（含用户指定剧情重点）→ 锚点卡。未确认不得越步，不得替用户选结构。
3. 单元 4–15 秒，目标 7–12 秒，**时长取整数秒**；单元内不跨场景。
4. 各镜合计 ＝ 各单元合计 ＝ 全片总时长，零误差。
5. 表演分三级：A 微表情用 FACS；B 峰值用可观察行为＋≤1 骨架参数；C 常态用意图＋行为。每镜节奏锚 ≤1 个。
6. 禁止牛顿/毫米/频率/肌群拉丁名等伪精确参数。
7. 台词可口语化，但必须留痕；不得增删信息与反转。
8. 超过 3 秒的对白：画外音贯穿 ＋ 0.6–0.8 秒反应镜 ＋ 切回"正在说"状态。
9. 声音四层（人声/核心音效/环境细节/空间混响），不写 BGM。
10. 镜头间只用硬切；文字一律后期叠加，AI 不生成可读文字。
11. 在场角色必须出镜；有台词的角色必须出镜。
12. 站位用物理方位＋相对关系，禁止裸"居左/居右"。
13. 手别、越肩方向、视线、位置、机位五者自洽；驾驶看后视只用后视镜。
14. 景别列只填 ELS/LS/FS/MS/中近景/MCU/CU/ECU/OTS；主观/半主观写进机位列。
15. 角度用汉字"度"；全片画幅统一。
16. 每个单元自包含；每个单元复写锚点与空间。
17. **技法落点唯一**：一条技法只落一格，不得跨列重复描述（55 §3）。同一效果在机位列写了，画面内容里不许再写一遍。
18. **档位纪律**：只用 T1/T2；T3 须按 55 §4 画幅改写后才可用；T4 禁投技法不得作为机位或运镜写法出现，一律改用 55 §7 替代并在衔接备注注明（CT08 拦截）。
19. **数值分层**：分镜层写「意图＋可观察行为」，禁毫米/每秒N次/FACS/光比数字；数值留给关键词层（45）。
20. **英文与典故隔离**：技法英文名（Dutch Angle / dolly zoom…）与影史典故不得进正文，「参考电影」列只写《片名》年份且 ≤1 部（CT07/CT05/CT06 拦截）。
21. **首单元首镜必须有钩子**：每集第一个单元的第一镜，第一帧就是异常（微距/黑场炸光/高速入画…，按 46 选一条），首镜时长压到 ≤2 秒，第二镜交接它；钩子写进「画面内容」，**不写进机位列**（CT11 只看首组首镜 0—2 秒，缺特征词即 warning）。
22. **运镜写三样，不写数**：轴／方向与落点／起止景别关系（按 43）；米数、度/秒、焦段、快门、f 值一律不写，留关键词层。
23. **光影写三件，不写数**：光源与方向／光质（硬或柔）／冷暖关系（按 44）；K 值与光比数字留关键词层，实景光源必须给画面里的位置。

## 6. 高频翻车点（写之前扫一眼）

| 翻车 | 症状 | 纠正 |
|---|---|---|
| 只闻其声 | 有台词但人在画外 | 补出镜镜或标明确设定（电话/广播/主观） |
| 串座串手 | 越肩方向反了、道具换手 | 回查空间座位图，逐条核五者自洽 |
| 大头贴干说 | 3 秒以上单人正脸念台词 | 插反应镜＋画外音 |
| 单元塞满 | 一单元跨两个场景 | 按场边界重切 |
| 全员同一镜头 | 群像堆在一起 | 拆多分镜＋独立反应镜 |
| 空镜凑时长 | 无信息画面填时间 | 换成细节镜/道具镜，必须带信息 |
| 情绪全克制 | 全片没有一次打中的峰值 | 高潮补 B 级峰值 |
| 账目对不上 | 镜头加总 ≠ 总时长 | 回第 5 步重算，不要改数字凑 |
| 同上/同前 | 第二组起省掉锚点 | 逐组复写 |
| 术语矛盾 | "长焦推 0.6 米""航拍小幅升降" | 换摇臂/变焦，量级匹配 |
| 技法堆叠 | 一镜写了「推近+甩镜+环绕」 | 只留 1 个主运镜，辅技法不得同轴（55 §5.1） |
| 技法串味 | 分镜表里冒出「倾斜12度」「每秒2次」 | 数值赶去关键词层，分镜层写看得见的结果（55 §8） |
| 典故入正文 | 正文写「参考《银翼杀手》的赛博感」 | 只进「画面参数·参考电影」，≤1 部（55 §7） |
| 横屏技法硬塞竖屏 | 竖屏写了航拍大远景 | 查 55 §4 替代或拆镜（55 §4.3） |
| 开场慢热 | 首镜还在摇全景交代环境、还在打字幕 | 换 46 的模板，第一帧就放异常（CT11 会 warning） |
| 钩子假预告 | 开场很炸，本集根本没发生那件事 | 钩子必须由本集核心事件当场兑现（46 §5） |
| 运镜只写名字 | 「缓缓推近」「镜头拉远」没有落点 | 补方向与落点、起止景别（43），不补米数 |
| 光只写感觉 | 「暖黄氛围光」「冷调侧光」 | 走 44 三件：光源与方向、光质、冷暖关系 |
| 手艺词进机位列 | 机位格里写「黑场起手」「倒放」 | 手法定式写画面内容，机位只写景别/角度/机位 |

## 7. 典型调用

**例 1**：用户发来剧本 + "画幅 9:16，1080×1920，单集 3 分钟内，红果"
→ 直接进第 1 步，出梗概，再出 3–4 结构方案。

**例 2**：用户只说"把这个剧本出成分镜"
→ 一条消息问齐：画幅、分辨率、模式、时长上限；说明"确认后我先给梗概和结构方案"。

**例 3**：用户给 10 集剧本
→ 先确认是全季规划还是逐集产出；逐集做时每集一套锚点，共用角色/道具常量表。

**例 4**：用户说"继续"
→ 读上一轮交付的锚点表与台账，从下一个单元接续，不重写已确认内容。
