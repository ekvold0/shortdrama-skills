# 短剧分镜头脚本生成

> **版本行**：`V2.13｜2026-11-26｜图像资产层 ＋ 记录镜头定式 ＋ 分镜图按档位 ＋ 多镜组与图锚 ＋ 提示词字数预算／数据契约 ＋ 场景卡（光线来源／拍摄规格）＋ 整场级前置单元与节拍 ＋ A/B 构图雷区 ＋ 角色卡六块（音色）；CT16–CT35`

- 技法只从 `references/55-技法选取-300条.md` 取一条已降维的写法。

- **只用 T1/T2**；T3 只在 55 §4 允许的画幅下用；**T4 一律走 55 §7 的等价替代**，并在衔接备注写「由 X 替代」。
- **一镜一主技法**：单镜 1 个运动类主技法，光影/色彩/构图类辅技法 ≤2，且不得与主技法抢同一运动轴（转动 vs 位移不可并存）。
- **一个效果一个落点**：同一效果不许在两列重复描述。
- **典故不进正文**：参考片只进「画面参数·参考电影」，写《片名》年份，全片 ≤1 部。
- 分镜层**禁量化**：不写毫米/每秒N次/FACS/光比数字——那是关键词层的活（见 55 §8）。

取料命令（不必整库读）：

```python
import sys; sys.path.insert(0, "scripts")
import cine_tech
cine_tech.by_slot("C3d 画面参数·运镜")   # 30 条候选
cine_tech.by_slot("C3e 画面参数·光影")   # 46 条候选
cine_tech.allowed(("T1", "T2"))          # 209 条可投池
```

## 1.6 写法层（技法管叫什么，写法库管这句话怎么写）

55 那套 300 条解决的是「这一招叫什么、什么档位、能不能投」；**「这一镜的话该写成什么样」在另外四份库里**：

| 要写的东西 | 读哪份 | 拿到什么 |
|---|---|---|
| 机位与运镜 | `43-运镜选型.md` | 十个轴 + 26 条运镜的分镜层写法定式（轴／方向与落点／起止景别） |
| 光影 | `44-打光选型.md` | 16 种布光的分镜层写法（光源与方向／光质／冷暖关系）+ 情绪→布光速查 |
| 每组前 2 秒 | `46-开场钩子.md` | 12 条钩子模板 + 短剧专属 4 条 + 堆叠规则 |
| 整场怎么切 | `47-类型分镜配比.md` | 八类题材的镜数/景别梯度/单镜时长/钩子/运镜/光位倾向 |
| 动作怎么连 | `45-表演与动作衔接.md` | 预备-动作-跟随、动作匹配切、重心与接触点 |
| 串起来快不快 | `48-节奏与剪辑.md` | 速度曲线、可读性三账、声音桥与静默、交付前复核 |

**执行顺序**：先按 47 定这场戏的形状 → 按 46 定首镜 → 按 43/44 写具体镜头 → 按 45 补动作三拍 → 整集切完用 48 过一遍速度与可读性 → 最后才去 55 查档位（T1–T4）确认这条技法能不能投。**倒过来会先拿到一个技法名再硬塞进画面，CT07/CT08 必爆。**

写法库四份都是**整篇读的**（不像 55 那样按落点查），它们没有条号，内容可以直接抄进分镜表，但不许当引用写。

## 2. 模式判定

| 模式 | 判定线索 | 结构要求 | 单镜上限 | 单元 |
|---|---|---|---|---|
| 竖屏短剧 | 9:16、单集 ≤3 分钟、强钩子 | 梗概＋结构方案（轻量） | 8 秒 | 4–15 秒 |
| 横屏短剧 | 横画幅、单集 1–3 分钟 | 梗概＋结构方案（轻量） | 10 秒 | 4–15 秒 |
| 短篇视频 | 10–15 分钟、完整起承转合 | **全片分幕分场规划（必做）** | 15 秒 | 4–15 秒 |

- 画幅**永远来自用户**，上表只描述典型画幅，不得拿来当默认值。
- 时长上限以用户给值为准；用户说"按平台常规"时，给建议值并请其确认。

## 3. 九步工作流

### 第 0 步 · 参数确认
收齐画幅、分辨率、模式、时长上限；确认交付格式。缺项按第 1 节处理。

### 第 1 步 · 规范研读
加载顺序：
1. `references/05-落地要求-覆盖层.md`（最高优先级，**必读**）
2. `references/00-通用内核.md`（方法底座）
3. 模式参数：`10-竖屏短剧.md` / `20-横屏短剧.md` / `30-短篇视频.md`
4. 用到才读：`40-表情微表情库.md`、`41-对话台词库.md`、`42-声音设计库.md`、`43-运镜选型.md`（写机位与运镜时）、`44-打光选型.md`（写光影时）、`46-开场钩子.md`（写每集首单元前必读）、`45-表演与动作衔接.md`（写动作与反应镜时）、`47-类型分镜配比.md`（第 5 步切单元前）、`48-节奏与剪辑.md`（第 5 步切完单元后、整集排完时）、`50-跨类型分镜法.md`、`55-技法选取-300条.md`（卡在机位/运镜/光影/景别时**按落点查**，别整篇读）、`60-范例库.md`

写法库（43/44/45/46/47/48）与技法库不同：**整篇读，先定写法再查档位**，见 1.6。

**打戏必读**：`references/53-武打动作组.md`（六阶段／轴线／八种拍法一次只选一型／3D漫风格化），并配 `templates/11-武打动作组模板.md` 逐镜填；动作物理参数交给关键词层 `references/56`，分镜层不写数值。

不得只看模板不看附件；每个分镜块要能指回它用了哪条方法（附件 4 条目 / 词库条目）。

### 第 2 步 · 故事梗概 ★闸门 1
写清：主线与反转、出场人物与动机、时间地点与时间线、情绪曲线、贯穿道具、与前后集的衔接点。
**输出后必须停止，等用户确认。确认之前不得出结构方案，更不得出分镜。**

### 第 3 步 · 叙事结构方案 ★闸门 2
给 **3–4 种**方案，每种六要素：
①开场钩子 ②叙事视角 ③信息揭示顺序 ④悬念与反转落点 ⑤留存/完播设计 ⑥与前后集衔接。
支持组合（如 A+C＝结果前置＋倒叙回退），但组合必须写清两件事：**回退点落在剧本已有的时点**（不得为倒叙新增情节）、**在哪一镜切换结构**。
候选不得凭空发散：必须按 `references/49-方案候选索引.md` 检索得出 **6–8 条**（钩子 4＋结构组合 3 为基准，每条带库名与条目来源），用户勾选后才写方案表。
同时请用户指定**本集剧情重点**（哪 2–3 个节拍必须打中），并在方案表里预分配镜数与时长。
**输出后必须停止。用户选定结构并给出重点之前，不得写任何分镜。**

### 第 4 步 · 一致性锚点 ★闸门 3
- 角色锚点：外形（脸型/发型/服装单品）＋声线（音色/语速/口音）
- 贯穿道具常量表：材质、状态变化、复现位置
- 视觉常量：色彩/光影编码、视觉母题
- **空间座位关系图**：谁在哪、面朝哪、视线看谁、前景/深处、靠门还是靠通道

短篇模式在此加做**分幕分场表**（三幕配比、场次地图、弧光增量、情绪强度）。

### 第 4.5 步 · 图像资产 ★闸门 3.5（V2.0）
锚点卡确认之后、切单元之前，把图备齐——**图不对，后面写多细都白搭**：

1. **无人场景图**（每场 1 张，覆盖所有可能入镜的墙面）→ 从它取色出**色卡**（`templates/08`）
2. **角色卡三类**（大脸／无头服装／背面后脑，`templates/09`；道具按道具另给）
3. **黑白线稿站位图**（多人调度必做，`templates/07`；不画脸、引线标名、换位换图）
4. 这套资产同时是关键词技能的输入——缺一张，关键词层的 `[图片N]` 就编不出来

> 这一步不是可选的美工：站位图决定"人会不会乱跑"，色卡决定"一场戏会不会三个色温"，大脸卡决定"换镜头会不会换人"。三者加起来就是 CT16–CT25 的判定对象。

### 第 5 步 · 时长规划与单元切分
先算账再写字：
1. 总时长 → 按结构分段 → 分到各场
2. 各场按原文顺序切生成单元（4–15 秒，目标 7–12 秒，**单元时长必须是整数秒**，如 7 秒而非 7.2 秒，单元不跨场景）
3. 逐句台词按语速验算（2.5–3.0 字/秒，紧张 3.0–3.5，抒情 2.0–2.5）
4. 台账三列：镜号 / 时长 / 累计

### 第 6 步 · 逐场分镜（分批交付）
- 每次交一场或 3–6 个单元，等确认再继续；一次输出全部必被截断。
- 每个单元自带：画幅、视觉风格、角色锚点、空间坐标**完整复写**，禁止"同上/同前"。
- 表单形态与 AI 单元形态同时产出（见第 4 节）。

### 第 7 步 · 四轮自检
①逐句映射 ②单元与账目 ③合规与规格 ④图像资产层（V2.0：记录镜头／站位图／色卡／参考链／分镜图／素材上限）。清单见覆盖层第七节与 `70-自检清单.md`，逐条打勾，结果随交付。

### 第 8 步 · 交付
交付物清单见第 4 节；末尾附：待确认项、合规风险提示、台词改动留痕表。

## 4. 输出契约

**默认交付（Excel 一个文件，多 sheet）**
| Sheet | 内容 |
|---|---|
| 分镜表 | 镜号 / 景别 / 时长 / 机位与运镜 / **动作** / 画面内容与景深 / 台词·音效 / 情绪目标 / 画面参数·参考电影 |
| 技法映射 | 按需生成：镜号 / 单元 / 技法 / 落点 / 档位 / 参数片段（镜头 `tech` 有值才出） |
| AI 单元 | 每单元一段结构化文本（14 字段，禁止表格形态） |
| 锚点表 | 角色 / 声线 / 道具 / 视觉常量 / 空间座位图 |
| 自检 | 三轮自检记录 |
| 台词留痕 | 原句 → 改写句 → 理由（无改动则写"无"） |

**可选**：同内容的 Markdown / Word 版本（用户要才给）。

**工具**
- 写完一批先跑 `scripts/verify.py` 校验（字段/账目/镜号/违禁词/语速/情绪分级）。
- 校验通过后再跑 `scripts/build_xlsx.py` 生成 Excel 交付件。
- 关键词稿已有时，再跑 `scripts/crosscheck.py --storyboard <本集 source.json> --keyword <关键词 kwdata.json>`：两边镜数、秒数、景别、台词对不上就在这里现形（X02/X03 硬错，X04–X07 账目警告）。
- 数据格式与命令见 `scripts/README.md`。

**命名**：`{剧名}_S{集号}_分镜_v{n}.xlsx`；单文件多集时用 `{剧名}_S{起}-S{止}_分镜_v{n}.xlsx`。
**位置**：默认输出到用户工作目录下的 `输出/`；同名 JSON 源文件与 xlsx 一起交付，便于改完重跑校验。
**重点标注**：用户指定的剧情重点，在单元坐标后标【重点①】，并在汇报里单独列出"怎么加的"。

**编号规则**
- 镜号：竖屏/横屏 `S03-005`；短篇 `M3-S09-05`；子镜 `-1/-2`
- 单元号：`U01` 起全片连续
- 时间：一律"第 X.X 秒至第 X.X 秒"，0.1 秒精度

## 5. 硬规则速查（违反即返工）

1. 画幅、分辨率、时长上限以运行期参数为准，不得假设。
2. **三个停车点必须停**：梗概 → 结构方案（含用户指定剧情重点）→ 锚点卡。未确认不得越步，不得替用户选结构。
3. 单元 4–15 秒，目标 7–12 秒，**时长取整数秒**；单元内不跨场景。
4. 各镜合计 ＝ 各单元合计 ＝ 全片总时长，零误差。
5. 表演分三级：A 微表情用 FACS；B 峰值用可观察行为＋≤1 骨架参数；C 常态用意图＋行为。每镜节奏锚 ≤1 个。
6. 禁止牛顿/毫米/频率/肌群拉丁名等伪精确参数。
7. 台词可口语化，但必须留痕；不得增删信息与反转。
8. 超过 3 秒的对白：画外音贯穿 ＋ 0.6–0.8 秒反应镜 ＋ 切回"正在说"状态。
9. 声音四层（人声/核心音效/环境细节/空间混响），不写 BGM。
10. 镜头间只用硬切；文字一律后期叠加，AI 不生成可读文字。
11. 在场角色必须出镜；有台词的角色必须出镜。
12. 站位用物理方位＋相对关系，禁止裸"居左/居右"。
13. 手别、越肩方向、视线、位置、机位五者自洽；驾驶看后视只用后视镜。
14. 景别列只填 ELS/LS/FS/MS/中近景/MCU/CU/ECU/OTS；主观/半主观写进机位列。
15. 角度用汉字"度"；全片画幅统一。
16. 每个单元自包含；每个单元复写锚点与空间。
17. **技法落点唯一**：一条技法只落一格，不得跨列重复描述（55 §3）。同一效果在机位列写了，画面内容里不许再写一遍。
18. **档位纪律**：只用 T1/T2；T3 须按 55 §4 画幅改写后才可用；T4 禁投技法不得作为机位或运镜写法出现，一律改用 55 §7 替代并在衔接备注注明（CT08 拦截）。
19. **数值分层**：分镜层写「意图＋可观察行为」，禁毫米/每秒N次/FACS/光比数字；数值留给关键词层（45）。
20. **英文与典故隔离**：技法英文名（Dutch Angle / dolly zoom…）与影史典故不得进正文，「参考电影」列只写《片名》年份且 ≤1 部（CT07/CT05/CT06 拦截）。
21. **首单元首镜必须有钩子**：每集第一个单元的第一镜，第一帧就是异常（微距/黑场炸光/高速入画…，按 46 选一条），首镜时长压到 ≤2 秒，第二镜交接它；钩子写进「画面内容」，**不写进机位列**（CT11 只看首组首镜 0—2 秒，缺特征词即 warning）。
22. **运镜写三样，不写数**：轴／方向与落点／起止景别关系（按 43）；米数、度/秒、焦段、快门、f 值一律不写，留关键词层。
23. **光影写三件，不写数**：光源与方向／光质（硬或柔）／冷暖关系（按 44）；K 值与光比数字留关键词层，实景光源必须给画面里的位置。
24. **动作写三拍**（按 45）：预备—动作—跟随；一镜只放一个完整动作组，大动作拆起势/完成/落定三镜；重心、支撑脚、手与道具的接触点都要写进「画面内容」。
25. **整集要有速度曲线**（按 48）：一处加速、一处减速、一个「呼吸」单元；不许连续 3 个单元都在 6 秒以下，也不许整集单元时长一个样（CT15）。每个切点都要有动机，声音桥不许跨出生成单元。
26. **跨段必收记录镜头**（V2.0，SB-02）：一次生成只能拍一个场景的一个角度。凡存在段边界（相邻两个单元属于不同次生成），**上一段末镜必须是记录镜头**——`24mm，时长 1 秒，景别大全景，运镜固定，镜头角度俯拍，承接上镜头的结束姿态，人物和道具物品强制静止一秒`，五条缺一条截出来就是糊的。**段内连续镜头不必做**（CT16 只在存在段边界时判，缺则 warning）。
27. **站位图是资产不是配图**（V2.0，SB-01）：换景别、换机位、有人走动之前，先按 `templates/07-站位图资产规范.md` 出一张黑白线稿站位图；**人物有换位就必须换一张**，不许在同一张图上改表情硬顶。线稿只描述静止姿态，运动路径写文字。
28. **空间四件套与视角一致**：站位图必须标出门／窗／主家具／通道四件参照，且与正式场景图同一视角（只允许画风差异）；每人一条引线写人物名，名字与角色卡、提示词逐字一致；**不画五官**（画了脸会被当长相参考吃掉）。
29. **色卡在场景图之前定**（V2.0，SB-07）：3–5 个主色必须从无人场景图取色并记 HEX，写进 `templates/08-色卡规范.md`；同场次色温漂移 > 800K 判越界。CT18 在关键词层拦四件事：色温偏差、正文色值必须来自色卡（不许现编 HEX）、每个 HEX 必须写 rom（取自场景图哪一处）、主色 3–5 个。
30. **角色卡三类拆开开**（V2.0，AS-01/AS-02）：大脸卡管长相、无头服装卡管衣服（颈根同高、上方留空灰底）、背面卡管后脑与头饰；道具卡按道具拆不按角色拆。**一张图只做一件事**，塞满三视图＋七张脸＋配饰的「标准角色卡」信息越杂串得越狠。
31. **参考链分双链**（V2.0，AS-05）：身份链（长相／发型／服装）永远引原始大脸卡、**禁止传递**；空间链（站位／墙／家具）允许逐段传记录帧，但必须同时挂原始场景图作依据（`scene_ref`）；链深 > 1 即 error（CT23）。
32. **分镜图是正式环节**（V2.0，SB-03）：资产统一之后、视频生成之前出关键帧，编号单镜组 `KB_{集号}_U{单元号}_v{n}.png`、多镜组 `KB_{集号}_U{单元号}_{镜号}_v{n}.png`（V2.4），路径写进分镜表；单元有编号无文件即 error（CT25）；资产变更后旧图必须作废重出。分镜图进关键词 `refs` 时标 `kind: board`——2.0 里它只是整组生成起点（`role: first_frame`，不许当单镜参考），2.5 flash/标准版才是逐镜画面参考（`role: shot_ref`）；分镜图**也占一张图片名额**（9/10/30 里要扣掉它，V2.12 平台实测），且不参与身份链（CT17/CT23）；2.5 里它可以兼首帧。
    - **预算紧时允许只抽 1/3 关键帧**（V2.2）：覆盖单元数 ≥ ⌈总单元数 ÷ 3⌉ 即可，但**三类关键单元一张都不能省**——① 跨段衔接处（段末且后面还有段）② 打戏单元 ③ B 级情绪峰值单元。省之前先想清楚：这三类省下来，段与段之间就没有锚点、打戏动作会断裂、高潮那一镜没处对。缺图即 error。
33. **一次生成能塞多少素材是硬上限**（V2.0）：Seedance 2.0 系列 9 图 / 3 视频 / 3 音频（音频不可单独用；本组生成 4–15 秒，单条参考 4–15 秒），2.5 flash 10/5/5（本组生成 4–30 秒，单条参考视频/音频 4–30 秒），2.5 标准版 30/10/10（本组生成 4–30 秒，单条 4–30 秒）。分镜阶段就要按档位留预算给 `[图片N]`——编号最省的是「一张站位图 + 一张场景图 + 每人一张脸卡」（CT17 在关键词层拦）。
33b. **短镜头在分镜阶段就定去路**（V2.2）：4 秒是生成地板，**三个档位都一样**，剧本里 1–2 秒的镜头不许留到生成时才处理——带信息且空间人物没变的并进相邻单元当一个 `shot`（组仍 4–15／4–30 秒）；带信息但换空间的，先看能不能用本空间的东西把这点信息讲完，讲不完说明它是过渡、砍掉用末帧接起幅；只负责打击感节奏的不进 AI 视频、用首尾静帧后期做。**允许"撑"（填真信息到 4 秒），不许为凑 4 秒注水**。判据：抽掉它观众会不会看不懂。写法见关键词 `references/40-画面参数.md` §短镜头，覆盖层见 `references/05-落地要求-覆盖层.md` A9。这条机器上是**双层拦**：`verify.py` 的 CT17 报「组时长低于档位下限 4 秒」，`run_generate.py` 的 `min_sec` 在投喂清单里再报一次。
34. **人物锚点不在分镜里现编**（V2.2）：真值源是项目根的 `角色锚点.json`，分两阶段填——先登记名字（`stage=names`），再补 `anchor`/`features`（→ `look`/`full`）；外貌列从 `anchor` 逐字复写，声线/体态/本集变化留在 `templates/04` 表里。锚点表还是示例或 `stage=names` 时不该出分镜图，流程见 `drama-pipeline-gate/references/角色锚点两阶段_v1.md`。
35. **短镜落地要写出来（V2.3）**：短于 4 秒的镜头在「短镜落地」列写 并进／后期／砍掉（默认并进）。判据是「抽掉这镜观众会看不懂吗」——会 → 并进；不会但缺节奏 → 后期；连节奏都不承担 → 砍掉。标了 砍掉 却仍留在单元里、或 ≥4 秒的镜头标 后期/砍掉，CT26 报 warning。
36. **单元上限 30 秒，但 2.0 只到 15 秒（V2.3）**：校验器上限按最高档位放开到 30 秒；单元超过 15 秒且没写 tier: 2.5 时，会提示「超 2.0 上限」——要那么长就显式写档位。
37. **多镜组一镜一句、单组最多 6 镜、镜里点名**（V2.5）：单元内 ≥2 镜时，关键词那一层的 `prompt` 要自带 `镜N（起-止 秒）：…；切点＝…`，标记数＝镜数（CT27）；镜里角色写名字，不许写「两人/三人/他们/大家」；末镜写整组收在哪。分镜图用 `[图锚 KB_...]` 指名（CT17）。
38. **分镜图只在 >15 秒的组里用**（V2.6）：4–15 秒（2.0）不挂分镜图，15–30 秒（2.5）才挂 `kind: board`；分镜图照常产出（1/3 抽帧），它仍是站位锚点与自己的出图交付物（CT17）。
39. **整集一套风格包**（V2.6）：`data.style_pack` ∈ `modern_live`／`ancient_period`／`3d_stylized`，分镜图提示词第 0 段的风格前缀从这里取，不再每张现编（CT28）。
40. **风格前缀只有一份正文**（V2.8）：第 0 段照抄 `ct_rules.STYLE_PACKS[pack]["prefix"]`（`scripts/ct_rules.py` 里的 `style_prefix()` 能直接打印），`templates/10-分镜图提示词.md` 里那三段只是副本，测试会核对两边一致——别在别处另起一套。
41. **原生配音进资产表**（V2.8）：平台原生配音抽出来之后登记进 `assets.audios[]`（`id`／`file`／`group`／`version`／`from_native`），组的 `refs[].kind` 写 `audio`，文件名要对得上（CT29）。资产根统一用 `--assets-root`（＝项目的 `资产/` 目录），`file` 写含子目录的相对路径。
42. **多镜组的分镜图要带镜号**（V2.9）：`assets.boards[].shot` 填 `S01`/`S02`，逐镜各一张；关键单元（跨段衔接／打戏／B 级峰值）缺镜判 error，普通多镜组缺镜给提示（CT25）。
43. **落库命名两件套**（V2.9）：文件 `<剧名>_<组号>_v<版本>.mp4`、画布节点标题 `<组号>`（补帧 `_补帧`）——`gate.py assets` 只按节点标题认组，标题不带组号这条素材就进不了账。
44. **首帧唯一、只认分镜图**（V2.10）：一组只能有一张 `role: first_frame`，且必须 `kind: board`；资产图 role 只写 `look_ref`／`cloth_ref`／`item_ref`／`scene_ref`，标错会被算进图片名额（CT31）。
46. **提示词字数有预算**（V2.12，平台实测）：**2.0 上限 4000 字、2.5（含 flash）10000 字以内**，软预算取 3/4；超了优先拆组，别赌平台不截断（截断的表现是后半截镜头不生成）。
47b. **分镜图占名额、可兼首帧**（V2.12，平台实测）：`kind: board` 那张**也占一张图片名额**（2.0 的 9 张要扣掉它，CT17 按 `pics = len(have)` 判）；2.5 里可以兼首帧（`shot_ref` ＋ `first_frame` 写同一张），一组仍只一张首帧（CT31）。
47. **数据契约三件**（V2.11）：分镜数据写 `schema: "sbdata/1"`；`meta` 键名照 `META_KEYS` 写（`epsoide` 这类笔误会被提示）；资产桶内 id 不许重复（CT33）。
45. **角色开剧一次定完**（V2.6）：通读全部剧本定下角色全集，按首次出场形象出卡，跨集沿用；只有剧本明确换装/造型变化才升 `v{n}`，同一角色换衣服不是新角色。
48. **场景卡三块写全**（V2.13，SB-07/CT34）：场景图必须回答三件事——环境要素（含 HEX 色彩基调，色卡的来源）、光线与光影（**光源类型·来向·色温·光比·影子·氛围**，只写「光线柔和」等于没写）、拍摄规格（写实装 ARRI ALEXA 35/65/Mini LF ＋ Signature Prime/Master Prime/Prime DNA，T2.8–4；3D 漫画风走风格包）。规则见 `templates/13-场景图资产规范.md`；顺序永远是 场景图 → 取 HEX → 色卡，不许先编色值。
49. **整场级前置单元 + 节拍表**（V2.13）：每场开戏之前先写摄影机与色彩基线、全局限制（强制有／强制无）、角色站位详述（站位图的文字版，多主体一律点名）；节拍 **2–4 个**（少于 2 戏不够、多于 4 拆场），镜头数 <3 要补、>8 要拆。规则见 `references/57-节拍与反模式.md`。
50. **A/B 雷区分开管**（V2.13）：A 类是艺术性（正面居中／头顶贴边／死压中线／眼神无空间／断关节／背景过亮／多人正面平铺），要在组头写「解锁：编号＋为什么＋试过什么」且同组最多解一次；B 类是工程性（物体穿身／服装突变／杂乱前景／比例失调／重复元素／空鸡蛋构图／道具状态突变）**永不解锁、只能改写**（例：穿身写成「手在桌沿上方」，比例失调给尺度参照「碗口约一掌宽」）。规则见 `references/58-构图雷区.md`。
51. **角色卡六块，音色单列**（V2.13，AS-01/CT30）：①五官 ②发型 ③服装 ④化妆 ⑤随身道具 ⑥音色。身份证（脸型／骨相／五官／肤色／体态／永久识别点／音色）跨集永不变；发型／妆容／服装／配饰／道具／伤妆可随剧情变——换服装只升服装卡版本，**脸卡永远引原始那张，不许拿上个服装版再生成**。音色写七项（类型／质感／语速／重音／情绪基线／口音／TTS 标签）并落到 `anchors.characters[].voice`，关键词层 `sfx_layers.voice` 只能照抄。

## 6. 高频翻车点（写之前扫一眼）

| 翻车 | 症状 | 纠正 |
|---|---|---|
| 只闻其声 | 有台词但人在画外 | 补出镜镜或标明确设定（电话/广播/主观） |
| 串座串手 | 越肩方向反了、道具换手 | 回查空间座位图，逐条核五者自洽 |
| 大头贴干说 | 3 秒以上单人正脸念台词 | 插反应镜＋画外音 |
| 单元塞满 | 一单元跨两个场景 | 按场边界重切 |
| 全员同一镜头 | 群像堆在一起 | 拆多分镜＋独立反应镜 |
| 空镜凑时长 | 无信息画面填时间 | 换成细节镜/道具镜，必须带信息 |
| 情绪全克制 | 全片没有一次打中的峰值 | 高潮补 B 级峰值 |
| 账目对不上 | 镜头加总 ≠ 总时长 | 回第 5 步重算，不要改数字凑 |
| 同上/同前 | 第二组起省掉锚点 | 逐组复写 |
| 术语矛盾 | "长焦推 0.6 米""航拍小幅升降" | 换摇臂/变焦，量级匹配 |
| 技法堆叠 | 一镜写了「推近+甩镜+环绕」 | 只留 1 个主运镜，辅技法不得同轴（55 §5.1） |
| 技法串味 | 分镜表里冒出「倾斜12度」「每秒2次」 | 数值赶去关键词层，分镜层写看得见的结果（55 §8） |
| 典故入正文 | 正文写「参考《银翼杀手》的赛博感」 | 只进「画面参数·参考电影」，≤1 部（55 §7） |
| 横屏技法硬塞竖屏 | 竖屏写了航拍大远景 | 查 55 §4 替代或拆镜（55 §4.3） |
| 开场慢热 | 首镜还在摇全景交代环境、还在打字幕 | 换 46 的模板，第一帧就放异常（CT11 会 warning） |
| 钩子假预告 | 开场很炸，本集根本没发生那件事 | 钩子必须由本集核心事件当场兑现（46 §5） |
| 运镜只写名字 | 「缓缓推近」「镜头拉远」没有落点 | 补方向与落点、起止景别（43），不补米数 |
| 光只写感觉 | 「暖黄氛围光」「冷调侧光」 | 走 44 三件：光源与方向、光质、冷暖关系 |
| 动作没起势 | 人突然站起来、手凭空抓住道具 | 补预备与跟随，重写这三镜（45 §一） |
| 一个速度走到底 | 整集十二个单元全是 8 秒 | 排速度曲线：一快一慢一呼吸（48 §二） |
| 每镜都切 | 1 秒一镜连切六个，观众什么也没记住 | 换成 3 个 2 秒镜（48 §三） |
| 手艺词进机位列 | 机位格里写「黑场起手」「倒放」 | 手法定式写画面内容，机位只写景别/角度/机位 |

## 7. 典型调用

**例 1**：用户发来剧本 + "画幅 9:16，1080×1920，单集 3 分钟内，红果"
→ 直接进第 1 步，出梗概，再出 3–4 结构方案。

**例 2**：用户只说"把这个剧本出成分镜"
→ 一条消息问齐：画幅、分辨率、模式、时长上限；说明"确认后我先给梗概和结构方案"。

**例 3**：用户给 10 集剧本
→ 先确认是全季规划还是逐集产出；逐集做时每集一套锚点，共用角色/道具常量表。

**例 4**：用户说"继续"
→ 读上一轮交付的锚点表与台账，从下一个单元接续，不重写已确认内容。
