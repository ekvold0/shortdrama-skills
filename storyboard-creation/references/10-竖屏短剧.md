# 竖屏短剧参数（V2.2 适配）

> 只写竖屏模式**特有**的数值与偏好；通用方法见 `00-通用内核.md`，规则冲突以 `05-覆盖层` 为准。
> 画幅：**以用户当次给出为准**（典型 9:16），本文不提供默认值。

---

## 一、基本规格

| 项 | 值 |
|---|---|
| 成片时长 | 单集 ≤2 分 59 秒（不得达到或超过 3 分钟；上限以用户参数为准） |
| 生成单元 | 4–15 秒，目标 7–12 秒，**整数秒** |
| 单镜基础时长 | 3–5 秒 |
| 强冲突/强钩子/特写 | 1–3 秒 |
| 单镜上限 | 8 秒（无特殊叙事需求严禁超过） |
| 空镜/反应/动作镜 | 最长不超过 5 秒 |
| 情绪点密度 | 每 3–5 个镜头一个情绪点/冲突点/反转点 |
| 平铺上限 | 禁止超过 10 秒的无冲突、无情绪、无信息画面 |

---

## 二、画幅与构图

- 主体**居中**，上下各留约 10% 安全边距（给状态栏与字幕）。
- 关键信息不得落在画面上下边缘：字幕区、平台 UI 区一律避让。
- 竖屏纵向调度优先：人物上下楼梯、起身/坐下、抬头/低头、升降运镜都比横移更有效。
- 双人同框用中近景，三人以上同框慎用；群像拆成多个分镜与反应镜。
- 倾斜（荷兰角）角度不宜过大，避免人物出框。

---

## 三、景别偏好（严控远全占比）

| 景别 | 竖屏用法 | 时长 |
|---|---|---|
| ELS | 非必要不用；仅世界观建立、空镜转场 | ≤3 秒 |
| LS | 场景开篇定调、大场面；严控频次 | ≤3 秒 |
| FS | 仅场景开篇、全身动作、站位交代 | ≤4 秒 |
| MS | 3 人及以内同框、短动作戏 | 3–5 秒，非必要不用 |
| 中近景 | 双人对话、小范围肢体调度 | 2–5 秒 |
| MCU | **核心主力**：对白、单人叙事、情绪传递 | 2–4 秒 |
| CU | 强情绪、冲突爆发、关键线索、钩子 | 1–3 秒 |
| ECU | 极致情绪、关键揭示、钩子 | 1–2 秒 |
| OTS | 对话建关系；前景肩膀占比不宜过大 | 2–4 秒 |

**整体配比参考**：近景/特写/中近景合计 ≥ 60%，全景与远景 ≤ 20%，其余为中景。

---

## 四、机位偏好

- 对话主力：**2、3 号平行机位**（近景/特写正反打），穿插 4、5 号过肩建立空间。
- 1 号主机位只在场的开篇用一次，收尾可再用一次。
- 6、7 号内反拍用于情绪强调与重要台词。
- 仰拍可利用纵向空间强化高大感；俯拍强化压迫与无助。
- 运镜优先短距离精准推拉，禁止无意义炫技；跟拍幅度要小，避免画面剧烈晃动导致眩晕。

---

## 五、节奏与钩子

- 开篇 **前 3 秒**必须有强冲突、强悬念、强反转或强视觉奇观的钩子。
- 情绪前置：先给情绪/冲突，再给叙事铺垫，避免铺垫过长被划走。
- 每 3–5 镜一次起伏（递进、反转、释放）。
- 集末钩子：悬念收尾，**纯黑 ≤1 秒**，用声先入或"心跳漏拍"式收尾，不用长黑屏。

---

## 六、画面与声音偏好

- 画面信息密度高：一镜至少一个信息点（人物关系、道具、状态、环境变化）。
- 同组不跨场景；镜头间硬切。
- 文字（字幕、时间卡、UI、标牌）后期叠加，AI 只生成窗口/色块/框架。
- 声音四层写足；竖屏多为手机外放，人声必须清晰压过环境层，环境细节不可盖台词。

---

## 七、竖屏常见错误

| 错误 | 后果 | 纠正 |
|---|---|---|
| 照搬横屏构图，人物贴边 | 手机上看不见主体 | 主体居中，左右留边 |
| 大量全景/远景 | 人物太小，情绪传不到 | 换 MCU/CU |
| 三人以上挤一镜 | 脸都看不清 | 拆反应镜 |
| 单镜 8 秒以上不动 | 划走 | 拆镜或加调度 |
| 前 3 秒在铺环境 | 完播率崩 | 钩子前置 |
| 字幕压脸 | 信息丢失 | 上下 10% 留白 |
