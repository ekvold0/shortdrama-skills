# 声音设计库

> **四层结构（强制）**：人声 / 核心音效 / 环境细节 / 空间混响。
> **不写 BGM、不写配乐叙事**。声音母题（某个音效反复出现）可以替代配乐的情绪功能。
> 声音必须嵌进时间段，与画面同一条时间线，精确到 0.1 秒。

---

## 一、环境音与音效（20 类）

| 音效 | 写法要点 | 情绪功能 |
|---|---|---|
| 环境底噪 | 森林＝风叶＋远处鸟虫；城市＝交通低频＋喇叭＋人声嗡鸣；室内＝空调低鸣＋钟滴答；海边＝浪＋鸥 | 空间真实感 |
| 脚步声 | 按材质分：木地板咚、水泥脆、草地沙、雪地嘎吱、碎石细碎、积水溅 | 存在感、节奏、情绪 |
| 呼吸声 | 平静几乎不可闻；深呼明显；急促短快；喘息粗重；屏息骤停；叹息长呼 | 生理与情绪强度 |
| 心跳声 | 正常微弱不可闻；紧张明显；恐惧如鼓；可逐渐盖过其他声 | 紧张、恐惧、主观 |
| 风声 | 微风沙沙→中風呼呼→强风呼啸→暴风轰鸣 | 空旷、孤独、危险 |
| 雨声 | 小雨细密、中雨持续、大雨白噪、暴雨轰鸣；不同材质落雨音色不同 | 忧郁、隔绝、浪漫 |
| 雷声 | 远雷低沉 2–5 秒，近雷炸裂，连续雷叠加；延迟反映距离 | 威慑、高潮、天罚 |
| 金属碰撞 | 兵器尖锐＋余音；刮擦尖啸；落地沉重＋弹跳；断裂清脆 | 危险、战斗、力量 |
| 玻璃破碎 | 爆裂＋碎片落地；裂缝尖啸不碎；踩碎细碎碾压 | 冲击、脆弱、暴力 |
| 门声 | 开门铰链吱嘎；关门砰声（力度＝情绪）；敲门的节奏＝情绪 | 空间转换、悬念 |
| 武器出鞘 | 金属摩擦滑音 0.3–1 秒＋余鸣 | 仪式感、危险信号 |
| 枪声 | 手枪砰＋短回声；步枪更尖；霰弹低沉轰；消音压抑噗 | 危险、冲突 |
| 爆炸 | 小型砰＋碎片；大型轰鸣＋低频冲击＋倒塌；远处沉闷＋延迟；之后常接耳鸣或静默 | 震撼、灾难 |
| 水声 | 滴水、流水、浪拍、溅水、水下沉闷、水泡咕嘟 | 自然、危险、洁净 |
| 动物声 | 鸟鸣、犬吠（警觉/友好）、猫叫、马嘶、狼嚎、虫鸣 | 环境、季节、预警 |
| 机械声 | 引擎低频、齿轮节奏、液压嘶声、电子蜂鸣、持续运转 | 科技、工业、紧张 |
| 火焰 | 小火噼啪、中火燃烧＋爆裂、大火轰鸣、熄灭嘶声 | 温暖、毁灭、野性 |
| 纸张布料 | 翻书哗啦、撕纸干脆、纸落啪嗒、布料沙沙、衣物呼呼 | 细节真实感 |
| 身体接触 | 拳击闷啪、踢击砰、摔倒沉重＋滑动、骨断喀嚓、拍手脆、拥抱轻 | 暴力、冲击、亲密 |
| 环境音景 | 至少三层：近景（呼吸/脚步/衣物）＋中景（交通/人群/风）＋远景（火车/警笛/海） | 沉浸、空间完整 |

## 二、空间与混音（15 种）

| 手法 | 参数感觉 | 用途 |
|---|---|---|
| 近景声 | 音量最大、清晰度最高、混响最小，能听见气息与衣物 | 亲密、聚焦、主观 |
| 远景声 | 音量小、细节模糊、混响多 | 空间深度 |
| 声音透视 | 走近＝变大变清；走远＝变小变糊 | 动态空间 |
| 混响空间 | 小房间 <0.5 秒；大厅/教堂 >2 秒；户外几乎无；洞穴特殊回声；水下闷 | 空间感知 |
| 立体声定位 | 画面左侧声源出左声道，移动物体声道间移动 | 方向感 |
| 淡入淡出 | 从无到有 / 从有到无，速度影响情绪 | 过渡、开始与结束 |
| 声音叠加 | 至少 3 层，底噪＋主声＋装饰声，有明确音量比例 | 丰富、真实 |
| 声音隔离 | 只留一个声源（心跳、呼吸、一步），其余骤降 | 极致专注、孤独 |
| 声音延迟 | 画面先到、声音后到 0.5–5 秒 | 距离、真实 |
| 声音前置 | 下一场的声音提前 0.5–2 秒进入 | 流畅过渡、悬念 |
| 降噪/静音 | 骤降或全静；静音后的第一个声音冲击最大 | 死亡、震惊、失聪 |
| 主观声音 | 心跳放大、耳鸣、发闷、变清晰 | 心理状态 |
| 声音对比 | 极响↔极静、极复杂↔极简单 | 强调、转折 |
| 循环声 | 自然循环（雨/浪）几乎不被注意；异常循环（重复脚步/卡带）制造焦虑 | 时间感、异常 |
| 声音蒙太奇 | 不同时空声音叠加或交替 | 多线、内心混乱 |

## 三、声音与画面的关系（10 种，去掉配乐两条）

| 关系 | 做法 | 用途 |
|---|---|---|
| 声画同步 | 对白对口型、动作对音效、环境对场景 | 基础真实感 |
| 声画对位 | 声音与画面有意错位（暴力配优雅声、悲伤配轻快声） | 讽刺、张力 |
| 画外音 | 声音来自画面外 | 旁白、内心、回忆 |
| 声音前置/后置 | 先闻其声 / 画面切了声音还在 | 过渡、余韵 |
| 声音为情绪服务 | 悲伤场简化环境、突出一个音 | 情绪强化 |
| 声音为节奏服务 | 重音落在剪辑点 | 动作、追逐 |
| 声音为叙事服务 | 远处警笛＝危险逼近、鸟鸣骤停＝异常、门外脚步＝有人来 | 悬念、信息 |
| 声音标记（母题） | 某角色/场景/情绪绑定一个固定声音 | 辨识、主题统一 |
| 声音对比蒙太奇 | 极响→极静快速切换 | 高潮前后 |
| 声音后置余韵 | 换场后前一场景声音延续 0.5–3 秒 | 情感延续、诗意 |
| 声音骤停 | 无淡出直接切断 | 死亡、震惊 |
| 渐强 | 从极低渐强至顶点，层次逐步加入 | 高潮逼近 |

> 说明：`音乐叙事`（画面内可见声源）与`非叙事音乐`（配乐）两条**不进分镜块**。
> 若用户明确要后期配乐建议，另附一页"后期配乐建议"，不占分镜字段。

## 四、特殊声音效果（10 种）

| 效果 | 做法 | 用途 |
|---|---|---|
| 耳鸣 | 爆炸后所有声音发闷＋持续高频嗡声，数秒后恢复 | 失聪、冲击后 |
| 水下声 | 高频削弱、低频增强、整体压抑模糊＋水泡 | 溺水、窒息、隔离 |
| 慢动作声 | 声音拉长降调、细节放大、环境弱化 | 子弹时间、关键时刻 |
| 快速声 | 声音加速升调、变尖、细节压缩 | 时间加速、喜剧 |
| 回声重复 | 多次延迟重复，次数与间隔反映空间 | 洞穴、空旷、记忆 |
| 声音扭曲 | 延迟、重混响、变调、滤波 | 梦境、精神异常 |
| 电话音质 | 带通滤波，只留中频，薄而扁、有颗粒 | 电话、录音、监控 |
| 广播音质 | 带通稍宽、轻微噪与失真、音量微波动 | 时代感、怀旧 |
| 空间旋转 | 声道循环移动 | 眩晕、环绕运镜 |
| 静默设计 | 完全静音 0.5–10 秒，画面继续或定格 | 死亡、重大揭示 |

## 五、声音写作规则（硬）

1. 每个单元必须四层齐全；确实没有的层写"无"，但要说明为什么（如"环境细节：无，静默设计"）。
2. 声音写进时间段：`第 X.X–X.X 秒｜人声：……`，不得只在开头罗列。
3. 人声优先级最高：环境与音效不得盖住台词；手机外放场景尤其要注意。
4. 静音是武器，一场戏最多用一次；用之前要有声音铺垫，用之后要有对比。
5. 声音母题至少复现 2 次才成立；只出现一次的叫音效，不叫母题。
6. 不写"配乐渐起""BGM 推向高潮"——改成具体的音效或环境变化（如"远处火车声由远及近，压过室内"）。

## 六、一段标准写法（示例）

```
【本分镜音效】
人声　第 0.0–3.2 秒｜林知夏（轻声、语速放慢）：爸，趁热吃。
核心音效　第 1.2 秒｜碗底磕在木桌上，一声；第 3.0 秒｜木凳腿刮过地面，短促。
环境细节　第 0.0–8.0 秒｜清晨街面远处叫卖、锅内余火轻响；第 5.5 秒｜窗外鸟叫两声。
空间混响　小面馆，短混响约 0.4 秒；后厨方向声音略闷。
```
