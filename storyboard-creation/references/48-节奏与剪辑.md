# 节奏与剪辑（分镜层写法）

`47-类型分镜配比.md` 管「这个题材该拆成几个单元、每单元几镜」；这一份管**串起来之后的速度感**，以及**观众看不看得清**。

源材料是 lemo-opuscar 的 `DIRECTOR.md` §7（节奏）、§8（镜头）与 §11（交付前后复核），已按真人短剧分镜改写过。它那套 cue map／配乐网格没有搬——本技能禁 BGM。

注意：分镜层不写画面参数数值（厘米、度、焦段、f 值），但**时长列是数、必须写**，两者不矛盾。

---

## 一、评判顺序：声音、节奏、镜头、调度

原库第一句就是这个顺序：**sound, rhythm, camera, directing**，好看只是起点。

落到分镜上：先排声音落在哪、再排整集的快慢、最后才挑机位景别。反过来（先想这个角度帅不帅）就会得到一堆好看但接不起来的镜头。

## 二、一集的速度曲线

| 记号 | 要求 | 怎么落 |
|---|---|---|
| A | **一处明确加速** | 连续 2–3 个单元压到 4–6 秒、每单元 3–4 镜、单镜 1–3 秒 |
| B | **一处明确减速** | 加速之后还回来：一个 10–15 秒单元、2–3 镜、单镜 4–6 秒 |
| C | **一个「呼吸」** | 全集最静的单元：单镜长镜不切，或一个人物不动的停顿（画面里必须有事件，不能是空镜凑时长） |
| D | 别每镜都切 | 不许连续 3 个单元都在 6 秒以下；不许整集单元时长一个样 |

- 「呼吸」单元不是废镜——是观众消化信息的那一段。人物在动脑、在忍、在听，都算。
- 加速靠**更少的字 + 更短的镜**，不是把台词念快。

## 三、剪辑密度与单镜时长

- 原有规则不变：舒缓镜 3–6 秒、冲突镜 1–3 秒、单镜上限竖屏 8／横屏 10／短篇 15 秒。
- 补一条判断：**同样 6 个镜，1 秒一镜连切不如 3 个 2 秒镜**。切得太碎，观众记不住画面，也会放大 AI 生成的抖动。
- 对白超过 3 秒必须插反应镜——这条同时是节奏手段：把长台词切成「说／听／说」，速度自然有变化。

## 四、可读性三账

| 账 | 判据 |
|---|---|
| **台词账** | 台词说完到单元结束至少留 0.6 秒；单句台词不少于 1.8 秒 |
| **动作账** | 关键动作（抬手、摔、转身、递物）要留够看得懂的尾帧，不许动作做到一半就切 |
| **信息账** | 关键道具/文字画面至少 1.2 秒；纯文字卡至少 4 秒 |

中文台词的粗略换算：**字数 ÷ 4.5 + 1.5 秒**（例：9 字 → 3.5 秒），和关键词层 2.25 字/秒 的账互相校验，取大的那个。

## 五、主体可读性（AI 生成最容易出的事）

原库列的「最常见失败」几乎全适用，分镜阶段就要规避：

1. 主体太小、太远、被挤到画面边缘（竖屏 9:16 尤其）。
2. 暗到看不清，或同色叠同色（深衣人站深色墙前）。
3. 文字/字幕压住人物脸。
4. 关键动作快到来不及看懂。
5. 切点落在空白帧、纯色帧上。
6. 关键时刻**主体至少占画面高度三分之一**，剪影要读得出来。

写法：把这些写进「画面内容」（「她占画面高度约三分之一，背景亮、人偏暗」），不要只写景别——景别不等于占比。

## 六、用声音做转场

- 本技能只用硬切、禁转场特效，但可以用**声音桥**把两个镜头缝起来：上一镜的声音延续进来、下一镜的声音提前出现。
- 只允许在**同一生成单元内**使用。跨单元的声画错位属于剪辑层，写进「衔接备注」让后期做，不要写进音频列。
- 一场戏的转折或情绪高峰前，**至少放两处真静默**（不是「安静」，是完全没有声音），静默之后的第一个声音要是这一场最重要的声音之一。

## 七、交付前的复核

不是分镜阶段的活，但要知道下游怎么验，才能写对：

- **接触印相表**：每 1–2 秒抽一帧排成一张表，至少看两遍（一遍看构图与连续性，一遍看主体是否可读）。
- 关键动作按 0.2 秒间隔抽条带看（细节见 `45-表演与动作衔接.md` §七）。
- **带声全速看一遍**——静音看片会漏掉一半问题。
- **只修一轮**：第一轮把问题全改掉，第二轮只捡小问题。一轮之后还在改，通常是结构有问题，要退回单元切分那一步。

## 八、别做成「模板的重演」

如果你参考了某个范例（`60-范例库.md`），成片要和它比六项：结构、开场、招牌镜、机位路径、声音形状、结尾——**至少四项不同**。六项全一样就是抄，不是参考。

跨集同理：第 N 集和第 N−1 集比这六项（结构、开场、招牌镜、机位路径、声音形状、结尾），**至少四项不同**。二十集短剧最常见的死法是「每集都从同一个视角开场、同一个机位收尾」，观众第五集就腻了——这与「保持风格一致」不矛盾：一致的是视觉常量，不是镜头路径。

## 九、机器能拦到哪

| 项 | 谁管 |
|---|---|
| 首单元前 2 秒没有钩子 | CT11（warning） |
| 相邻单元时长完全一致、连续 ≥3 个 | CT15（分镜层与关键词层都查，warning） |
| 一镜多主运镜 | CT03（warning） |
| 主体占比、明暗差、空白帧、静默位置 | 判不了，靠 `70-自检清单.md` 与人工 |

## 十、自检

- [ ] 有 A 加速、B 减速各一处
- [ ] 有一个「呼吸」单元，且里面有事发生，不是空镜
- [ ] 没有连续 3 个单元都在 6 秒以下，全片单元时长不是同一个数
- [ ] 每句台词后留够 0.6 秒，没有台词顶到单元末
- [ ] 关键动作留了能看懂的长度
- [ ] 主体占比与明暗差检查过，没有太小／太暗／同色叠同色
- [ ] 声音桥都在单元之内，跨单元的已写进衔接备注
- [ ] 有至少两处真静默，且放在转折或高峰之前
