# 范例库

> 目的：给"写多细、写成什么样"定标尺。范例不是模板照抄，是对齐颗粒度。
> 注意：范例 1–2 来自基础规范的旧写法，**保留原样作对照**；范例 3 是 AI 单元的标准形态；范例 4 展示按新规则改写后的差异。

## 范例 3 · AI 生成单元（标准形态，照此颗粒度写）

```
【幕场坐标】M3-S08 / 单元 U37（高潮段，厨房学做面）
【分镜号】M3-S08-04
【原文片段】"她照着账本上的方子，第三次揉面，额角渗出汗，面团终于在掌心里变得光滑听话。"
【画幅】9:16（运行期参数）｜1080×1920
【视觉风格】写实电影感、暖黄灯光、低饱和暖色调、清晨厨房蒸汽质感，浅景深为主
【出场角色】林知夏（26 岁，按角色参考图）、面团（拳头大小，表面由粗糙渐光滑）、木质案板、面粉
【时间坐标】清晨（天刚亮）｜【年代】当代·江南小城｜【日期】冬季·老街面馆厨房
【气候天象】室外约 3 度干冷；室内灶台余温约 18 度；无风雨，窗玻璃有薄雾
【时间线与子镜头】
第 0.0–6.0 秒｜中近景，斜侧 45 度，机位与案板齐平，中等景深，固定机位：林知夏在画面中央偏右，身体朝案板、上身前倾；双手掌根压在面团上，以稳定节奏向前推揉、每次前移约一掌再折回，面粉在案板上留下浅痕；非聚焦主体：灶上蒸锅盖缝持续冒白汽，背景围裙下摆随穿堂风轻摆。
第 6.0–11.0 秒｜特写(CU)，俯拍案板约 50 度，浅景深聚焦双手与面团，机位以极缓速度推近：面团表面从有细小裂纹，到随揉压逐渐消失、转为微微光滑反光；第 8.2 秒她右手手背抬起蹭过额角、留下一道薄粉，额角一滴汗沿太阳穴缓慢下滑。
第 11.0–15.0 秒｜近景(MCU)，平视斜侧，中景深，固定机位：第 11.2 秒她停手，双手把面团托在掌心，面团成形为光滑椭圆；第 12.0 秒肩膀下沉、长长吐出一口气；第 13.0 秒嘴角提了一下又收住，视线落在面团上；非聚焦主体：蒸锅蒸汽持续，窗外天色由青蓝转暖白。
【动作物理化拆解】
第 0.0–9.0 秒：双臂掌根交替前推下压，每推一次折回，动作稳定；第 8.2 秒右手抬至额角蹭一下（一个动作，不重复）；第 11.2–12.0 秒双手托面、肩下沉、呼气；全程躯干前倾。
【情绪物理化拆解】
第 0.0–8.0 秒（C 级）：专注、绷着——眉头轻蹙，下唇抿住，呼吸偏快，眼睛只盯着面团。
第 9.0–12.0 秒（C 级转 B 级）：松下来——眉头舒展，呼气，肩膀沉下去。
第 13.0–15.0 秒（A 级微表情）：嘴角提了一下又压回去，眼里有一点亮，随即收回。
【本分镜对白】无。
【本分镜音效】
人声　无。
核心音效　第 0.0–11.0 秒｜面团按压的闷响，一下一下；第 8.2 秒｜衣袖蹭过皮肤的轻响。
环境细节　蒸锅水汽的嘶声持续；窗外清晨街面偶有车声。
空间混响　小厨房，短混响约 0.4 秒，蒸汽让高频略闷。
【衔接备注】上接 U36（第二次揉面失败、面团开裂、她蹙眉撒粉）：本单元开场面团仍带裂纹、案板面粉量与 U36 末帧一致；下接 U38（面团醒发、她转身开火下面），人物由案板前移至灶台，围裙与额角薄粉保持连续。
```

## 范例 4 · 同一镜的新旧写法对照

| 旧写法（规范原文风格） | 新写法（本技能规则） |
|---|---|
| 林建国眼眶泛红、泪光积聚，第 2.2 秒一滴泪在眼角悬停未落，眼角轮匝肌收缩 | 他眼睛红了，泪在眼角停住没落下来，喉咙动了一下 |
| 眉头向中间聚拢形成川字纹、眼睑紧绷、喉结上下滚动一次、指尖以每秒 2 次频率轻叩桌面 | 他眉头压下来，喉结滚了一下，手指在桌面上敲 —— 敲了两下就停了 |
| 嘴角上扬约 5 毫米 | 嘴角提了一下，随即收住 |
| 呼吸频率由每分钟 18 次降至 10 次 | 呼吸慢下来，胸口起伏变浅 |
| 镜头 12 秒内由 1.5 米匀速拉远升高至 3.5 米 | 机位在 12 秒里缓缓后拉并升高，把父女和整张桌子一起收进画面 |

**规律**：旧写法在描述"参数"，新写法在描述"看得见的变化 + 意图"。参数留给推演，成品给人看。

## 六、实战案例（试跑沉淀）

**项目**：《这位置我不让》第 07 集「道德绑架」｜9:16｜120 秒｜19 单元 35 镜

**结构**：用户选定 **A+C**（结果前置冷开场 + 倒叙回退）

```
0:00–0:05  冷开场：按肩 + "我说让，你才让"     ← 降饱和压暗角
0:05–0:09  倒回：她刚坐下、放包、呼气          ← 常规色调
0:09–1:16  顺叙全线
1:56–2:00  回到那只手，停格                   ← 复用末帧，不新增动作
```

**关键决策（可复用）**

| 问题 | 处理 | 理由 |
|---|---|---|
| 倒叙退到哪 | 只退到"她刚坐下"，不退到上车 | 剧本没有上车戏；"坐下"正是结尾 OS 要兑现的事实 |
| B 级峰值给几个 | 只给 3 个：急刹 / 按肩 / 红眼 | 其余标 `C 级（强度高，不计为峰值）`；标多了等于没有峰值 |
| 急刹怎么加重量 | 4 镜：全景前栽 → 手抓空 → 袋子撞椅侧 → **眼睛特写（怕还没收住）** | 最后那一镜让观众犹豫，人物才不扁平 |
| 红眼怎么不煽 | 她哭，对方张嘴没说出话、视线偏开半寸 | 重点是"对方接不住"，不是"她哭" |
| 时长超限 | 先压无声过场，再从无声单元借时间给重点 | 不删台词、不删原文信息 |

**一句话经验**：结构和重点先定死，镜头才有地方长；重点不是"多给几个特写"，是"多给一次别人没料到的反应"。

## 七、范例使用说明

1. **只对齐颗粒度，不抄内容**。范例是情感片，你拿到的是悬疑本，景别与节奏都要换。
2. 范例 3 的字段结构可以直接当模板用（`templates/` 里有可填版本）。
3. 范例 4 是校准器：写完一段，拿它比一比，看自己是不是又写回"毫米/次数"了。
4. 每部新片做完，把最好的一场补进本库，库会越用越准。
