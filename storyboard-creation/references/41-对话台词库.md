# 对话与台词库

> **用法**：确定"这段对白在干什么"（功能）→ 定"这个人怎么说话"（风格）→ 设计"没说出口的是什么"（潜台词）→ 排"什么时候快什么时候停"（节奏）。
> 台词可在不改剧情与人物的前提下适度口语化，但**必须留痕**（原句 → 改写句 → 理由）。

---

## 一、对话功能（15 种）

| 功能 | 写法要点 | 典型场景 |
|---|---|---|
| 信息传递 | 关键信息最简洁地说出，配合反应镜强化冲击 | 交代背景、揭示线索、汇报 |
| 情感表达 | 句子可不完整（哽咽、停顿、重复），从克制到释放 | 告白、争吵、和解、告别 |
| 权力博弈 | 表面礼貌、潜台词施压：反问、打断、沉默、转移话题 | 谈判、审讯、职场暗斗 |
| 幽默 | 双关、夸张、反差、自嘲、误解、荒诞逻辑；前句铺垫后句爆 | 喜剧、日常、伙伴互动 |
| 威胁 | 短句、低音、慢速、句间压迫性停顿；不直说"杀你" | 反派、对峙、审问 |
| 表白 | 从犹豫试探到说出核心；语速偏慢、声音可能抖 | 告白、重逢、情感高潮 |
| 安慰 | 先承认感受再给支持；不说教、不"你应该" | 陪伴、受伤后的关怀 |
| 争执 | 快、响、抢话打断；翻旧账、绝对化措辞；中间可有短暂软化 | 夫妻、家庭、反目 |
| 试探 | 看似随意、每问有目的；观察反应比台词重要 | 调查、谈判、试探心意 |
| 命令 | 祈使句、果断、不容置疑；可给或不给理由 | 军队、职场、危机 |
| 说服 | 先建共同点→逻辑＋情感→预判反对→给行动建议 | 演讲、劝解、辩护 |
| 忏悔 | 长沉默后慢速低音，先说事实再说原因；忏悔后的沉默更重 | 坦白、临终、告解 |
| 告别 | 简短克制，说出口的最轻、说不出口的最重 | 送别、分手、永别 |
| 宣战 | 陈述理由→宣告立场→行动宣言；无回头余地 | 决裂、复仇、对峙高潮 |
| 日常闲聊 | 话题零散、口语化、有停顿与转换 | 建关系、过渡、生活质感 |

## 二、对白风格（15 种）

| 风格 | 特征 | 适合角色 |
|---|---|---|
| 简洁冷峻 | 一个字能说完绝不用两个；信息密度高 | 硬汉、杀手、军人 |
| 喋喋不休 | 长句、跳跃、插入语多，不看听者反应 | 话痨、紧张掩饰、喜剧 |
| 文绉绉 | 成语典故、书面语、结构完整 | 学者、文人、古代贵族 |
| 市井粗口 | 俚语俗语、短促直接、音量大 | 市井、黑帮、街头 |
| 诗化 | 比喻排比、意象、节奏感 | 文艺片、武侠高手、旁白 |
| 沉默寡言 | 整场只说一两个字，靠表情动作传递 | 冰山型、神秘角色 |
| 讽刺挖苦 | 反话、夸张赞美、假装真诚 | 聪明而愤世嫉俗者 |
| 结巴不流畅 | 重复音节、停顿改口、句子不完整 | 紧张的小人物、社交焦虑 |
| 权威 | 祈使句、短句、低音、慢速、仪式感停顿 | 领导、法官、帝王、BOSS |
| 撒娇卖萌 | 叠词、拖长音、语气助词、用提问代替命令 | 恋爱、儿童、亲密关系 |
| 语重心长 | 完整句、温和而认真、用自身经验铺垫 | 父母、导师、长辈 |
| 官方辞令 | 模板化表达、绕开直接回答、滴水不漏 | 外交、政治、发布会 |
| 神经质 | 自我怀疑、反复确认、过度解释、话题跳跃 | 焦虑角色、心理剧 |
| 慢条斯理 | 极慢、字字清楚、周围慌乱也不变 | 智者、长者、幕后反派 |
| 傲娇 | 前半句攻击、后半句泄露真实心意 | 青春恋爱、动漫风 |

## 三、潜台词（10 种）

| 技法 | 做法 | 效果 |
|---|---|---|
| 言不由衷 | 字面 A，表情/语气/行为指向相反的 B | 心碎、压抑、假装坚强 |
| 避重就轻 | 被问关键问题时谈无关的 | 隐瞒、逃避、暴露问题所在 |
| 答非所问 | 回答与问题无关，但透露自己的关注点 | 疏离、异常、沟通障碍 |
| 暗示 | 比喻、双关、侧面描述 | 暧昧、威胁、礼貌拒绝 |
| 反话 | 字面与实际相反，靠语气传达 | 嘲讽、压抑的愤怒 |
| 留白 | 关键处停住，或完全不提 | 未说出口的爱、悬念 |
| 话中有话 | 表面谈 A，实为暗号 | 秘密、默契、危险 |
| 过度解释 | 不需要解释的地方说一堆 | 心虚、谎言 |
| 明知故问 | 不需要回答的问题 | 施压、强调、不耐烦 |
| 默认回避 | 沉默或不回应被解读为承认 | 无声对抗、微妙压力 |

## 四、节奏（10 种）

| 节奏 | 处理 | 用途 |
|---|---|---|
| 快问快答 | 每句 1–3 个词，几乎无停顿 | 审讯、紧急、喜剧 |
| 长停顿 | 关键处静默 1–5 秒，用表情填 | 冲击、思考、尴尬 |
| 打断 | 抢话头，被打断者或争或退 | 冲突、权力 |
| 重叠对话 | 两人同时说，听不清 | 混乱、真实、群戏 |
| 渐弱 | 话到一半声音消失 | 哽咽、放弃、不敢说 |
| 渐强 | 平静→加快加大→爆发 | 冲突积累 |
| 节奏突变 | 快转慢或慢转快 | 转折、揭示 |
| 重复 | 同一句说 2–3 次，语气递变 | 崩溃、自我说服、执念 |
| 话轮转换 | 谁说得长、谁被打断 | 关系与权力 |
| 终结性沉默 | 对话后静默 2–5 秒不收 | 余韵、冲击 |

**配平提醒**：以上节奏都要吃掉时间。写进分镜时必须按 `05-覆盖层` 的语速基准验算（2.5–3.0 字/秒），停顿单独占时长。

## 五、独白与旁白（10 种）

| 类型 | 用法 | 注意 |
|---|---|---|
| 内心独白 | 声音来自角色，嘴不动 | 画面给微表情或象征空镜 |
| 开场旁白 | 建立世界、定基调 | 配建立镜头 |
| 结尾旁白 | 收束、点题、留余韵 | 配远去画面或空镜 |
| 书信朗读 | 读信画外音＋信纸/收信人/信中场景 | 语言比日常更书面 |
| 日记朗读 | 私密记录被读出 | 与画面可矛盾 |
| 回忆叙述 | 从现在的视角回望 | 语言带"那时候/如果当时" |
| 全知旁白 | 叙述者知道一切 | 可带预见性 |
| 多角色切换旁白 | 不同段落不同叙述者 | 观众拼合真相 |
| 舞台独白 | 长篇、直面镜头或独处空间 | 全片演技高光 |
| 电话留言 | 通过留言传递 | 犹豫、改口、被提示音打断 |

**规则**：旁白一律标【旁白】，**不生成口型**；独白占用的时间要计入该单元时长。

## 六、特定场景台词（10 种）

审讯室 / 谈判 / 告白 / 告别 / 宣战决裂 / 忏悔 / 鼓舞士气 / 临终遗言 / 重逢 / 自我介绍。

每种都有固定套路（如审讯＝重复提问＋突然换题＋出示证据＋虚张声势；告白＝铺垫＋鼓起勇气＋核心句＋被告白者的反应）。
**用法**：套路不是模板照抄，而是检查清单——先问"这场戏缺了哪一步"，再补。

---

## 七、台词改编规则（硬）

1. **可改**：语序、语气词、口语化、把书面语改成人话、把长句拆短。
2. **不可改**：信息点、因果关系、人物关系、反转所依赖的措辞、关键道具/数字/名字。
3. **必须留痕**：交付时附"台词留痕表"——原句 → 改写句 → 理由（如"原句 23 字，2.5 字/秒需 9.2 秒，超单元时长，拆为两句"）。
4. 台词太长先拆镜，再考虑挪到无对白单元，最后才动字句。
5. 口语化不得改变人物身份：老人不能说出网络梗，古人不能出现现代词。

---

## 八、写台词时的四问

1. 这句话是**谁说给谁听**的？（对象决定措辞）
2. 他**真正想达成**什么？（功能）
3. 他**为什么不明说**？（潜台词）
4. 说完之后，**对方会怎么反应**？（反应镜在哪）
