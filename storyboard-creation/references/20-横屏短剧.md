# 横屏短剧参数（V1.1 适配）

> 只写横屏模式**特有**的数值与偏好；通用方法见 `00-通用内核.md`，冲突以 `05-覆盖层` 为准。
> 画幅：**以用户当次给出为准**（典型 4:3 或 16:9），本文不提供默认值。

---

## 一、基本规格

| 项 | 值 |
|---|---|
| 成片时长 | 单集 1–3 分钟；上限以用户参数为准 |
| 生成单元 | 4–15 秒，目标 7–12 秒 |
| 单镜基础时长 | 3–6 秒 |
| 强冲突/强钩子/特写 | 1–3 秒 |
| 视觉奇观/大场面 | 6–8 秒 |
| 单镜上限 | 10 秒（无特殊叙事需求严禁超过） |
| 空镜/反应/动作镜 | 最长 8 秒 |
| 情绪点密度 | 每 3–5 个镜头一个情绪点/冲突点/反转点/视觉奇观点 |
| 平铺上限 | 禁止超过 15 秒的无冲突、无情绪、无亮点画面 |

---

## 二、画幅与构图

- 宽幅是优势：左右空间用来放人物站位、环境纵深、前后景关系。
- 双人/多人可同框：MS 可容 3–5 人，负责关系调度。
- 构图左右留白要平衡；核心信息避开字幕区与下三分之一。
- 横移、摇镜、跟拍在宽幅里更有信息量，适合交代空间与关系。
- 倾斜镜头在宽幅里冲击力更强，但别滥用。

---

## 三、景别使用（七级全可用）

| 景别 | 用法 | 时长 |
|---|---|---|
| ELS | 世界观建立、环境叙事、大场面、奇观、转场空镜 | 3–5 秒 |
| LS | 场景开篇定调、大场面动作、氛围烘托 | 3–5 秒 |
| FS | 场景开篇、全身动作、站位关系、群像 | 3–6 秒 |
| MS | 多人对话、短动作戏、关系调度（主力） | 3–5 秒 |
| 中近景 | 双人对话、小范围肢体调度 | 2–5 秒 |
| MCU | 对白、单人叙事、情绪传递 | 2–4 秒 |
| CU | 强情绪、冲突爆发、关键线索、钩子 | 1–3 秒 |
| ECU | 极致情绪、关键揭示、钩子 | 1–2 秒 |
| OTS | 电影化对话核心机位 | 2–4 秒 |

**对话机位节奏**：4、5 号过肩建立空间与客观性 → 2、3 号平行机位强化情绪 → 6、7 号内反拍强调关键台词 → 1 号主机位开场收尾。

---

## 四、节奏与钩子

- 开篇黄金钩子：强冲突/强悬念/强反转/强视觉奇观，前 3–5 秒抓住。
- 高密度叙事与视觉奇观交替：不要连打，也不要连静。
- 每 3–5 镜一次起伏。
- 集末悬念钩子：纯黑 ≤1 秒，声先入收尾。

---

## 五、横屏特有的调度机会

| 机会 | 用法 |
|---|---|
| 宽幅双人关系 | 一左一右、中间留空，用距离表达关系；越走越近/越站越远 |
| 前后景 | 前景人物虚化、后景人物清晰，一镜交代两个人的不同状态 |
| 长焦压缩 | 把远距离人物压到同一平面，制造"逃不掉"的压迫感 |
| 横移扫描 | 扫过一排人/一排物，逐个揭示信息 |
| 纵深走位 | 人物从画面深处走到前景，完成情绪逼近 |

---

## 六、横屏常见错误

| 错误 | 后果 | 纠正 |
|---|---|---|
| 宽幅里人物居中发呆 | 空间浪费，画面呆板 | 用左右站位与环境层次 |
| 全景切全景 | 视觉疲劳 | 按递进/递退组织 |
| 多人同框但没人有反应 | 群像假 | 给非聚焦者微动态与反应镜 |
| 长镜头无调度 | 空镜静止 | 加走位或机位运动 |
| 单镜超 10 秒 | 节奏塌 | 拆镜 |
| 左右构图失衡 | 观众注意力漂移 | 检查重量分布 |
