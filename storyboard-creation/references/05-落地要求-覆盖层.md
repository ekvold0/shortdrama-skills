# 落地要求 · 覆盖层

> 本文件是本技能的最高优先级规则层。
> 优先级顺序：**运行期输入参数（用户当次给出） ＞ 本文件 ＞ 三份基础规范（竖屏 V2.2 / 横屏 V1.1 / 短篇 V1.0）**。
> 凡与三份基础规范冲突，一律以本文件为准；基础规范中被本文件取代的条款，不再执行。
> 标记约定：**【硬】**＝违反即返工，不得"视情况灵活处理"；**【软】**＝默认执行，有明确理由可偏离并注明理由。

## 一、八条裁决（与基础规范的差异，已定稿）

| 编号 | 事项 | 基础规范原写法 | 本技能最终规则 | 作废 / 保留范围 |
|---|---|---|---|---|
| 1 | 表演与情绪写法 | 全篇强制"部位+方向+幅度+速度+时长"，毫米级、每秒 N 次、FACS 肌群名 | **分级处理**（见第二节）：微表情走 FACS 拆解；整体情绪走"意图＋可观察行为"。物理参数只做内部推演，不回显到成品 | 作废：毫米/次数/牛顿等量化词作为成品描述；保留：0.1 秒时间码（排期用）、FACS 用于微表情条目 |
| 2 | 台词 | 与剧本逐字一致，不得修改 | 可在不改剧情、不改人物关系的前提下**适度口语化**，但必须**留痕**（原句 → 改写句 → 理由） | 作废：绝对逐字；保留：不得增删台词所承载的信息与反转 |
| 3 | 生成单元时长 | 目标 15 秒，允许 5–15 秒，不足填至 10 秒 | **4–15 秒，目标 7–12 秒，不得短于 4 秒，且时长必须是整数秒**；短篇模式上限仍为 15 秒 | 作废：15 秒目标值、5 秒下限、"填至 10 秒" |
| 4 | 转场 | 硬切/叠化/淡入淡出/匹配剪辑/动作转场/声音转场 | **镜头间只用硬切**，不写转场特效；转场库仅可用于实拍或后期建议，且不得写进 AI 生成单元 | 作废：叠化、淡入淡出、划像等写进分镜块 |
| 5 | 声音层 | 短篇四层含"配乐"，并要求音乐主题贯穿 | **四层：人声／核心音效／环境细节／空间混响**；不写 BGM、不依赖配乐叙事。声音母题可设计，但只作为音效/环境层的呼应手法 | 作废：配乐层、BGM 描述、"音乐主题贯穿全片"作为必填 |
| 6 | 站位写法 | 示例"角色 A 位于画面左侧，距镜头 2 米" | **物理方位＋相对关系**：靠门一侧／靠通道／画面深处／前景虚化／背对窗；禁止裸"居左/居右"（会随机位朝向翻转） | 作废：以画面左右定方位的写法；保留：相对距离、朝向、视线对象 |
| 7 | 景别分类 | 七级（含"中近景"），视点单列 | **枚举补全并融合**：ELS / LS / FS / MS / 中近景 / MCU / CU / ECU / OTS；"主观/半主观/客观/反应"写进**机位列**，不得混入景别列 | 保留：七级体系；新增：OTS 单列、机位属性分离 |
| 8 | 画幅 | 固定 4:3（横屏） | **不写死在技能里**：画幅比例、分辨率由用户在运行期提供；缺失必须停下来问，**禁止自行假设**。全片画幅统一、每组复写；角度一律用汉字"度"，不用半角 ° | 作废：任何硬编码的 4:3 / 9:16 / 1920×1440 |

## 二、表演分级表（裁决 1 的执行细则）【硬】

### 2.1 三级判定

| 级别 | 判定标准 | 写法 | 示例 |
|---|---|---|---|
| **A 级 · 微表情** | 时长 0.04–0.2 秒；瞬态泄露；局部面部变化；角色在**掩饰**真实情绪 | **FACS 式拆解**：点名部位（眉/眼睑/鼻/口/颊）＋方向＋幅度＋持续时长，可用表情库词条 | 听到"离婚"二字，第 3.2 秒眉头上端内抬约 10 度、上眼睑抬起一层、瞳孔放大，0.15 秒后全部复原，嘴角维持原状 |
| **B 级 · 情绪峰值** | 时长 0.5–2 秒；高潮、反转、爆发、崩溃；全片 1–3 次 | **可观察行为为主**＋至多 1 个 FACS 骨架参数 | 他攥住盒子，攥到指节发白——不是用力，是怕松手；随后整只手开始抖 |
| **C 级 · 常态情绪** | 持续 2 秒以上；整段表演；关系状态、心理底色 | **意图 ＋ 可观察行为**；物理参数只在内部推演，**不回显** | 她一直在笑，但笑之前总要先看一眼门口；每次门响，肩膀先动，眼睛后到 |

**计数规则【硬】**：B 级只给**真正承担转折或峰值**的段落（全片 1–3 个）。强度高但不承担转折的段落，写 `C 级（强度高，不计为峰值）`，不得为了强调而标 B——否则全片处处是峰值，等于没有峰值。

### 2.2 写法禁令【硬】

1. 成品描述中禁止出现：牛顿（N）、毫米级位移、"每秒 N 次"、"频率 2 赫兹"、FACS 肌群拉丁名或学术缩写（AU、颧大肌、眼轮匝肌等）。
   - 例外：A 级微表情可写"眉头上端内抬约 10 度"这类**可观察的角度/幅度**，但不得写成肌群解剖学。
2. 每个镜头**最多保留 1 个真正能拍的节奏锚**（如"定格半秒""雨刷每秒约 1 次""呼吸停了半拍"）。第二个节奏锚必须删掉。
3. 禁止"伪精确"：AI 与演员都无法执行、无法验证的参数，一律改写为行为。
4. 高潮段**至少安排一次明确的情绪峰值**（B 级），不得全片都是 C 级克制。

### 2.3 内部推演与回显

- 思考与自查阶段，仍按"部位＋方向＋幅度＋速度＋时长"推演，用于判断这个情绪是否成立、是否可拍。
- 落到成品时，只保留：**意图（为什么）＋ 可观察行为（看得见什么）＋ 至多 1 个节奏锚**。
- 不得在交付物里出现"内部推演过程"。自查记录中可写"该镜原推演为 X，因不可拍改为 Y"。

## 三、二十五条落地要求（分组执行）

### A 组 · 前置三步（第 2–4 条）

| # | 要求 | 检查点 |
|---|---|---|
| A0【硬】 | **三个停车点，禁止越步**：①故事梗概输出后必须停，等用户确认；②叙事结构方案输出后必须停，等用户选定（并要求用户指出本集剧情重点）；③锚点卡与空间图输出后必须停，等用户确认。三处任一未经确认就输出分镜内容，视为返工。**不得替用户选定结构，不得把梗概、结构、分镜一次性给完。** | 每轮只推进一个停车点；交付物中不出现未经确认的结构 |
| A1【硬】 | 动手前先逐条精读规范正文与全部附件（表情/情绪库、对白、声音、剪辑法、跨类型方法论），不得只看模板 | 交付物里每个分镜块引用了对应的附件条目 |
| A2【硬】 | **第一步：故事梗概**——详细写清本集讲了什么：主线与反转、出场人物与动机、时间地点与时间线、情绪曲线、贯穿道具、与前后集的衔接点 | 梗概能独立读懂；与全季设定无矛盾 |
| A3【硬】 | **第二步：叙事结构方案**——先给 **3–4 种**方案再动笔，每种写明六要素：①开场钩子 ②叙事视角 ③信息揭示顺序 ④悬念与反转落点 ⑤留存/完播设计 ⑥与前后集如何衔接 | 方案可组合（如 A+B 为主、C 补一拍）；**未确认不得写分镜** |
| A4【硬】 | 结构备选库（可自由组合）：线性、闪前冷开场、闪回/倒叙、双线交叉、三线交叉竞速、套层/监控套层、主观视角、阅卷回忆、倒计时记忆交叉 | 方案不得只换名字不换结构 |
| A5【硬】 | 冷开场若较长（纯悬念、不露脸、无台词），必须放一个**新观众能瞬间读懂的信息锚**（道具特写、关键物刻字、时间卡） | 该锚点在后续剧情中回扣 |
| A6【硬】 | **允许组合结构**（如 A+C＝结果前置＋倒叙回退），但必须写清两点：① 回退点落在剧本**已有**的时点，不得为倒叙新增情节；② 组合超过两种时标出主结构 | 回退点能在剧本原文里找到依据 |
| A7【硬】 | 用户在结构方案阶段指定的**剧情重点**（哪 2–3 个节拍必须打中），必须在分镜里可检索：在单元坐标后标注【重点①】等，并集中给镜数与时长 | 交付物能一眼看出重点是哪几场 |

### B 组 · 时长与节奏（第 5–9 条）

| # | 要求 | 检查点 |
|---|---|---|
| B1【硬】 | 时长上限按运行期参数：竖屏/横屏单集默认 **≤3 分钟**；短篇模式按 10–15 分钟。参数优先 | 总时长不超上限 |
| B2【硬】 | **账目自洽（零误差）**：各镜秒数加总 ＝ 各单元时长加总 ＝ 全片总时长；0.1 秒精度，四舍五入只在最终合计处做一次 | 三个合计数字完全相等 |
| B3【硬】 | 生成单元 **4–15 秒，目标 7–12 秒**，不得短于 4 秒；单元边界尽量与场边界对齐 | 无 <4 秒单元；无 >15 秒单元；每个单元时长都是整数秒 |
| B4【硬】 | 台词与时长配平：按正常口语语速核算，保证能讲完、不抢话、不赶、不留半句。**语速基准 2.5–3.0 字/秒**；抒情放慢 2.0–2.5；紧张加快 3.0–3.5；**上限 3.5 字/秒** | 逐句验算：字数 ÷ 语速 ≤ 该句所占时间 |
| B5【硬】 | 台词过长：先拆分到多镜，再考虑挪移到原本无对白的单元重新配平；不得压缩语速硬塞 | 无超速句 |
| B6【硬】 | 台词偏少的集子：用画面叙事＋内心 OS/旁白＋细节镜/反应镜补足信息，不允许大段无信息画面 | 每 10 秒至少一个信息增量 |
| B7【硬】 | 超过 3 秒的对白：画外音贯穿 ＋ 插入 **0.6–0.8 秒**反应镜 ＋ 切回时角色仍在"正在说"的状态（嘴微张、头保持说话角度）。插入节奏：每 2.5–3.0 秒一次 | 逐句核查，不得"大头贴干说" |
| B8【硬】 | 集末钩子不用长黑屏：纯黑 **≤1 秒**；改用声先入、心跳漏拍、物件声收尾 | 末镜无 >1 秒黑场 |
| B9【软】 | 单镜时长：竖屏 3–5 秒（强钩子 1–3 秒，不超 8 秒）；横屏 3–6 秒（奇观 6–8 秒，不超 10 秒）；短篇 3–8 秒（情绪长镜头 8–15 秒） | 按模式套用，见模式参数文件 |
| B10【硬】 | 时长超限时的压缩顺序：① 先压**无台词的过场镜**（不是删，是压到 4–5 秒）② 再合并同空间相邻单元 ③ 最后才动台词（拆句、挪移）④ **严禁删原文信息**。反过来，加重点时优先从无声单元借时间 | 超时不得靠删台词解决 |

### C 组 · 景别、机位、运镜、调度（第 10–14 条）

| # | 要求 | 检查点 |
|---|---|---|
| C1【硬】 | 景别列**只填枚举值**：ELS / LS / FS / MS / 中近景 / MCU / CU / ECU / OTS；"主观/半主观/客观/反应"写进机位列 | 景别列无形容词、无视角词 |
| C2【硬】 | 景别按递进/递退组织（中景切特写、全景切近景），切换必须有叙事动机；不得同景别无意义跳切 | 相邻镜景别变化可解释 |
| C3【硬】 | 术语物理准确、量级匹配：航拍只用于真正的高空大范围运动；小幅升降写摇臂/云台；长焦"推近"必须靠变焦或大幅位移，**禁止"长焦推 0.6 米"**这类自相矛盾设定 | 器材与运动幅度匹配 |
| C4【硬】 | 运镜必须服务情绪与信息，不用无意义炫技；快切段落可强化风格化 | 每个运镜能说出目的 |

| C6【软】 | 多角度机位、多层次景别交替；画面要有景深、机位要有层次 | 连续 5 镜内机位高度/角度有变化 |

### E 组 · 人物出场与一致性（第 17–18 条）

| # | 要求 | 检查点 |
|---|---|---|
| E1【硬】 | 凡剧情在场的角色都要**真实出镜**，不能只以画外音存在；意识体/灵魂态按设定形态现身 | 逐场核对在场名单与出镜镜号 |
| E2【硬】 | **有台词的角色必须在对应镜头出镜**；"只闻其声不见其人"仅限电话、广播、主观镜头等明确设定的情况，且需标注理由 | 台词与画面人物一一对应 |
| E3【硬】 | 配角/意识体按剧情出镜 1–2 次即可，不必每镜都在；群像用多分镜、反应镜分别表现，不得把多人堆进同一镜头 | 群像场有独立反应镜 |
| E4【硬】 | 建立并每组复写**角色外形锚点、声线锚点、贯穿道具/视觉标记常量表**，保证跨镜跨集一致；关键道具单独锁定参考 | 同一角色跨场描述无矛盾 |

### F 组 · 空间物理关系（第 19–20 条）

| # | 要求 | 检查点 |
|---|---|---|
| F1【硬】 | 每场先建**固定空间/座位关系图**（物理坐标）：谁在哪、面朝哪、视线看谁、谁在前景（虚）、谁在画面深处、靠门还是靠通道 | 关系图随场交付 |
| F2【硬】 | 用**物理方位＋相对关系**描述，禁止裸"居左/居右"；必须写"靠中控台一侧""靠车门一侧""背对窗""面向走廊" | 全文检索无裸左右方位 |
| F3【硬】 | 道具操控写明**用哪只手、道具在哪、如何操作**（驾驶时谁握盘、谁操控；谁抱道具、谁揉眼/摸耳后） | 手别与身体位置不矛盾 |
| F4【硬】 | 驾驶/操作场景中，看后座或侧后方只能通过后视镜或符合安全逻辑的方式，不能直接回头 | 无违规回头 |
| F5【硬】 | 越肩（OTS）必须写清"越过谁的肩、朝哪个方向、拍到谁"，保证轴线不错位 | 正反打方向一致 |
| F6【硬】 | **五者自洽**：位置、朝向、视线、道具、机位逐组核查（车厢、房间、走廊、车内多角色尤其严格） | 无串座、无串手、无越轴 |

### G 组 · 视听设计与母题（第 21–22 条）

| # | 要求 | 检查点 |
|---|---|---|

| G3【硬】 | 声音分四层写足：人声 / 核心音效 / 环境细节 / 空间混响；不写 BGM、不依赖配乐叙事 | 每单元四层齐全，无"无"敷衍 |
| G4【硬】 | 所有文字（字幕、时间卡、屏幕 UI、标牌）一律标注**后期叠加**；AI 只生成窗口/色块/框架，不生成任何可读文字 | 全文无"画面上显示文字"式描述 |

| # | 要求 | 检查点 |

| H2【硬】 | 闪前/闪回必须明确标注，并给视觉区分（色温、画质、边缘、画幅内框等） | 每处闪回有标识与回归点 |

| H5【硬】 | 字段齐全、名称与顺序符合模板，不得缺字段、不得自创字段名 | 模板逐字段核对 |
| H6【硬】 | **每个生成单元自包含**：画幅、视觉风格、角色锚点、空间坐标每组完整复写，禁止"同上/同前/见前文" | 全文检索"同上/同前/省略" |

## 四、运行期必填参数（裁决 8 的执行）

以下参数**必须由用户在当次任务中提供**，技能不得自带默认值：

| 参数 | 说明 | 缺失时的动作 |
|---|---|---|
| 画幅比例 | 如 4:3、9:16、2.35:1 | **停下来问**，不得假设 |
| 分辨率 | 如 1920×1440、1080×1920 | 可追问；若用户说"随意"则按画幅比推算并注明 |
| 模式 | 竖屏短剧 / 横屏短剧 / 短篇视频（10–15 分钟） | 可依剧本与时长推断，但需一句话确认 |
| 单集/全片时长上限 | 如 ≤3 分钟、12 分钟 | 按模式给默认建议值，请用户确认 |
| 平台 | 如红果、抖音、其他 | 影响合规尺度与钩子强度 |
| 剧集上下文 | 前后集剧情、人物设定、贯穿道具 | 缺失时按"独立单集"处理并注明风险 |
| 参考图 | 角色/场景参考图（可选） | 无参考图时提醒先出定妆照/概念图 |

**硬规则**：画幅未确认前，不输出任何分镜内容（可以先做梗概与结构方案）。

## 七、自检挂钩（每次交付前跑一遍）

### 第一轮 · 逐句映射
- [ ] 剧本每一句台词都有对应镜号承接
- [ ] 每一个动作、心理活动、环境变化都有画面落点
- [ ] 未承接的内容为零；如有删减，逐条列出理由

### 第二轮 · 单元与账目
- [ ] 各镜秒数合计 ＝ 各单元合计 ＝ 全片总时长（零误差）
- [ ] 无单元 <4 秒、无单元 >15 秒
- [ ] 单元内不跨场景
- [ ] 逐句台词按语速验算可讲完

### 第三轮 · 合规与规格
- [ ] 字段齐全、顺序正确、无自创字段
- [ ] 画幅与运行期参数一致、全片统一
- [ ] 无半角 °；角度用"度"
- [ ] 无"同上/同前"；每单元自包含
- [ ] 无 BGM；声音四层齐全
- [ ] 所有文字标注后期叠加
- [ ] 镜头间均为硬切
- [ ] 无牛顿/毫米/频率等伪精确参数
- [ ] 每镜节奏锚 ≤1 个
- [ ] 有台词的角色均已出镜
- [ ] 站位无裸"居左/居右"
- [ ] 手别、越肩、视线五者自洽

## 八、已确认的数值（2026-10-26 定稿）

| 项 | 确认值 | 说明 |
|---|---|---|
| 台词语速基准 | **2.5–3.0 字/秒** | 比旧规范"1–2 字/秒"稍快、比常规口语稍慢，留出表演停顿 |
| 抒情段语速 | 2.0–2.5 字/秒 | 慢而不拖，不得低于 2.0 |
| 紧张段语速 | 3.0–3.5 字/秒 | 上限 3.5，超过即判"抢话" |
| 情绪峰值数量 | 全片 **1–3 次** | 至少 1 次，最多 3 次 |
| 单镜上限 | 竖屏 8 秒 / 横屏 10 秒 / 短篇 15 秒 | 沿用基础规范，未被新文档覆盖 |
| 封闭场景呼吸口 | 每场 1–2 个 | 长对话场中后段插入 |

> 以上为定稿值，后续如需调整只改本表与对应条目（B4、D3）。
