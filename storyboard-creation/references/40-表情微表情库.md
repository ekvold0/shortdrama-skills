# 表情与微表情库

> **用法**：本库只用于 `05-覆盖层` 的 **A 级微表情**（0.04–0.2 秒瞬态泄露）与 **B 级峰值**（取 1–2 个参数即可）。
> C 级常态情绪**不要**从这里抄参数——改用"意图＋可观察行为"。
> 抄用规则：幅度/方向可以写，频率与毫米数不写；每条不超过 3 个可见变化。

---

## 一、基础八大核心情绪

| 情绪 | 可见特征 | 可用参数（择 2–3 项） | 常见用途 |
|---|---|---|---|
| 真实微笑（杜乡） | 嘴角上扬＋眼周参与，苹果肌上提 | 嘴角上扬、眼裂缩小约 20%、眼角出细纹、持续 2–5 秒自然回落 | 真心愉悦、亲密、治愈 |
| 社交微笑（假笑） | 只有嘴动，眼不动 | 嘴角上扬 15–25%、眼周平整无纹、可维持 5–30 秒不僵 | 客套、疏离、伪装友好 |
| 悲伤 | 八字眉、眼睑下垂、嘴角下沉 | 眉头上端内抬、眉心浅纵纹、视线下移、嘴角下弯 | 失落、离别、回忆伤痛 |
| 愤怒 | 眉下压聚拢、眼裂变锐、牙关紧 | 眉头下压、眉心深纵纹、眼裂收窄、鼻翼微张、咬肌隆起 | 争执、对峙、爆发 |
| 恐惧 | 眉上扬、上睑大开、瞳孔放大 | 眉毛整体上扬、上眼睑抬至露眼白、瞳孔扩大、面色发白 | 危机、恐慌、求生 |
| 惊讶 | 眉眼大张、口微开 | 眉头上抬、眼裂最大化、下颌自然下垂、嘴呈 O 型、0.5–2 秒消退 | 反转、爆料、轻惊吓 |
| 厌恶 | 鼻肌起皱、上唇上提 | 鼻梁横褶、鼻尖微抬、上唇上提、眼裂缩小 | 反感、嫌弃、道德厌恶 |
| 轻蔑 | 单侧嘴角上扬（唯一不对称基础情绪） | 单侧嘴角上扬、同侧鼻唇沟加深、头微仰、视线微向下 | 不屑、权力碾压、嘲讽 |

## 二、十大微表情（闪现 0.04–0.2 秒，随即复原）

| 微表情 | 泄露的心理 | 可见特征 | 典型场景 |
|---|---|---|---|
| 微愤怒 | 隐忍、暗藏怒火 | 眉头短促下压、眼裂收紧、眉心细纹闪现即抹平 | 强忍不满、职场暗斗 |
| 微恐惧 | 心虚、强装镇定 | 眉毛微抬、上睑微张、瞳孔瞬间扩张，0.2 秒内消失 | 说谎被质疑、面对强敌 |
| 微悲伤 | 假装没事 | 瞬间八字眉＋嘴角微垂，立刻恢复 | 强颜欢笑、掩饰委屈 |
| 微厌恶 | 表面客套，内心反胃 | 鼻纹、上唇微抬一闪即逝 | 虚伪社交、被迫迎合 |
| 微惊喜 | 快速压下诧异 | 眉眼微抬、未张嘴即压制 | 假装不意外、看破不说破 |
| 微蔑视 | 潜意识优越感 | 单侧嘴角极快上扬随即归位 | 暗地看不起、心理优势 |
| 微愉悦 | 压抑不住的真心笑意 | 眼角与嘴角微联动，瞬间收起 | 暗恋对视、憋笑、暗爽 |
| 微痛苦 | 生理或心理痛感破防 | 眼周骤紧、面部微抽、瞬间放松 | 带伤硬撑、心理刺痛 |
| 微困惑 | 认知卡顿 | 眉眼轻微不对称、眉头瞬间轻蹙 | 接收复杂信息、假装听懂 |
| 微警觉 | 捕捉异动 | 瞳孔微扩、眼裂微张、头微转向刺激源 | 察觉危险、听到线索 |

## 三、复合情绪（15 种）

| 情绪 | 组合特征 | 用途 |
|---|---|---|
| 苦涩微笑 | 嘴角上扬＋眉心紧锁 | 无奈、自嘲、认命 |
| 愤怒之泪 | 怒态＋眼眶盈泪＋下唇颤 | 被冤枉、背叛、无力抗争 |
| 恐惧微笑 | 嘴笑＋眉眼惊恐 | 讨好、怯懦、自我保护 |
| 惊喜微笑 | 惊讶眉眼＋真笑 | 重逢、礼物、好消息 |
| 悲伤平静 | 轻八字眉＋眼睑微垂＋视线柔和向下 | 告别、释怀、落幕 |
| 厌恶好奇 | 鼻皱＋眼睛睁大前倾 | 窥探秘密、禁忌吸引 |
| 蔑视愉悦 | 单边轻扬＋双眼微眯 | 幸灾乐祸、看对手翻车 |
| 焦虑微笑 | 嘴角僵硬＋眉心轻皱＋眼神飘 | 表白、面试、等答复 |
| 坚毅 | 眉微压＋唇紧抿＋视线稳定 | 抉择、迎战、关键时刻 |
| 渴望 | 轻八字眉＋视线固定远方＋唇微张 | 思念、眺望、离别凝望 |
| 羞耻 | 头低＋视线回避＋面部内收 | 当众失态、被揭穿 |

| 无助 | 八字眉明显＋嘴微张＋头微仰 | 突发困境、求助 |
| 狂喜 | 大笑最大化＋眼眯成弯月＋细纹密集 | 圆梦、夺冠、失而复得 |
| 麻木 | 面部僵直＋视线失焦＋眉眼无起伏 | 重大打击、绝望、深度疲惫 |

## 四、伪装与欺骗（9 种）

| 手法 | 破绽在哪 | 怎么用 |
|---|---|---|
| 压抑愤怒 | 上脸中性，下半脸紧绷 | 咬肌紧、下颌收、唇线僵 |
| 假装悲伤 | 眉眼模仿到位，眼神无低落 | 眼睑与气色没有真实变化 |
| 假装恐惧 | 动作像，瞳孔不扩 | 眼神稳定、无应激 |
| 标准假笑 | 只有嘴笑 | 眼周零变化、无细纹、苹果肌不发力 |
| 情绪替换 | 用 A 情绪盖 B | 表情与心态错位 |
| 表情过度 | 幅度超场景需要 | 用力过猛、持续过久 |
| 不对称表情 | 左右力度不一致 | 典型伪装破绽 |
| 表情闪切 | 两种情绪快速交替 | 内心剧烈冲突 |
| 延迟表情 | 情绪慢半拍 | 刺激后 0.5–3 秒才出现 |

**用法**：这九种是"演假"的工具，最适合"人物在演给另一个人看"的戏。写的时候只要指出破绽点（眼没跟上、半张脸先动），不要解释心理。

## 五、动态时序（判断真假情绪的尺子）

| 维度 | 真实 | 伪装 |
|---|---|---|
| 起始速度 | 0.2–0.5 秒顺滑启动 | 过快突现或过慢延迟 |
| 消退速度 | 慢衰减、有余韵 | 瞬间消失、生硬截断 |
| 顶点时长 | 1–3 秒自然稳定 | 过久僵住或无峰值 |
| 不对称变化 | 起始不对称、顶点对称 | 全程不对称固定 |
| 切换速度 | 0.5–2 秒自然过渡 | 0.3 秒突变 |
| 与语言先后 | 表情先于语言 0.2–0.5 秒 | 语言先、表情后补 |
| 衰减曲线 | 先快后慢 | 线性匀速或阶梯断层 |

**这是本库最实用的部分**：判断一个角色"是不是在装"，看时序比看表情更准。写分镜时可以只写时序差（"话说完半秒，笑才上来"）。

## 六、极端状态（8 种，留给高潮）

惊恐发作 / 崩溃痛哭 / 失控狂笑 / 面部冻结 / 神经性抽搐 / 解离失神 / 极致痛苦 / 愉悦巅峰。

用法：每部片只挑 1–2 处，配合 `05-覆盖层` 的 B 级峰值使用。**不要每场都用**，用多了就失效。

---

## 七、高阶社交表情（8 种）

默契会心笑 / 社交尴尬笑 / 笑容渐褪 / 礼貌倾听 / 偷看被抓 / 挑衅玩味笑 / 无奈苦笑 / 自嘲微笑。

用途：这类表情最适合"关系戏"——两个人之间的微妙默契或尴尬，比台词更省。

---

## 八、东方含蓄特质（5 种）

东亚内敛微笑 / 舞台夸张表情 / 扑克脸稳态 / 平静灵性表情 / 忍痛微笑。

**提示**：国产短剧大量使用"内敛微笑"与"忍痛微笑"，幅度要小、克制，不要按西方情绪强度写。

## 九、镜头＋表情的叙事组合（10 种）

| 手法 | 写法要点 |
|---|---|
| 微距推近抓微表情 | 慢推特写，抓瞬态破绽 |
| 焦点呼吸式解码 | 焦点在眉眼嘴之间游走 |
| 环绕立体展示 | 多角度看面部张力 |
| 双人正反打对照 | 表情对比＝权力关系可视化 |
| 慢动作表情 | 拆解肌肉运动顺序，区分真假 |
| 荷兰角扭曲 | 倾斜＋表情失衡，强化错乱 |
| 快切微表情序列 | 短镜拼接心理破绽 |
| 推进渐强 | 越近情绪越浓 |
| 拉出消退 | 远景抽离，情绪落幕 |
| 顶点冻结 | 定格最高光瞬间 |

## 十、组合法则（9 条）

| 法则 | 内容 | 用法 |
|---|---|---|
| 脸身错位 | 脸稳身体慌，或脸笑身体防御 | 说谎、隐忍 |
| 言行错位 | 话积极、表情消极 | 口是心非 |
| 群体同步 | 一人起情绪，多人连锁 | 群戏 |
| 面具碎裂 | 伪装瞬间泄露再迅速补全 | 揭穿时刻 |
| 镜像共情 | 双方无意识同步神态 | 亲密关系标志 |
| 多层叠加 | 主情绪＋次情绪＋底层隐忍 | 复杂人物 |
| 渐变转场 | A 情绪平滑过渡到 B | 长镜头内完成 |
| 静态凝固 | 情绪僵住不散 | 震惊、麻木、演戏 |
| 血色变化 | 潮红＝羞/怒/激动；苍白＝恐/惊/失神 | 生理层面的情绪 |

---

## 十一、写作提示

1. **一条只写 2–3 个可见变化**，写多了 AI 也演不出来。
2. 微表情必须带时间码：第 X.X 秒起、持续 0.X 秒。
3. 优先写"时序"和"破绽"，比写"幅度"更能让人看懂。
4. 同一个角色不要反复用同一种微表情，会变成标签。
5. C 级情绪请回 `00-通用内核.md` 用"意图＋行为"写法。
