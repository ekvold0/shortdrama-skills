# 短篇视频参数（10–15 分钟，V1.0 适配）

> 短篇与短剧的根本区别：短剧是连续剧里的一集，靠钩子和悬念拉人追看；短篇是**一部自成起承转合的完整作品**，必须在单部内完成建置、对抗、高潮、结局的闭环。
> 画幅：**以用户当次给出为准**，本文不提供默认值。

---

## 一、基本规格

| 项 | 值 |
|---|---|
| 成片时长 | 10–15 分钟（600–900 秒） |
| 场数 | 通常 8–14 场 |
| 生成单元 | 4–15 秒，目标 7–12 秒；全片约 40–90 个单元 |
| 单镜基础时长 | 3–8 秒 |
| 强冲突/冷开场/特写 | 1–4 秒 |
| 情绪/调度长镜头 | 8–15 秒（必须有持续调度，不得静止空镜） |
| 视觉奇观/大场面 | 6–10 秒 |
| 单镜上限 | 15 秒（AI 单元上限） |
| 节奏底线 | 连续 20–30 秒内必须有信息/关系/情绪增量 |

---

## 二、结构规划（分镜前必做，不可跳过）

### 2.1 五个结构段

| 结构段 | 功能 | 时长占比 | 12 分钟基准 | 10–15 分钟区间 |
|---|---|---|---|---|
| 冷开场/序幕 | 强钩子、核心悬念或事件前置 | 5%–8% | 约 0:40 | 0:30–1:10 |
| 第一幕·建置 | 主角/世界/欲望，激励事件 | 18%–22% | 约 2:40 | 2:00–3:00 |
| 第二幕·发展 | 冲突升级、阻碍、中点转折、最低谷 | 38%–45% | 约 5:00 | 4:30–6:30 |
| 高潮 | 终极抉择、正面对决、情感总爆发 | 12%–22% | 约 2:30 | 1:30–3:00 |
| 第三幕·结局尾声 | 解决、主题落点、弧光闭环、余韵 | 10%–15% | 约 1:30 | 1:20–2:00 |

### 2.2 各段要点

- **冷开场**：前 15–30 秒（最长 45 秒）抛钩子，可用结果前置、悬念事件、反常画面、冲突预演；必须与后续主线回扣，不能是噱头。
- **第一幕**：交代主角与世界，明确 Want（外在目标）与 Need（内在需求）的落差；用激励事件打破平衡。
- **第二幕**：连续行动与层层阻碍；全片约中点（第 5–8 分钟）设中点转折（重大揭示/反转/伪胜利/伪失败）；后段可设最低谷蓄力。
- **高潮**：外在冲突与内在冲突同时爆发，主角在压力下做出体现弧光的关键选择。
- **结局**：呈现选择后的新状态，与开场形成可见对照；主题落点，可开放但须回扣主题，**不设"追看下集"式悬念**。

### 2.3 分场表（场景地图）字段

```
场号 | 场景（内/外·地点·时间）| 出场人物 | 叙事功能/关键节拍 | 时长 | 情绪强度(1-5) | 弧光/主题增量
```

规则：
- 同一地点、同一连续时段＝一场；地点或时间跳跃即换场。
- 每场必须有推进（新信息/关系变化/冲突升级/情绪转变）；无推进的场删掉或合并。
- 关键场要做足戏，避免场景过碎、频繁切场。
- 标注场与场之间的时空关系与转场方式；跨场道具、服装、情绪、伤口须连续。

---

## 三、人物弧光与主题

- **单一核心主题**：全片只聚焦一个（和解、成长、救赎、遗憾），支线服务主题。
- **弧光可追踪**：开场状态 → 外在目标 Want／内在需求 Need 的落差 → 认知或关系或价值观的转变，拆成若干节拍分到具体场次，在分场表"弧光增量"列逐场登记。
- **高潮即抉择**：高潮场必须让主角做出体现弧光的选择；结局场呈现选择后的新状态。
- **关键道具/意象贯穿**：配置可反复出现的道具或视觉意象（一封信、一碗面、一件旧物），在特写里复现与变奏，承载情感。

---

## 四、情绪曲线

- 每场标情绪强度（1 平静–5 爆发），连成曲线。
- 形态：冷开场小高峰 → 建置平缓铺垫 → 发展阶梯式抬升（中点显著拉高）→ 高潮顶点 → 结局回落留余韵。
- 张弛交替：高压之后必须有舒缓段，但舒缓段仍要有信息增量。
- 中点防塌：第二幕最长，必须用中点转折重新拉起张力。

---

## 五、镜头与声音

- 可从容使用大远景、全景、长镜头（比短剧更宽松），但切换仍须有叙事动机。
- 关键场次（建置入场、冲突对峙、高潮和解、尾声升华）设计 8–15 秒情绪/调度长镜头：用走位、前后景层次、匀速推拉摇移完成景别与关系的递进。
- 超过 15 秒的长镜头拆成多个运动方向与速度一致的单元拼接，衔接帧锁死。
- 声音四层写足；不写 BGM，但可设计**声音母题**（某音效在多处呼应）替代配乐功能。
- 结尾：缓拉/升降长镜头、关键意象特写复现、留白空镜收束。

---

## 六、短篇特有的坑

| 坑 | 症状 | 纠正 |
|---|---|---|
| 没有中点 | 第 5–8 分钟开始平，观众流失 | 补重大揭示或反转 |
| 主题分散 | 什么都想说 | 砍支线，只留一条 |
| 弧光突兀 | 主角突然想通 | 把转变拆成 3–4 个节拍埋到前面场次 |
| 场次过碎 | 每场 30 秒，情绪沉不下来 | 合并场次，关键场做足 |
| 结尾靠悬念 | 像剧集预告 | 改主题落点与余韵 |
| 长镜头无调度 | 画面静止凑时长 | 加走位/机位运动，或拆镜 |
