# 构图雷区（A 类可解锁 / B 类永不放开）

> 分两类，因为它们的成因不同：
> **A 类**是人在表达上的选择——平时不许用，但情绪真需要时可以**明说理由**解锁；
> **B 类**是模型与物理的问题——不管什么情绪都不可能成立，永远不许。
> 写作时没看到这条区别，就会把工程错误当艺术处理。

---

## 一、A 类 · 艺术性雷区（可白名单解锁）

| 编号 | 雷区 | 长什么样 | 什么时候可以解锁 |
|---|---|---|---|
| A1 | 正面居中 | 人物正对镜头、居中切一刀，画面呆板 | 需要一个"被审判/被注视"的正面压迫感时 |
| A2 | 头顶贴边 | 头顶几乎顶到画框上沿，看着憋 | 空间压抑、被压住、抬不起头时 |
| A3 | 死压中线 | 地平线/桌沿精确穿过画面中线 | 需要绝对的平衡或绝对的冷（对称构图）时 |
| A4 | 眼神无空间 | 人物看向画外但那一侧没有留白 | 人物在逃避、被切断与外界联系时 |
| A5 | 断关节 | 画框正好切在手腕、脖颈、膝盖等关节上 | 想强调身体的某一部分（残肢感、局部力量）时 |
| A6 | 背景过亮 | 主体暗、背景过曝，主体糊在光里 | 主体正在被吞没、被抹掉、失去存在感时 |
| A7 | 多人正面平铺 | 三个人并排正对面朝镜头，像证件照 | 众生相、宣告、集体受审时 |

**解锁写法（必须写清三件，缺一不算解锁）**

```
【分镜 7】· 解锁 A2（头顶贴边）
· 为什么：这场是牢房，人的头顶被门框压着，抬不起头
· 替代检查：已试过顶拍与低机位仰拍，表达不出"抬不起头"，故用 A2
```

规则：

1. 同一组里 A 类解锁 **最多一次**；一次戏里最多两次。
2. 解锁必须给"为什么"，且必须写"已试过的替代方案"——只写"因为好看"不算，直接按禁用处理。
3. 没有写解锁说明却用了 A 类 → 按**违规**处理（CT35 只能查形，文字层靠自检）。

## 二、B 类 · 工程性雷区（永不解锁）

| 编号 | 雷区 | 为什么不可解 | 提示词里怎么写才安全 |
|---|---|---|---|
| B1 | 物体穿身 | 模型不理解遮挡关系 | 明确写"手在桌沿上方""刀身在鞘内"，别让两件东西重叠在一句话里 |
| B2 | 服装/发型突变 | 参考图没锁住会跨镜漂移 | 每个角色每套衣服都在 refs 里点名（`[图片N]`），不让模型自由补 |
| B3 | 杂乱前景刺眼物 | 前景多一件小物，模型会把它当主体 | 前景账只留一件，写清"虚化、不抢焦" |
| B4 | 比例失调 | 头身比、手的大小、道具与人的尺度错 | 给尺度参照（"碗口直径约一掌宽"），不给"很大/很小" |
| B5 | 重复元素无重点 | 一排同样的东西，画面没有落点 | 明确"哪一个是要看的"，其余写"一致重复" |
| B6 | 空鸡蛋构图 | 画面里空一块却没有任何信息 | 空白必须是有意的（`留白` 要写"为什么空"） |
| B7 | 道具状态突变 | 上一镜装满的火上镜见底 | 道具状态逐镜沿用，换状态必须给动作（"喝干了"） |

**处理方式**：B 类不许"解锁"，只能**改写**。发现自己在为 B 类找理由，就是写错了。

## 三、机器怎么查（CT35 查得到的三条 + 查不到的）

| 检查 | 手段 |
|---|---|
| 景别连排（A 类风险信号） | CT35：连续 ≥4 个单元同一开场景别 → warning |
| 平均切镜 | CT35：一组 ≥3 镜且时长差 <0.3 秒 → warning |
| 一组超 8 镜 | CT35：单元内 shot 数 >8 → warning |
| 解锁说明缺失 | 人评（自检表逐条走） |
| B 类七条 | 人评 + 抽帧看（`references/外部验收核对表_v1.md` 的压镜检查） |
| 穿身/尺度/状态突变 | 抽帧看；`drama-pipeline-gate` 的 readback 会查角色特征词是否漂 |

> 机器只能查"形"，查不到"该不该"。所以：**CT35 报的是提醒，不是判决**；人评不过就是不过。

## 四、自检（五条）

- [ ] 用到的 A 类雷区都写了「解锁三件」（雷区编号 + 为什么 + 已试过的替代）
- [ ] 同一组 A 类解锁不超过一次
- [ ] 没有任何 B 类雷区被当成"艺术处理"留下
- [ ] 前景只有一件抢焦的东西（想用多件就把其余写成"一致重复"）
- [ ] 道具与服装状态逐镜沿用，换状态有动作交代
