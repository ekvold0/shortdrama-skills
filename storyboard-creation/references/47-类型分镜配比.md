# 类型分镜配比 · 八类题材怎么切、怎么给光

> 用途：第 5 步（时长规划与单元切分）和第 6 步（逐场分镜）开写之前，先按题材查一张「配比表」——每单元几个镜、景别怎么梯、首镜用哪条钩子、运镜偏哪边、光偏哪边。
> 来源：关键词技能 `55-类型成品提示词.md` 的八组成品反推出来的分镜参数，**只保留分镜层能定的量**（镜数、单镜时长、景别、钩子条号、运镜倾向、光位倾向）；米数、K 值、光比不在这一层。
> **和三份写法库的关系**：这里定「这场戏大概什么形状」，具体到每个镜头怎么写，去 `43-运镜选型`、`44-打光选型`、`46-开场钩子` 取。

## §1 八类配比表

### 1. 都市虐恋（雨夜诀别、分开、说破）
| 项 | 取值 |
|---|---|
| 单元时长 | 10–14 秒，情绪戏宁长勿碎 |
| 镜数 | 3–4 镜／单元 |
| 景别梯度 | MS（关系）→ CU（脸）→ ECU（眼/手）→ LS 或后拉（人流吞没她） |
| 单镜时长 | 首镜 1.5–2 秒钩子，中间 3–5 秒，末镜 3–4 秒停留 |
| 开场钩子 | ①微距（伞骨上的水珠）、⑩睁眼、⑬先声后影 |
| 运镜倾向 | 固定为主，末镜一次后拉 |
| 光位倾向 | 6 冷月夜／7 实景霓虹；雨夜必给实景光源位置（路灯在她左后方） |
| 忌 | 两人同框推拉来回、雨只写「下着雨」不写落在哪 |

### 2. 复仇打脸（会议室反杀、当众揭穿）
| 项 | 取值 |
|---|---|
| 单元时长 | 10–13 秒，节奏要顶 |
| 镜数 | 4–5 镜／单元 |
| 景别梯度 | 反打 OTS（对立）→ CU（施压者）→ ECU（证据/文件）→ CU（被压者变色）→ FS 或 MS（全场静止） |
| 单镜时长 | 1.5–3 秒一镜，快切 |
| 开场钩子 | ⑭结果前置、⑮反常动作、⑦高速入画 |
| 运镜倾向 | 前推压施压者，被压者用固定；全场静止给一个后拉 |
| 光位倾向 | 1 三点光（会议室）／13 双色分割（两派对立） |
| 忌 | 群像堆一镜、每镜都推 |

### 3. 悬疑惊悚（楼道听见、门后）
| 项 | 取值 |
|---|---|
| 单元时长 | 8–12 秒，靠停顿 |
| 镜数 | 3–5 镜／单元 |
| 景别梯度 | ECU（局部/缝）→ LS（空走廊）→ MS（她的背）→ CU（反应的半张脸） |
| 单镜时长 | 2–4 秒，允许一个 5 秒的静镜 |
| 开场钩子 | ②黑场炸光、⑪反转机位、⑯异物入镜、⑤静默炸响 |
| 运镜倾向 | 全固定；需要时慢速纵摇，别环绕 |
| 光位倾向 | 2 明暗对照／14 低调戏剧光／9 体积光（门缝） |
| 忌 | 一惊一乍的音效代替画面、把「恐怖感」写进画面内容（CT01） |

### 4. 古装权谋（夜殿对质、密谈）
| 项 | 取值 |
|---|---|
| 单元时长 | 12–15 秒，仪式感 |
| 镜数 | 3–4 镜／单元 |
| 景别梯度 | LS（殿内格局）→ MS（两人距离）→ CU（一人压）→ CU（一人不跪） |
| 单镜时长 | 首镜 2 秒，其余 3–6 秒 |
| 开场钩子 | ⑫尺度错位（殿柱压人）、③倒放、⑨几何硬对比 |
| 运镜倾向 | 固定＋升降（降镜落到人）；环绕只在小角度用 |
| 光位倾向 | 11 火光烛光／2 明暗对照／14 低调戏剧光 |
| 忌 | 竖屏里塞大殿全貌、烛光写成「暖黄的氛围」 |

### 5. 职场压迫（加班、挨骂、背锅）
| 项 | 取值 |
|---|---|
| 单元时长 | 10–12 秒 |
| 镜数 | 3–4 镜／单元 |
| 景别梯度 | LS（空旷工位）→ MS（她的背）→ CU（屏幕/文件）→ CU（脸在暗部） |
| 单镜时长 | 3–5 秒，压抑感靠长 |
| 开场钩子 | ①微距（键盘缝里的碎屑/咖啡渍）、⑮反常动作、④微距陌生化 |
| 运镜倾向 | 固定为主；一次前推到位即止 |
| 光位倾向 | 10 日光灯冷绿／8 平光／15 高调美容光（反讽用） |
| 忌 | 用「疲惫感」当表演（走三级表演：肌肉/可观察/意图） |

### 6. 家庭撕扯（年夜饭摔碗、婆媳）
| 项 | 取值 |
|---|---|
| 单元时长 | 12–15 秒，多人调度 |
| 镜数 | 4–6 镜／单元 |
| 景别梯度 | FS（一桌人）→ MS（说话的人）→ CU（被说的人）→ ECU（筷子/碗落）→ LS（全场僵） |
| 单镜时长 | 2–4 秒，节奏跟着台词走 |
| 开场钩子 | ⑤静默炸响、⑯异物入镜、⑦高速入画 |
| 运镜倾向 | 固定；群像时靠画框内调度，不靠横移 |
| 光位倾向 | 16 钨丝实景家用／12 正午硬光（反季对照） |
| 忌 | 七个人挤一镜、台词超时（>3 秒对白必须插反应镜） |

### 7. 校园甜宠（教室对视、走廊擦肩）
| 项 | 取值 |
|---|---|
| 单元时长 | 8–12 秒，轻 |
| 镜数 | 3–4 镜／单元 |
| 景别梯度 | MS（两人与距离）→ CU（一人偷看）→ ECU（手/笔/耳尖）→ OTS 反打（被看见） |
| 单镜时长 | 2–4 秒 |
| 开场钩子 | ④微距陌生化（橡皮上的字）、⑧移焦双平面、⑩睁眼 |
| 运镜倾向 | 全固定；一次极轻的移焦即可 |
| 光位倾向 | 5 黄金时刻／8 平光／4 逆光晕边（窗口光） |
| 忌 | 甜得太满（每镜都在笑）、把「心动」写进画面内容 |

### 8. 玄幻打斗（山巅一击、斗法）
| 项 | 取值 |
|---|---|
| 单元时长 | 8–12 秒，快 |
| 镜数 | 5–6 镜／单元 |
| 景别梯度 | CU（手/器）→ LS（两人距离）→ MS（起势）→ CU（接触点）→ LS（余波） |
| 单镜时长 | 1–2 秒一镜，冲击镜可到 0.5–1 秒 |
| 开场钩子 | ⑦高速入画、⑨几何硬对比、③倒放 |
| 运镜倾向 | 固定＋甩（硬切收尾）；环绕只给一次 |
| 光位倾向 | 9 体积光／4 逆光晕边／6 冷月夜 |
| 忌 | 一招一镜地拍成流水账、特效写进画面内容（本技能写可拍的内容） |

## §2 速配

| 看到这些关键词 | 按哪类切 |
|---|---|
| 分手、雨、电话、离婚 | 都市虐恋 |
| 会议、证据、下跪、打脸 | 复仇打脸 |
| 走廊、门、听见、血 | 悬疑惊悚 |
| 陛下、殿、跪、密信 | 古装权谋 |
| 加班、PPT、老板、背锅 | 职场压迫 |
| 年夜饭、婆婆、摔碗、亲戚 | 家庭撕扯 |

| 山巅、灵力、剑、掌 | 玄幻打斗 |

题材不明时按「都市虐恋」的配比开，最通用；情绪戏宁长勿碎。

## §3 三条纪律

1. **配比是起点不是牢笼**：这场戏确实需要 6 镜就给 6 镜，但要说得出现在这一版比配比多在哪、为什么。
2. **跨类型混搭只换钩子与光，别换节奏**：都市＋悬疑可以，取都市的镜数与时长，换悬疑的钩子（②⑪⑯）与光（2/14）。
3. **同一集内不换配比**：前五单元按 A 类切、后五单元按 B 类切，观众会觉得换了个剧。
