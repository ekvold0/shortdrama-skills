# 运镜选型 · 分镜层只写「轴向哪、落在哪」

> 用途：写「机位与运镜」列时，从这里选一个轴、一个落点，别现编。
> 来源：关键词技能 `41-运镜库.md`（higgsfield camera.md 的 22 条运镜百科合并去重而来）的**分镜层改写版**。
> **与关键词层的分工**：这里只管「用哪个轴、往哪个方向、停在哪」；米数、度/秒、焦段、快门、f 值一律不写——那是关键词层的活（`55-技法选取` §8、关键词技能 `45` §4）。写了就是 CT09 式的伪精确，分镜表会被打回。
> **一镜一轴**：同一镜跨两个运动族即 CT03。要两个运动，拆两镜，或按 §4 写「一条主、一条辅」。
> **机器拦到哪**：`CT03` 拦多轴（warning）、`CT01` 拦空泛词（error）、`CT07` 拦英文技法名（error）、`CT08` 拦 T4 禁投中文名（error）。「这个运镜配不配这场戏」机器不判，走 70 的自检。

---

## §1 分镜层只写三样

| 写什么 | 例 | 不写什么 |
|---|---|---|
| 轴 | 前推 / 后拉 / 横摇 / 横移 / 跟拍 / 升降 / 环绕 / 甩 / 变焦 / 俯仰 / 固定 | 不写「缓慢推近 0.3 米」「摇 60 度」 |
| 方向与落点 | 沿轴向前，落点停在她的眼；自脚摇至脸，停在下颌 | 不写速度、不写时长比例 |
| 起止景别关系 | 起幅中景 → 止幅近景；前景出画、后景主体显现 | 不写焦段变化、不写 f 值 |

一句合格的分镜运镜：**「前推，起幅中景，落点停在王桂兰的嘴，机位不动不抬」**。它给了模型三件事：往哪走、停在哪、别加戏。

> 为什么分镜层不写数字：分镜是给导演和美术看的，写「0.3 米」既无法验证又会在关键词层被重写一遍，两处数字不一致就成了返工源。关键词层拿到同一句后按 `41-运镜库` 的四要素表补量。

## §2 十个轴 · 什么时候用

| 家族词 | 用在什么情节 | 分镜写法定式 | 禁忌 |
|---|---|---|---|
| 推 / 前推 | 施压、逼近、把观众按到脸上 | 「前推，起幅 X → 止幅近一档，落点在 Y」 | 连续三镜都推会喘不过气 |
| 拉 / 后拉 | 揭示、抽离、告别、孤立 | 「后拉，主体留在画内，环境逐层出现」 | 后拉时主体被挤出画外 |
| 摇 / 横摇·纵摇 | 扫场、交代空间、纵向揭示 | 「原地横摇，落幅停在次主体」 | 收尾没有落点，模型会摇过头 |
| 移 / 横移 | 并肩走、路过、空间平行展示 | 「横移，主体保持画面一侧，前景视差大于后景」 | 竖屏横向被裁，改前推 |
| 跟 / 跟拍 | 追、走、逃、贴身压迫 | 「跟拍，与主体同步，主体始终占画面同一位」 | 不写「手持感」这种空词（CT01） |
| 升降 / 摇臂 | 场面揭示、上帝视角落地 | 「上升，主体始终在画面下三分之一」 | 竖屏升起后主体出框 |
| 环绕 / 旋转 | 对峙、权力展示、情绪悬停 | 「以主体为圆心环绕，主体始终居中」 | 竖屏超 90 度易穿帮 |
| 甩 / 甩镜 | 极速转场、打断 | 「甩到全糊，硬切」 | 本技能全硬切，不加转场特效 |
| 变焦 | 几乎不用 | 「变焦，机身零位移」 | 写实短剧优先推轨；变焦改透视 |
| 俯仰 | 荷兰角、顶拍、视点高度 | 「机位固定，画幅倾斜」「垂直向下俯拍」 | 倾斜角过大在竖屏里主体被压扁 |

**固定**也算一种选择，而且是最稳的一种：AI 生成里固定机位的崩坏率最低。群像、对峙、微表情戏优先「固定」，用画框内的调度积累张力。

## §4 一条主 + 一条辅的写法

允许同镜有第二条运动，但必须是**辅助量级**、且不与主轴抢同一运动轴：

- 允许：主＝跟拍，辅＝轻微俯仰（视线高度随人物身高变化）；主＝固定，辅＝移焦。
- 不允许：主＝环绕，辅＝横移（两张都在动方位，模型会出畸变）；主＝推近，辅＝变焦（透视与位移打架，除非写明平衡条件，那条留给关键词层）。

分镜表上就写成一句：「跟拍为主，视线高度随她低头轻降；不叠加环绕」。

## §5 竖屏（9:16）改写速查

| 原写法 | 冲突 | 改法 |
|---|---|---|
| 横移长镜、航拍大远景 | 宽度被裁，宏大感丢 | 前推穿层、纵摇揭示，用纵深换广度 |
| 大角度环绕 | 半径小则背景穿帮 | 缩到小角度，或「半环绕＋前推」两镜 |
| 升镜 | 顶部空间少，主体出框 | 改降镜，自上而下接近 |
| 甩镜 | 落点信息易丢 | 垂直甩或纯过渡 |
| 多人横排同框 | 每人宽不足 | 拆正反打，一人一镜 |

## §6 组级运镜（一个 4–15 秒单元要成句）

三个镜头各来一下，是最常见的运镜事故。一个单元只讲一件事：

- **施压型**：固定（听）→ 前推（压）→ 固定（反应）。张力靠「不动—逼近—不动」的节奏。
- **揭示型**：后拉（或纵摇）把观众从局部带到全局，末镜固定让人看清。
- **悬停型**：全固定，靠人物微动作和呼吸撑住，用在情绪最满的那一拍。

组内运镜方向要一致（都往人物身上推，或都往外拉），不要一推一拉互相抵消。

## §7 数值去哪了

分镜定完轴，写关键词脚本时去关键词技能 `41-运镜库.md` 取四要素参数串（方向＋幅度＋速度＋时长），那里给的是可直接填 `movement` 的成品句。两处说的必须是同一个轴——分镜写「前推」，关键词就不能变成「环绕」。

---

## §8 自检（每单元一遍）

1. 每镜只有一个运动轴；复合的写清了主与辅。
2. 每镜的运镜都说得出**落点**（停在哪个人/物/景别上），不是「缓缓推近」。
3. 没有米数、度/秒、焦段、快门、f 值（有就是越层）。
4. 组内运镜成句，不是三镜各来一下。
5. 竖屏没有硬塞横移长镜、大环绕、升镜。
6. 英文技法名没进正文（Dutch Angle / dolly zoom 等，CT07）。

## 九、一集别只用一种轴

单镜一轴是底线（CT03），但**整集只有一种轴同样不合格**——十二个单元全是「缓慢推近」，第二个单元起观众就麻木了。

- 一集里用到的运动轴**不少于 4 种**（十个轴见 §二）。
- 全集留**一个招牌镜**：一次尺度揭示、一次性走完的长镜、或只有这个题材才成立的手法，放在情绪最高点；写进该镜「画面内容」并注明。
- 轴够了还要看分布：别把四种轴全塞在前三个单元，后半集只剩固定。
- 关键词层写作时同理，`CT14` 会在那边报 warning（分镜层靠人工，见 `48` 与 `70`）。
