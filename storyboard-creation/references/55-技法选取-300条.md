# 技法选取手册 · grokfilm 300 条（分镜层）

> **定位**：写到「机位与运镜 / 画面内容与景深 / 情绪目标」三列卡住时，按**落点**查这张表，取一条已降维好的写法。不是灵感清单，是施工料单。
> **数据源**：`scripts/cine_tech.json`（300 条，version 1.0，与工作区 `技法库整合/cine_tech.json` 同源）。改数据改真源后重跑构建，勿手改本文件。
> **分层纪律**：本文件是**分镜层**写法——只写意图与可观察行为，**禁毫米/每秒N次/FACS 肌群名**。要数值版去关键词技能 `45-技法到参数.md`。

## §1 用法：三步，别整篇读

1. **定落点**：这一镜要解决什么——机位？光影？景别？剪辑衔接？先查 §3 表找到十字段落点代码。
2. **查档位**：按落点在 §2 找到候选，看档位。**只用 T1/T2**；T3 只在 §4 允许的画幅下用；T4 一律走 §7 替代。
3. **填写法**：照候选的写法改写，落进分镜表对应列。

**三条铁律**：

- **一镜一主技法**：单镜只能有 1 个运动类主技法；光影/色彩/构图类辅技法 ≤2；辅技法不得与主技法抢同一运动轴（转动 vs 位移不可并存）。
- **一个效果一个落点**：同一效果不许在两列重复描述（机位列写了倾斜，画面内容别再写「画面是歪的」）。
- **典故不进正文**：参考片写进「画面参数·参考电影」，只填片名+年份，全片 ≤1 部；正文不出现技法英文名与「致敬/风格化」。

## §6 十套配方 RC01–RC10（填槽即用）

跑通一集用这 10 套打底，改数字不改结构。**每套的主技法序列按序使用，不要合并成一镜。**

### RC01 开场钩子（前 3 秒抓人）

- **主技法（按序）**：插入镜 → 大特写 → 推镜
- **配套参数**：单组 4–5 秒，2–3 镜
- **提示词骨架**：`0.0–2.0秒：{道具局部}占画面70%，{动作}；2.0–4.5秒：切{人物眼部}大特写，瞳孔{收缩}，机位由{高度}缓慢推进至{距离}`

### RC02 权力碾压（强弱同框）

- **主技法（按序）**：仰拍 → 俯拍 → 短焦贴近
- **配套参数**：光比 1:16，背景压黑
- **提示词骨架**：`{弱势方}位于画面下三分之一仰头，{强势方}背光成剪影占据上三分之二，机位{worms-eye}高度 30cm 上仰 15度`

### RC03 反转揭示（信息砸脸）

- **主技法（按序）**：插入镜 → 停帧 → 荷兰角
- **配套参数**：单镜≤2 秒，节奏 3 连切
- **提示词骨架**：`插入镜{关键证据}0.8秒 → 停帧0.5秒 → 荷兰角倾斜12度切回{人物}，机位{高度}不变`

### RC04 长对白压迫（说不停）

- **主技法（按序）**：过肩 → 反应镜 → 慢推
- **配套参数**：每 2.5–3.0 秒一次反应镜
- **提示词骨架**：`OTS 让{听者}占前景1/4虚化，{说者}在三分线，机位每 3 秒推近 10%，反应镜 0.6–0.8 秒`

### RC05 回忆闪回（时间跳切）

- **主技法（按序）**：柔焦 → 降饱和 → 边缘失焦
- **配套参数**：S6 Nostalgic 参数
- **提示词骨架**：`整组{降饱和20%}、{颗粒}可见、四角{柔焦}，色温 3000K 偏黄，声音只留{环境层}并加{混响}`

### RC06 夜戏独行（不安感）

- **主技法（按序）**：单点光源 → 长焦压缩 → 背跟
- **配套参数**：光比 1:32，色温 4000K 偏绿
- **提示词骨架**：`{人物}背影占画面中央1/3，唯一光源为{路灯}在画面右上，机位后跟 2 米持稳，长焦{focal}压缩纵深`

### RC07 手机屏揭示（信息特写）

- **主技法（按序）**：插入镜 → 微距 → 屏幕光打脸
- **配套参数**：仅屏幕为光源
- **提示词骨架**：`{屏幕}占画面80%，可见{内容}，屏幕光从下方打亮{面部}，机位距{15cm}正面平视，画面{琥珀色CRT}`

### RC08 冲突爆发（动手瞬间）

- **主技法（按序）**：甩镜 → 手持晃动 → 高速快门
- **配套参数**：1/250 秒，单镜≤1.5 秒
- **提示词骨架**：`0.0–0.8秒 甩镜跟随{挥动}，1/250秒冻结{接触点}，接 0.7 秒反向甩回{反应}`

### RC09 集末悬念（留白收束）

- **主技法（按序）**：缓慢后拉 → 大面积空镜 → 黑场
- **配套参数**：结尾留白≥0.5 秒
- **提示词骨架**：`{人物}留在画面{位置}，机位以{极慢}速度后拉至{全景}，最后 0.8 秒画面变暗，黑场≤1 秒`

### RC10 极简空镜（换气）

- **主技法（按序）**：对称构图 → 静止机位 → 环境音
- **配套参数**：单组 3–5 秒，1 镜
- **提示词骨架**：`机位完全静止，{建筑/窗}几何对称占满画面，无人入镜，四层音效只留{环境细节}与{空间混响}`

| 变形宽银幕 | Anamorphic | 光学 | 竖屏完全冲突；横屏可作质感但须与画幅参数一致；替代＝竖屏改「浅景深+横向光带」造宽银幕感 |
| 数字减龄 | Digital De-aging | 禁用项 | AI 换脸必糊；替代＝换演员＋妆造区分 |
| 黑人剥削片 | Blaxploitation | 审核 | 文化与合规风险，整类弃用 |
| 剥削电影 | Exploitation Film | 审核 | 平台红线，整类弃用 |
| 色差 | Chromatic Aberration | 禁用项 | AI 感标志物，违写实红线 |
| 交叉淡化 | Crossfade | 禁用项 | 与 dissolve 同禁；替代同上 |
| 循环动画 | Loop Animation | 禁用项 | 短剧无循环需求；写了会让人物动作卡顿 |
| 磨坊电影 | Grindhouse | 审核 | 与写实/画质红线冲突；替代＝胶片颗粒（轻度） |
| 身体恐怖 | Body Horror | 审核 | 平台审核红线；替代＝遮挡＋声音暗示（sound 层承担） |
| 英雄流血 | Heroic Bloodshed | 审核 | 审核红线；替代＝枪口闪光＋人物后仰＋无血浆 |

**负向提示词纪律**：T4 技法名**不能**当负面词乱贴（写「禁一镜到底」反而会引入构图）。负向只写「禁 X 现象」，如「禁画面旋转」「禁转场特效」。

## §8 与关键词层的分工（最容易串味的一处）

| 维度 | 分镜层（本技能） | 关键词层（45-技法到参数） |
|---|---|---|
| 数值 | **禁**毫米/每秒N次/FACS/光比数字 | **要**米/度/秒/百分比/色温 |
| 情绪 | 意图 + 可观察行为 + ≤1 节奏锚 | 肌肉名 + 方向 + 距离 + 呼吸次数 |
| 一镜到底 | 禁止单镜实现，拆 3 镜续接 | 3 组各 2.0 秒，声桥接续 |
| 参考电影 | 画面参数·参考电影，≤1 部 | params.reference，≤1 部且须在片单库 |
| 反向提示词 | 不写；只在衔接备注写「由 X 替代」 | 五段齐备（基础/质量/畸变/穿帮/剧情） |

> 串味的典型症状：分镜表里出现「roll 轴倾斜 12 度」。正确写法是「画面里门框窗框都不是正的，人站不直」——数值留给关键词层，那里模型才需要它。
