# 方案候选索引 · 第 3 步按「情绪 / 题材 / 剧情节点」取条目

> **一句话定位**：本文件只**指路**——第 3 步要的候选一律从 `46 / 47 / 48 / 50 / 53 / 55` 里取，**条目正文不在这里复制**；同一句话只有一个源头，改库不会两处打架。
> **用在哪**：第 3 步「叙事结构方案」（闸门 2），产物是 `templates/02-叙事结构方案模板.md`。
> **不做什么**：不新增拍摄知识、不发明条目编号、不评好坏（好坏走 `70-自检清单.md` 与人工）。

**怎么用（4 步，十分钟量级）**

1. 定处境 → §3 按情绪检索表（本集主角落在哪一格）。
2. 定题材 → §4 按题材检索表（拿结构组合、节奏上限、镜头偏好、要避开的套路）。
3. 还找不到切入点 → §2 三层结构表按「剧情节点」往下钻。
4. 按 §5 出 **6–8 条候选** → 用户勾选 → 才写 02 的方案表。

引用格式统一写成 `库名 §节 序号【条目原名】`，例：`46 §2 ⑨几何硬对比`。这样写才搜得到；只写「46 里有」等于没引。

## §5 候选输出规范

### 5.1 条数与配比（固定）

| 项 | 规定 |
|---|---|
| 基准 | **7 条 ＝ 钩子 4 条 ＋ 结构组合 3 条** |
| 最多 | 8 条：多出的 1 条标【备选】，钩子或结构组合均可 |
| 最少 | 6 条：只许减结构组合（4＋2），不许减钩子 |
| 钩子分布 | 4 条至少覆盖 `46 §4` 的两个通道（视觉／听觉／空间），否则等于四条同款 |
| 结构组合 | 3 条必须"真不一样，不能只换名字"（`templates/02` 开头原文） |

### 5.2 每条的四段写法

1. **一句话描述**：写"做什么"，不是"叫什么"（例："首镜耳光已经打完，第二镜回到三分钟前"）。
2. **适合什么情绪**：从 §3 取词（例："反转打脸 / 身份碾压"）。
3. **本集怎么落**：哪个单元、哪一镜、多少秒、写进哪一列（钩子只进「画面内容」，机位列不写手法词）。
4. **来源**：`库名 §节 序号【条目原名】`；**主来源 1 个 ＋ 辅来源最多 1 个**。

来源三档写法：

| 情形 | 写法 |
|---|---|
| 单条 | `46 §2 ⑨几何硬对比` |
| 模板类 | `templates/02 备选库「闪前冷开场」` |
| 组合 | `46 §3 ⑭结果前置 ＋ templates/02 备选库「闪前冷开场」` |

**不许**：来源写"AI 建议／行业惯例／综合经验／结合剧本"；只写文件名不写节号（搜不到）；一个候选挂三个以上来源（等于没来源）；改了结构又说来源只是钩子。

### 5.3 示例（都市打脸第 1 集，7 条＋1 条备选）

> 只演示格式与颗粒度。换题材按 §3/§4 重取，别照抄这 8 条。

**C-01｜钩子：结果前置**
- 一句话：首镜耳光已经打完，第二镜才回到三分钟前她推门进会议室。
- 适合：反转打脸 / 身份碾压。
- 本集怎么落：首单元首镜 0—1.5 秒 CU 固定（手停在半空、对方脸偏过去），第 2 镜硬切回门口；"打完"只进「画面内容」，机位列照写 CU／固定。
- 来源：`46 §3 ⑭结果前置`。

**C-02｜钩子：微距跳切大远景**
- 一句话：先给合同上被涂改的签名（微距），第二镜才见整间会议室。
- 适合：被冤枉 / 反转打脸。
- 本集怎么落：首镜 1.0–1.5 秒 ECU 微距固定，第 2 镜 LS 会议室，第 3 镜回签名；涂改必须是本集要解释的那一处。
- 来源：`46 §2 ①微距跳切大远景`。

**C-03｜钩子：先声后影**
- 一句话：画外一声"你签的字，你认"，1 秒后她才出画。
- 适合：被冤枉 / 威胁。
- 本集怎么落：首镜空镜（桌面文件）＋画外台词放「台词·音效」列，画面列只写空镜里有什么；第 2 镜 MS 她抬头。
- 来源：`46 §3 ⑬先声后影`。

**C-04｜钩子：几何硬对比**
- 一句话：一条长桌把画面切成两半，她只占下三分之一。
- 适合：身份碾压。
- 本集怎么落：首镜 1.0–2.0 秒 FS 固定，俯角写进机位列；对面的人只给背影。
- 来源：`46 §2 ⑨几何硬对比 ＋ 43 §3 #18 顶拍`。

**C-05｜结构组合：闪前冷开场＋线性回溯**
- 一句话：首单元给打脸结果，第 2 单元回退到"她进门"，之后线性推到底。
- 适合：反转打脸 / 复仇。
- 本集怎么落：回退点必须是剧本已有时点（"她刚坐下"），第 2 单元首镜切换，切换镜写进「衔接备注」。
- 来源：`templates/02 备选库「闪前冷开场」＋ 组合规则第 3 条`。

**C-06｜结构组合：双线交叉＋中段合流**
- 一句话：会议室线与走廊线交替，合流在"推门"那一镜。
- 适合：身份碾压 / 对峙。
- 本集怎么落：A／B 各 2.0 秒交替硬切，用声桥标记切换（跨线声桥只写进衔接备注）；合流后不再拆线。
- 来源：`templates/02 备选库「双线交叉」＋ 55 §4.3 平行剪辑替代（交替硬切）`。

**C-07｜结构组合：线性＋集末悬念**
- 一句话：全片线性，末单元后拉、空镜、黑场 ≤1 秒收。
- 适合：复仇 / 悬疑。
- 本集怎么落：末单元 3–5 秒、1–2 镜，最后 0.8 秒压暗；黑场不超 1 秒。
- 来源：`55 §6 RC09 集末悬念`。

**C-08｜备选：主观视角开场**
- 一句话：全程她的视线，只在打脸那一下切回客观反打。
- 适合：被冤枉 / 身份碾压。
- 本集怎么落：首单元用主观视点，必须写清画外人在哪；反打那镜交代越肩方向。
- 来源：`templates/02 备选库「主观视角」＋ 43 §3 #24 主观视点`。
