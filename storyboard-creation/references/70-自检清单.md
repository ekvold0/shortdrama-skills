# 自检清单

> 交付前必跑三轮，结果随交付物一起给用户。任一项不过，先修再交。
> 带 ★ 的是高频退回项，几乎每次都会踩。

---

## 第一轮 · 逐句映射

| # | 检查项 | 判定 |
|---|---|---|
| 1.1 ★ | 剧本每一句台词都有对应镜号承接 | 按原文顺序逐句打勾 |
| 1.2 ★ | 每个动作、心理活动（外化）、环境变化都有画面落点 | 同上 |
| 1.3 | 原文过渡段单独给了镜头，没有跳过 | 常见漏点：时间跳跃、路上、进屋 |
| 1.4 | 被删减或合并的内容逐条列出理由 | 无理由＝不许删 |
| 1.5 | 叙事顺序若调整（闪前/倒叙），有明确的视觉标识与回归点 | 标【闪回】并说明区分手法 |
| 1.6 | 有台词的角色全部出镜（电话/广播/主观除外，需标注理由） | 逐句核对"声音—人物—画面" |
| 1.7 | 剧情在场的角色没有只以画外音存在 | 名单逐场比对 |
| 1.8 | 群像没有堆在一个镜头里，有独立反应镜 | 群戏场必查 |

## 第二轮 · 单元与账目

| # | 检查项 | 判定 |
|---|---|---|
| 2.1 ★ | 各镜秒数合计 ＝ 各单元合计 ＝ 全片总时长（零误差） | 三个数字必须完全相等 |
| 2.2 ★ | 无单元 <4 秒、无单元 >15 秒；目标区间 7–12 秒 | 列时长表核 |
| 2.3 | 单元内不跨场景 | 逐单元看场景属性 |
| 2.4 | 单元之间时间连续或顺序递进，无解释性跳跃 | 看衔接备注 |
| 2.5 ★ | 逐句台词按 2.5–3.0 字/秒验算，能讲完、不抢话 | 字数 ÷ 语速 ≤ 占用时长 |
| 2.6 | 单镜时长覆盖对白，且留 0.5–1 秒情绪留白 | 逐镜看 |
| 2.7 | 超过 3 秒的对白有反应镜（0.6–0.8 秒）＋画外音标注 | 逐句查 |
| 2.8 | 总时长不超过用户给的上限 | 与参数比对 |
| 2.9 | 集末钩子纯黑 ≤1 秒 | 看末镜 |

## 第三轮 · 合规与规格

| # | 检查项 | 判定 |
|---|---|---|
| 3.1 ★ | 画幅、分辨率与运行期参数一致，全片统一 | 每单元都复写了 |
| 3.2 ★ | 字段齐全、名称与顺序符合模板，无自创字段 | 逐字段核 |
| 3.3 ★ | 无"同上/同前/见前文"，每单元自包含 | 全文检索 |
| 3.4 ★ | 无牛顿、毫米、频率、肌群拉丁名等伪精确参数 | 全文检索关键词 |
| 3.5 | 每镜节奏锚 ≤1 个 | 数一数 |
| 3.6 | 情绪分级标注正确（A 微表情 / B 峰值 / C 常态）；全片 B 级 1–3 次 | 抽查高潮与常态段 |
| 3.7 | 景别列只填枚举值；主观/半主观写进机位列 | 抽查 10 行 |
| 3.8 | 角度用汉字"度"，无半角 ° | 全文检索"°" |
| 3.9 ★ | 声音四层齐全，无 BGM/配乐描述 | 逐单元查 |
| 3.10 | 所有文字（字幕/时间卡/UI/标牌）标注后期叠加 | 全文检索"文字""字幕" |
| 3.11 ★ | 镜头间全部硬切，无转场特效 | 全文检索"叠化/淡入/划像" |
| 3.12 ★ | 站位无裸"居左/居右"，全部物理方位 | 全文检索"画面左/画面右" |
| 3.13 | 手别、越肩方向、视线、位置、机位五者自洽 | 逐场核空间图 |
| 3.14 | 驾驶/操作场景没有违规回头 | 特殊场景必查 |
| 3.15 | 每个空间都有座位关系图且与画面一致 | 逐场比对 |
| 3.16 | 景别按递进/递退组织，无同景别无意义跳切 | 抽查连续 5 镜 |
| 3.17 | 每个运镜说得清目的，器材量级不矛盾 | 抽查复杂运镜 |
| 3.18 | 封闭场景长对话插了 1–2 个呼吸口 | 查车厢/房间戏 |
| 3.19 | 台词改动有留痕表；无改动写"无" | 查表 |
| 3.20 | 引用外部条目写全出处（附件4 第N条＋片名片段） | 全文检索"附件4" |
| 3.21 | 与前后集的人物、道具、设定衔接无漏洞 | 对照上下文 |
| 3.22 | 合规风险点已标注【合规风险提示】 | 暴力/敏感题材必查 |

### 第三轮附 · 写法层（43/44/46/47）

| # | 检查项 | 判定 | 机器 |
|---|---|---|---|
| 3A ★ | 每集首单元首镜第一帧就是异常，且首镜时长 ≤2 秒、第二镜交接（46） | 逐集看首镜 | CT11（缺特征词 warning） |
| 3B | 首镜钩子 ≤3 条，分属视觉/听觉/空间不同通道（46 §4） | 数一数 | 人工 |
| 3C | 钩子由本集核心事件当场兑现，不是假预告（46 §5） | 对照本集剧情 | 人工 |
| 3D | 手法词（黑场/倒放/微距）写在画面内容，没有塞进机位列（46 §6） | 检索机位列 | 人工 |
| 3E | 每镜只有一个运动轴，复合的写清主与辅（43 §4） | 逐镜看 | CT03（多轴 warning） |
| 3F | 每镜运镜都说得出落点，不是「缓缓推近」（43 §1） | 逐镜看 | 人工 |
| 3G | 没有米数/度秒/焦段/快门/f 值（43 §5、数值分层） | 全文检索数字 | 人工 |
| 3H | 每单元都有光位，说得出光源是什么，写了硬或柔（44 §1） | 逐单元看 | 人工 |
| 3I | 冷暖关系与视觉常量表一致，实景光源给了画面位置（44 §4） | 抽查 | 人工 |
| 3J | 没有 K 值、光比数字（越层） | 全文检索「K」「光比」 | 人工 |
| 3K | 整场切法符合题材配比，或写清了偏离理由（47 §3） | 对照 47 | 人工 |
| 3L | 无英文技法名、无典故入正文、「参考电影」≤1 部且带年份 | 检索 | CT07 / CT05 / CT06 |
| 3M | 无反投影/斜投影（CT08 禁投 T4 中文名） | 检索 | CT08 |

> 「机器」列写了规则码的，`scripts/verify.py` 会拦；写「人工」的只能靠这一轮看出来，别跳。

## 高频退回原因（写的时候就要避开）

| 退回原因 | 占比感受 | 根因 | 预防 |
|---|---|---|---|
| 时长账目对不上 | 极高 | 写完才加总 | 先做第 5 步台账 |
| 只闻其声不见人 | 高 | 写台词时忘了给出镜 | 写完台词立刻配镜 |
| 全程克制没有峰值 | 高 | 怕夸张 | 高潮强制 B 级 |
| 站位左右乱 | 高 | 用画面左右定位 | 建空间图，用物理方位 |
| 单元跨场景 | 中 | 按原文段落切而不是按场切 | 先划场界再切单元 |
| 空镜凑时长 | 中 | 台词不够用环境补 | 补细节镜/道具镜，必须带信息 |
| 同上/同前 | 中 | 图省事 | 每单元复写 |
| 转场写特效 | 中 | 旧习惯 | 检索"叠化/淡入" |
| BGM 描述 | 中 | 旧习惯 | 检索"配乐/BGM/音乐" |
| 术语矛盾 | 低但致命 | "长焦推 0.6 米" | 写前核器材量级 |
