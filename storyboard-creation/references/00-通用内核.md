# 通用内核（三模式共用）

> 三份基础规范中 90% 相同的方法层。与 `05-落地要求-覆盖层.md` 冲突时，以覆盖层为准。
> 本文件管"怎么读、怎么拆、怎么写"；具体数值差异看 `10/20/30`。

---

## 一、读剧本：九层采集

通读剧本，逐段逐句提取，不允许跳过任何描写、对话、动作、心理或环境细节。产出是一张采集表，不是感想。

| 层 | 要提取什么 | 落成什么 |
|---|---|---|
| 角色层 | 姓名、年龄、性别、地域、身高体型、脸型五官、发型发色发质、服装（每件：款式+颜色+材质）、标志物、体态与步态 | 角色卡底稿 |
| 主体层 | 人物以外的重要道具/物品/生物：材质、尺寸、颜色、形状、纹理、磨损、功能、发光或特效属性 | 主体卡底稿 |
| 场景层 | 地理位置、建筑风格、内外、时间（年代/季节/昼夜/时刻）、天气（量化）、温度体感、环境光、空间尺寸、核心陈设 | 场景卡底稿 |
| 叙事层 | 按原文顺序列出所有事件节点：每个动作、每句对话、每个心理外化、每个环境变化、每个情绪转折、每次位移、每个时间标记 | 事件清单（逐句编号） |
| 动态层 | 所有动作、表情、环境动态、光线变化的走向与节奏 | 动作清单 |
| 声音层 | 环境音、拟音、对白（逐字）、声音母题 | 声音清单 |
| 运镜层 | 适合复杂运镜或长镜头的段落（动作戏、情绪爆发、关键揭示、关系调度） | 运镜机会点 |
| 站位层 | 每场初始位置、朝向、移动路径、相对距离 | 空间关系底稿 |
| 特殊叙事层 | 闪回/倒叙/梦境/幻觉、内心独白、多人同时说话、天气突变、换装、外貌变化、角色消失 | 特殊处理清单 |

**输出要求**：采集表要能反向核对——每一句原文都能在表里找到归属。做不到就是漏了。

## 二、一致性锚点卡

对每个主要角色、每个重要主体、每个主要场景各建一张卡，**段落式**输出，不用表格塞满。

### 2.1 角色卡

```
姓名｜年龄｜性别｜地域
外形：身高体型 / 脸型 / 五官特征 / 发型发色发质 / 皮肤状态
服装：上衣（款式·颜色·材质）/ 下装 / 鞋 / 配饰（逐件）
标志物：
体态与步态：
声线：音色 / 语速 / 口音 / 口头禅
弧光状态：开场状态 → 结局状态（仅主角与关键角色）
```

### 2.2 主体卡

```
名称｜类型
材质｜颜色｜尺寸｜形状｜纹理｜磨损痕迹
特殊功能｜发光或特效属性
状态变化表：第X场（新/旧/破损/易主）
```

### 2.3 场景卡

```
场景名｜内/外｜地点｜时间（年代·季节·昼夜·时刻）
环境光：光源方向 / 色温 / 强度
空间：尺寸 / 核心陈设 / 出入口 / 纵深层次
视觉风格：艺术风格 / 画面质感 / 色彩分级倾向 / 特效风格
天气量化：温度 / 湿度 / 风 / 雨雪
变体：同一场景在不同时间/情绪下的光线与陈设变化
```

**参考图规则**
- 用户给了参考图：后续分镜优先遵循参考图；角色描述可简化为"角色 A（按参考图）"，其余动态照常写。
- 没给：文字锚点为唯一依据，并在交付物开头提醒"建议先生成定妆照与场景概念图再进视频生成"。
- 锚点卡里的动作/情绪只作默认参考，**每个单元仍须重新写**，不得写"见锚点卡"。

## 三、空间座位关系图（每场必建）

比锚点卡更硬：这是防串座、串手、越轴的基础。

```
场号：
空间类型：车厢 / 客厅 / 走廊 / 驾驶室 / 病房……
固定物：门 · 窗 · 桌 · 中控台 · 通道（作为方位基准）
人物坐标：
  A：靠窗一侧，面朝车厢前部，视线落 B，距镜头最近（前景）
  B：靠过道，面朝 A，身体略侧向门
  C：画面深处，背对窗，站在门口
移动路径：A 第 3 秒起身，沿过道向车尾走 1.5 米
手部约定：B 左手扶杆、右手持伞；C 右手抱箱
```

**书写禁令**
- 不用裸"居左/居右"（机位一翻就错），改用"靠门一侧／靠窗一侧／画面深处／前景虚化"。
- 距离写相对关系（"隔一张桌面""两人相距约 1.5 米"），不写"距镜头 2 米"这种随镜头变化的绝对数（除非该镜固定机位且确有需要）。

## 四、七字段写法

字段固定、顺序固定、不得增删改名。

### 4.1 镜号
- 竖屏/横屏：`S03-005`（第 3 集第 5 镜）；短篇：`M3-S09-05`（第 3 幕第 9 场第 5 镜）。
- 同一镜内多组分切：`-1`、`-2`。
- 闪回/梦境：镜号后加 `【闪回】`，不另起编号。
- 全片不跳号、不重号、不断号。

### 4.2 景别（只填枚举）
`ELS / LS / FS / MS / 中近景 / MCU / CU / ECU / OTS`

- 主观、半主观、客观、反应——写在**机位列**，不写进景别列。
- 递进/递退组织（MS→CU、FS→MCU），切换要有动机。
- 对话/独白必须换景别，禁止同景别无意义跳切。

### 4.3 时长
- 一律"第 X.X 秒至第 X.X 秒"，0.1 秒精度。
- 单镜上限：竖屏 8 秒 / 横屏 10 秒 / 短篇 15 秒。
- 单镜必须覆盖对应台词，并留 0.5–1 秒情绪留白。
- 超过 3 秒的对白按"长对白闭环"处理（见第五节）。
- 账目零误差：各镜合计 ＝ 各单元合计 ＝ 总时长。

### 4.4 机位与运镜
机位由四维决定，四维都要写出来：

| 维度 | 取值 | 叙事作用 |
|---|---|---|
| 拍摄距离 | 即景别 | 主体大小与信息量 |
| 拍摄高度 | 平视 / 仰拍 / 俯拍 / 鸟瞰 / 倾斜（荷兰角） | 权力、压迫、失衡 |
| 拍摄方向 | 正面 / 斜侧 45 度 / 正侧面 / 背面 | 正式、立体、轮廓、悬念 |
| 视角属性 | 客观 / 主观 / 半主观 / 反应 | 代入、旁观、正反打 |

运镜：固定 / 跟拍 / 推 / 拉 / 摇移 / 升降 / 环绕 / 甩。写清轨迹、速度、起止时间、画面同步动态。
**量级必须匹配**：航拍只用于高空大范围；小幅升降写摇臂或云台；长焦"推近"靠变焦或大幅位移。

对话的三角形机位（两人及以上）：

| 机位 | 位次 | 作用 |
|---|---|---|
| 1 号 | 顶角/主机位 | 交代环境与关系，场的开篇与收尾 |
| 2、3 号 | 平行机位 | 单人近景/特写正反打，对话主力 |
| 4、5 号 | 外反拍/过肩 OTS | 建立空间关系与客观性；写清越过谁的肩、朝哪拍 |
| 6、7 号 | 内反拍 | 单人主观，强调情绪与重要台词 |
| 8、9 号 | 骑轴/正反打 | 直视镜头、关键宣告、强情绪对视 |

轴线原则（180 度）必守；越轴只能用中性镜头、机位运动越轴、人物运动越轴来实现。

### 4.5 画面内容与景深
固定结构：**场景氛围 → 人物站位 → 光影色调 → 人物动作 → 场面调度 → 细节道具**。

- 开头写场景属性：`【内/外】+ 地点 + 时间（日/夜/晨/昏）+ 氛围基调`。
- 逐句映射：原文每个动作、过渡、环境变化都要有落点，不得跳过。
- 站位用第三节的物理方位法。
- 景深：特写/近景浅景深；中景中等；全景/远景大景深。可用景深变化揭示信息。
- 每个画面统一引用场景卡的【视觉风格】。

### 4.6 台词与音效
四层：**人声 / 核心音效 / 环境细节 / 空间混响**。不写 BGM。

- 人声：逐字、标角色、标语速与情绪基调；内心独白标【旁白】、不生成口型。
- 核心音效：只在关键节点用（碎裂、倒吸气、心跳、顿住的鼓点），标 0.1 秒触发点。
- 环境细节：与场景严格匹配；同一场景跨时间复现要随天气/心境变化。
- 空间混响：小房间短混响、大厅长混响、户外几乎无混响、水下闷。
- 优先级：人声 ＞ 核心音效 ＞ 环境细节。
- 静音要显式标注【静音】与时长。

### 4.7 情绪目标
两句结构：**先点核心感受，再给可观察外化**。按 `05-覆盖层` 的表演三级表写，禁止量化伪精确。

## 五、长对白闭环（强制）

1. 单句超过 3.0 秒 → 至少插入 1 个听者反应镜或空镜。
2. 反应镜期间对白转画外音，画面给听者面部或空镜。
3. 切回说话人时，从"正在说"的状态接（嘴微张、头保持说话角度），不能从"刚说完"接。
4. 插入节奏：每 2.5–3.0 秒插一个，反应镜 0.6–0.8 秒。
5. 时间段内必须写明："第 X.X 秒至第 X.X 秒插入反应镜，画面为……，对白画外音继续"。

## 六、防穿帮与多主体微动态

### 6.1 防穿帮
- 每个时间段都必须有位置与相对关系，移动要写路径与速度。
- 跨场复现同一场景/服装/道具，核对状态连续性（伤口、发型、道具新旧、光线时段）。
- 换装必须有过渡（空镜、遮挡、时间省略），禁止瞬间换装。

### 6.2 多主体微动态（强制）
- 画面内 2 个及以上主体时，**非聚焦主体也必须有持续微动态**：呼吸起伏、眨眼、视线微移、重心转移、手指屈伸、衣摆、发丝、吞咽。
- 每段至少写 1 项，分别注明，不得只写聚焦主体。
- 微动态只写"看得见的变化"，不写频率数值。

## 七、特殊叙事处理

| 类型 | 处理 |
|---|---|
| 闪回/倒叙/梦境/幻觉 | 色温突变、边缘柔化、画质差异、画幅内框；镜号标【闪回】；回到现实用硬切 + 色温恢复 |
| 内心独白 | 不生成口型，用旁白；画面给微表情或象征性空镜 |
| 多人同时说话 | 标清每人口型与声音错落；每个说话人至少 0.5 秒；对白并列写 |
| 天气突变 | 写变化过程与光线变化（亮度、色温），不写"突然下雨" |
| 角色换装 | 空镜/遮挡/时间省略过渡 |
| 外貌变化 | 写过程（伤口如何出现、发色如何变），不写结果 |
| 角色死亡/消失 | 标清时间点与画面处理，后续场景不得出现 |

## 八、复杂运镜落地

可用 ACT 语言、子弹时间、环绕、贴地俯冲、三段式，但**必须转成物理描述**：

- 禁止：只写"子弹时间""环绕镜头"。
- 要写：以谁为中心、轨迹、速度曲线、与主体的相对位置、起止时间、画面内各元素同步动态。
- 示例：以角色为中心极慢速环绕，角色跃起瞬间凝固，衣摆发丝缓飘，背景水滴悬停，持续 2.5 秒。

## 九、结构规划

### 9.1 短剧单集（竖屏/横屏）
轻量版：故事梗概 ＋ 3–4 种结构方案（六要素）＋ 场次清单。不做全片三幕配比。

### 9.2 短篇视频（10–15 分钟）
必做全片结构规划，见 `30-短篇视频.md`：三幕配比表、分场表、弧光、情绪曲线。

## 十、开工前的五问

1. 画幅与分辨率是多少？（必答）
2. 这集要讲哪一件事？反转在哪？
3. 谁是主角，他要什么（Want），他真正缺什么（Need）？
4. 哪一句台词/哪一个动作是这一集的"钉子"（必须在镜头里落地）？
5. 和上一集/下一集怎么接？

答不出第 4 条，先别写分镜——说明还没读懂这集。
