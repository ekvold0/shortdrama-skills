# 表演与动作衔接（分镜层写法）

`40-表情微表情库.md` 管的是脸上那套（FACS、微表情分级）；这一份管的是**身体**——动作怎么起、怎么做完、怎么接到下一镜，以及哪些动作根本拍不出来。

源材料是 lemo-opuscar 的 `DIRECTOR.md` §9（表演）与 §10（最常见的失败），已改成真人短剧分镜的写法。它的「两掌之间插值」那种动画术语没有搬，只留下能落到分镜表里的判断。

分镜层铁律不变：**不写数值**（不写厘米、度、秒的精确值、不写 FPS），那是关键词层的活。

---

## 一、三拍：预备—动作—跟随

一个有意义动作，在分镜里要占三段，不是一格：

| 拍 | 画面内容里写什么 | 例（起身） |
|---|---|---|
| **预备** | 重心先动、身体先倾、手先离位 | 「上身先向前倾，双手撑住扶手」 |
| **动作** | 主位移或主变化，方向 + 幅度 | 「借手臂撑力把身体顶起，臀部离开座椅」 |
| **跟随** | 惯性余动、衣物头发滞后、落定 | 「起身后微微前冲半步才稳住，外套下摆甩起后垂落」 |

- 三拍可以是**一镜内**（镜头不停），也可以是**两到三镜**——起势一镜、完成一镜、落定一镜。切在「动作顶点」最好看，切在「动作中段」会显得断。
- 分镜表里，三拍都写在「画面内容」，不要写在「机位」列。

## 二、动作匹配切（本技能唯一鼓励的「转场」）

本技能只用硬切、禁转场特效，但硬切可以切得顺——靠三样：

| 手法 | 怎么切 | 例 |
|---|---|---|
| **动作匹配** | 上一镜动作的收势，与下一镜动作的起势同向、同速 | 上一镜她抬手把茶盏推向桌沿／下一镜同一只手在推开门 |
| **视线匹配** | 上一镜人物看的方向，下一镜就是他看到的东西 | 她抬眼看向门外／门外走廊的灯灭了 |
| **声音桥** | 上一镜的声音延续到下一镜画面里，或下一镜的声音提前进来 | 上一镜门锁咔哒／下一镜她的背影，脸上已变色 |

- 声音桥的「提前进来」只允许在**同一生成单元内**。跨单元的声音错位要在剪辑层做，写进「衔接备注」，不要写进音频列——每段是独立生成，声音会跟着画面走。
- 切点要**有动机**：动作、视线、声音、信息之一。找不到动机的切点就是「为了换景而切」，观众感觉得到。

## 三、单镜只做一个动作组

- 一镜内最多一个完整的「预备—动作—跟随」，可以再带一个微动作（眼神、手指）。
- 「她站起来，走过去推门，回头看他」= 三个动作组，至少拆三镜。
- 冲突戏快切不是「一镜多动作」，是「每个动作切得短」。

## 四、重量、重心、接触

这三样是 AI 分镜最容易漏、观众最容易看出假的：

- **支撑脚**：转身、起身、蹲下都要写明哪只脚承重（`右脚为支撑脚，左脚跟先离地`）。
- **落地反馈**：脚落地时膝盖微屈、衣物与头发下沉一下；不写就是一记无声的飘落。
- **背负与搬运**：重心偏向一侧、另一侧手臂外展平衡。
- **手与道具**：交接写成「一只手放到另一只手上」；写清接触点（托杯底、扣杯耳、指节压住边沿），不许出现道具悬空。

## 五、反应镜与「听」的动作

- 对白超过 3 秒要插反应镜（这是原有硬规则），反应镜里**必须有动作**，不能只是「他听着」：下颌收紧、目光移开、手指扣紧、喉咙吞咽。
- 反应镜的音频列写「对白继续、画面切听者」，让声音连续。
- 一场戏里至少有一处「听的人比说的人有戏」，这是短剧里最省钱的张力。

## 六、情绪要有两个点

- 每个单元至少写清情绪**起点与终点**，并给**触发点**（某句台词、某个动作、某个声音之后才变）。
- 表情细节走 `40-表情微表情库.md` 的 FACS 三级，不在本文件重复。
- 一个单元从头到尾一个表情 = 观众读不出信息量。

## 七、交稿前的抽看

- 关键动作按 **0.2 秒间隔抽帧**看一遍（或把三拍逐句念一遍），找跳帧、穿模、道具脱手、脚底打滑。
- 重点看三处：手与道具的接触点、双脚与地面的关系、头与脖子的衔接。
- 这一条在分镜阶段就能做——不用等素材生成，靠的是画面内容写得够不够细。

## 八、自检

- [ ] 每个有意义的动作都有预备／动作／跟随三拍（或明确拆成起势—完成—落定三镜）
- [ ] 没有一镜塞两个以上大动作
- [ ] 重心与支撑脚写清了
- [ ] 手与道具的接触点写清了，没有悬空
- [ ] 每个切点都有动机（动作／视线／声音／信息）
- [ ] 声音桥没有跨出生成单元
- [ ] 反应镜里有动作，不只是「听着」
- [ ] 每个单元的情绪有起点、终点与触发点
