## 填写规则

| 规则 | 内容 |
|---|---|
| 编号 | `R001` 起递增，不回收、不复用；作废的条目保留并标"已撤销" |
| 一次一行 | 同一天两条触发线各触发一次 → 记两行，不合并 |
| 证据必填 | 「判定依据」必须能打开：产物路径、抽帧图、`gate.py` 原始输出片段、公告链接其一 |
| 时限要写死 | 「作废旧结论日」与「新结论落地日」都填 `YYYY-MM-DD`；未落地填预计日并加 `(预计)` |
| 改完要对账 | 新结论落地当天，回填「重估章节」里每个文件的新版本号；版本号对不上即该行未完成 |
| 撤销 | 判定被推翻时不动原行，追加一行同编号带 `-撤销`，写明推翻证据 |
